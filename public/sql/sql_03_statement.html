SQL Statements

DDL

  • DDL is used to construct an object in the database and deals with the structure of the object
  • It has 5 statement
    1. create
    2. Rename
    3. Alter
    4. Drop
    5. Truncate

① Create

  • It is used to Built / construct An object
  • object / entity can be a table or View (virtual tab)

How to create

  1. Name of the table
  2. Table Name should be different
  3. Number of column
  4. Names of the column
  5. Assign datatype for the column
  6. Assign constraints [Not mandatory]

② Rename

It is used to change the name of the object

Rename Table_name To New_name Rename customer To cust_1;

③ Alter

It is used to modify the structure of the table

★ To ADD column

Alter Table Table_name ADD column_name Datatype constraint_type Alter Table customer ADD ADDRESS (15)

★ To Drop column

Alter Table Table_name Drop column column_name Alter Table cust_1 Drop column MailID;

★ To Rename a column

Alter Table Table_name Rename column column_name to new_column_name Alter table customer Rename column CNO to PHNo

★ To modify the Datatype

Alter Table Table_name Modify column_name New_Datatype Alter Table customer Modify ADDRESS varchar(12);

★ To modify Not Null constraints

Alter Table table_name Modify column_name existing datatype [NULL/Not NULL]; Alter Table customer Modify ADDRESS Varchar(12) Not NULL

④ Truncate

It is used to remove All the Record from the table Permantly

TRUNCATE Table table_name

⑤ Drop

It is used to remove the table from the Database

Drop table table_name Drop Table customer
  • This command removes the table from the database But it is not completely removed from the database, it stores the address of that table and store in bin folder

★ To recover the table (Use Flashback)

Flashback Table table_name To Before Drop;

★ To Delete completely from BIN (Folder) (Use PURGE)

PURGE Table table_name

DML

It is used to manipulate the object by performing insertion, updation and deletion

① Insert

It is used to insert / create record in the table

Insert INto table_Name Values (V1,V2,V3 ---);

② Update

It is used to modify an existing value

Update Table_name set col_name = value, col_name = value --- [WHERE stmt];

③ Delete

It is used to remove a particular record From the table

Delete From table_name [WHERE stmt];

TCL

It is used to control the transaction done on the database, the dml operations performed on database are known as transaction such as Insertion, Updating and Deletion

We have 3 statement

  1. commit
  2. RollBack
  3. savepoint

① Commit

This statement statement is used to save the transaction into the Database

commit;

② RollBack

  • This statement is used to obtain only the saved data from the Database
  • It will bring you to the point where you have committed For the last time
ROLLBACK;

③ savepoint

  • This statement is used to control the flow of data between the users
  • This statement is used to mark the position or restoration points (nothing rejected to database)
savepoint savepoint_Name;

DCL

This statement is used to control the flow of data between the users

① GRANT

This statement statement is used to control the flow to give permission to a user

GRANT SQL_statement ON table_Name TO User_name;

② Revoke

This statement statement is used to take Back the permission from user

REVOKE SQL_statement ON table_Name FROM User_name;
