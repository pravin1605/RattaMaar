Group By and Having

Group By clause

  • It is used to create the group
  • It execute Row by Row
  • We can use group By clause without using WHERE
  • IF We use where claused then must be used before Group By
  • We can use group by with respective single column and multiple column
  • After the execution of group by clause we get group
  • Any clause with execute after group by clause should execute group by group
  • The column_name and expression written in group By clause can be written in select clause

syntax

Select group_by_expression / group Function FROM table [WHERE <row filter condition>] Group by column_name / expression;

HAVING Clause

  • It is used to Filter the group
  • It execute Group by Group
  • Having clause must be used after Group by clause
  • In having we are passing Group Filter condition

syntax

Select group_by_expression / group Function FROM table_name [WHERE column_name condition] Group By column_name / expression Having <Group Filter condition

ORDER of Execution

  1. FROM
  2. WHERE → Row by Row
  3. Group BY → Row by Row
  4. Having → Group by Group
  5. select → Group by Group

Assignment 04 Having (28-12-2025)

① WAQTD DNO and total sal Needed to pay All emp In each Dept IF there are atleast 4 emp In each Dept

SELECT count(*), sum(sal), deptNO FROM emp Group BY deptNO Having count(*) >= 4;

② WAQTD Number of emp earning sal more than 1200 In each JOB and the total sal Needed to pay emp of each job must excess 3000

SELECT count(*), sum(sal), Job FROM emp WHERE sal > 1200 Group by job Having sum(sal) > 3800;

③ WAQTD DeptNO and number of emp working only if there are 2 emp working in each Dept as analyst.

SELECT count(*), DeptNO FROM emp WHERE job = 'analyst' Group by DeptNO Having count(*) = 2;

④ WAQTD the salaries which are Repeated in emp table.

SELECT count(*), sal FROM emp Group by sal Having count(*) > 1;

⑤ WAQTD AVG sal of each Dept, IF AVG sal is less than 3000

SELECT AVG(sal), DeptNO FROM emp Group by DeptNO Having AVG(sal) < 3000

⑥ WAQTD The Hiredate which are Duplicate in emp table

SELECT count(*), Hiredate FROM emp Group by Hiredate Having count(*) > 1

⑦ WAQTD DeptNO IF there are atleast 3 emp In each Dept WHOSE Name Has char 'J' OR 'W'

SELECT count(*), DeptNo FROM emp WHERE ename like '%J%' OR ename like '%W%' Group by DeptNo Having Count(*) >= 3;

⑧ WAQTD MIN AND Max sal of each job IF MIN sal IS More than 1000 and max sal Is less than 5000

SELECT MIN(sal), Max(sal), job FROM emp Group by job Having MIN(sal) > 1000 AND Max(sal) < 5000;

⑨ WAQTD Number of emp Hired on the same Day Into The same department.

SELECT deptno, hiredate, count(*) FROM emp Group by deptno, hiredate Having count(*) > 1;

⑩ WAQTD Number of emp Getting the same sal In same department

SELECT deptno, sal, count(*) FROM emp Group by deptno, sal HAVING count(*) > 1;

⑪ WAQTD Number of emp Having the same name IN the same department

SELECT DeptNo, ename, count(*) FROM emp Group BY DeptNo, ename Having count(*) > 1;

⑫ WAQTD Number of emp Getting the same sal In same department Having the same name

SELECT deptNO, ename, sal, count(*) FROM emp Group BY deptNo, ename, sal Having Count(*) > 1

⑬ WAQTD Number of emp Getting the same sal In the same department AND Hired on same day

SELECT deptNO, sal, hiredate count(*) FROM emp Group BY deptno, sal, hiredate Having count(*) > 1;

⑭ WAQTD Display Job and total sal of each job, IF the total sal of each job is greater than 3000.

SELECT Job, sum(sal) FROM emp Group By Job Having sum(sal) > 3000;

⑮ WAQTD Display Job and total sal of the emp working In the Job IF the emp earning more than 1500 and AVG sal Job should be more than 1500

SELECT job, sum(sal) FROM emp WHERE sal > 1500 Group by Job Having AVG(sal) > 1500;
