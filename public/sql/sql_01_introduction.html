Introduction to SQL

What is SQL

SQL stands for Structured Query Lang. It is used to communicate with relational database with SQL I can:

  1. Create table and database
  2. Insert New data
  3. Update existing data
  4. Delete unwanted data
  5. Fetch data using queries

Database

Database is place or medium which is used to store the data in a systematic and organised manner
  • In Database we perform important operation universally referred as CRUD operation

DBMS

DBMS is a software which is used to maintain and manage the database
  • Security and authorization are the two important things by the DBMS
  • In DBMS we will store the data in form of files
  • To communicate with DBMS the query lang is used.

Types of DBMS

  1. Hierarchical
  2. Network
  3. RDBMS
  4. Object oriented DBMS

RDBMS

RDBMS is a type of DBMS software which is used to store the data in the form of tables
  • We use Structured Query Lang (SQL) to communicate with RDBMS

Relational Model

  • It is designed and developed by E.F. Codd
  • In relational model, we store the data in the form of tables
  • Any DBMS, if they follow relational model they become RDBMS
DBMS → Relational model → RDBMS

↓ E.F. Codd

Table

  • A table is a collection of rows and columns in a database
    • Each row is one record
    • Each column is a field

Cells

  • The intersection of rows and columns is known as cells
  • The smallest unit of the table is known as cell
