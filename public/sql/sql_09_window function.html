  • These Functions are used to calculate the operation Across set of groups without grouping
  • ANY Function which uses over keyword IS known as window Function

① ROW_Number()

  • This IS a window Function which is used to Assigne serial numbers to the Rows present In the result table
  • we can assigne the serial number BY Arranging the records either IN accending or Deccending order BY Using order BY clause
  • We can also use partition By clause to Divide the result table with respective A specific column
select col_name, ROW_Number() over([partition BY col_name] order BY col_name[Asc/DESC] from table_name
select sal, ROW_number() over(order BY sal) From emp;
select sal, ROW_number() over(partition BY DeptNo order BY sal) From emp

② Rank()

  • This is a window Function which is used to Assigne to ranks based on the values. It will always skip a rank whenever Rank are repeated
  • we can assigne the serial number BY arranging the records either IN Asc or Decs by using order BY clause
  • we can also use partition BY clause to Divide the result table with respective A specific column
Select col_name, Rank() over([partition BY col_name] order By col_name [Asc/DEcs]) From table_name
select DeptNo, sal, Rank() over(partition BY DeptNo order By sal) From emp;

③ Dense_Rank():

  • This is a window Function which is used to assigne to rank Based on values, It will not skip the ranks whenever ranks are repeated
  • we can assigne the serial number By arranging the records either in ASC or Decs using order BY clause
  • we can also use partition By clause to Divide the result table with respective A specific column
select col_name, Dense_Rank() over([partition By col_name] order By col_name [Asc/DEsc]) From table_name
select DeptNo, sal, Dense_Rank(partition By DeptNo order By sal) From emp;

LEAD (col_name)

  • This is a window Function which is used to obtain the next value present In the Row Based on the given column
  • we can assign the serial number BY arranging the record either in Asc or Desc order By using order By clause
  • We can also use partition By clause to Divide the result table with respective A specific column
select col_name, LEAD(col_name) over([partition By col_name order BY col_name [Asc/DESC]) From table_name;
select DeptNo, sal, lead(sal) over ([partition By deptNo order By sal) From table emp

Lag (col_name)

  • This is a window Function which is used to obtain the previous value present in the Row Based on the given col_name
  • We can assign the serial number By arranging the record either in Asc or Desc order By using order By clause
  • We can also use partition BY clause to Divide the result table with respective A specific column
select col_name, lag(col_name) over([partition BY col_name] order By col_name [Asc/DESC])
select DeptNo, sal, lag(sal) over (partition BY DeptNo order By sal) From table_name;
