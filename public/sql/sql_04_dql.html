Notes (order of Execution)

  • From clause starts the execution
  • For from clause we can pass table_name as an argument (Input)
  • The Job of From clause is to go to the database search for the table and put the table under execution
  • select clause executes after the execution of from clause
  • The Job of select clause is to go the table under execution and display mentioned columns.

IN operator

  • IN operator is a multivalue operator which can accept multiple value present at RHS
  • IN operator return value or output if any one of the condition is satisfied at RHS

syntax

Select column_name FROM table_name WHERE column_name/expression IN (V1,V2 ... Vn);
  • IN is helpful when we want to Filter data based on a set of values
  • It can be used with number/text and even subqueries
  • It makes the query more readable and maintaible than using many OR condition

question

① WAQTD Details of emp working in dept 10, 20, 30

select * FROM emp WHERE DeptNO IN (10,20,30)

② WAQTD Details of emp working as manager or salesman

select * FROM emp WHERE Job IN ('manager','salesman')

NOT IN OPERATOR

  • It is similar to IN operator instead of accepting the value it reject the value

syntax

select * FROM table_name WHERE column_name/expression NOT IN(V1,V2, ... Vn)

BETWEEN

  • BETWEEN operator is used whenever we have range of values
  • We cannot interchange the ranges
  • Between includes the ranges
  • It's most often used with number and table

syntax

column_name/expression BETWEEN 'lower_range' (>=) AND 'higher_range' (<=)

    2. '_' → underscore
