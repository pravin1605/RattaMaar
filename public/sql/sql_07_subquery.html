SubQuery

A Query written inside the another query is known as subquery

Working Principal of sub query

  1. Let's considered two query (outer and Inner)
  2. Inner query executes First and generate an output, the output of innerquery will backed as outer query
  3. outer query executes and generate the result
  4. we can state that outer query is dependent on innerquery

Case ①

Whenever we have indirect or unknown condition we should use subquery

① WAQTD to display the name of emp who sal is greater than James

select ename From emp Where sal > ( select sal From emp Where ename = 'James');

② WAQTD Details of emp earning sal more than smith less than king

Select * From emp Where sal > ( select sal From emp Where ename = 'smith') AND sal < ( select sal From emp Where ename = 'King');

The data to be selected and the condition to be executed are present in different table then we use subquery

Types of SubQuery

① Single Row subquery

IF the subquery written exactly one record or Value we called it as Single Row subquery

IF it written only one value then we can use normal operators or special operator to compare the value.

select DName From Dept Where DeptNO = or IN (select DeptNO From emp Where ename = 'James');

both be valid

  1. If subquery gives a single value then use (=)
  2. If it multiple value then use special

② MultiRow subquery

IF the subquery written more than one value or record we called as multiRow subquery

IF it written more than one value we cannot use normal operator we have to use special operator to compare the value

ANY Operator

  • It is subquery operator which is used along with relational operator to compare the value present at the RHS
  • ANY operator written true if any one of the value is gets satisfied at RHS
