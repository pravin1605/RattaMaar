Function

Function are Block of code or list of instruction which are used to perform specific task

① Single Row Function

  • It executes Row by Row
  • SRF take an input process and execute and then takes the next input
  • IF you pass n number of input It will give n number of outputs

② Multi Row Function

  • It execute in group
  • MRF take the all inputs at one shot then executes and provides an single output

N number of Input → return 1 output

Components of Function

  1. Function name
  2. Number of argument
  3. Return type

Note

  1. Along with a multi Row Function any other column in the select clause Not supported
  2. we cannot use multi Row Function in where clause
  3. multi Row Function ignore the null values
  4. MRF can accept only one argument column_name or expression
  5. COUNT is only MRF which can accept * as argument

① Length()

  • It is used to count the number of character present In the given string

syntax

Length('string')

Example

select Length(ename) From emp Where ename ='smith';

WAQTD Names of emp having exactly Four character without using like operator

select ename from emp Where Length(ename) = 4;

② CONCAT()

  • It is used to JOIN the given two string

syntax

CONCAT('string', 'string')

Example

select concat('MR', ename) From emp

③ UPPER()

  • It is used to convert given string to upper case

syntax

UPPER('string')

Example

④ LOWER()

  • It is used to convert given string to lower case

syntax

Lower('string')

example

⑤ INITCAP()

⑥ REVERSE()

⑧ Replace()

  • It is used to replace a string with another string in orginal string
Replace('original string', 'string' [new_string]) Replace('BANANA', 'A', 'C') → BCNCNC

① WAQTD number of 'A' present in malayalam

select Length('malayalam') Length(Replace('Malayalam', 'A')) From DUAL

IF the third argument is not mentioned the default value is not null

⑨ INSTR()

  • It is used to obtain the position in which the string is present in the orginal string.
  • It is used to a string in their if present it return the position else it return 0
INSTR('original_string', 'string', position [occurence])

IF occurence is not mentioned then the default of occurence is 1

ⓐ WAQTD Name having char A without using like operation

select ename From emp where INSTR('ename', 'A', 1, 1) > 0

ⓑ WAQTD Name of emp having char A at least twise

select ename From emp where INSTR('ename', 'A', 1, 2) > 1

ⓒ WAQTD Name of emp having char exactly twise in their name

select ename from emp where INSTR(ename, 'A', 1, 2) > 0 AND INSTR(ename, 'A', 1, 3)

TRUNC()

ORDER BY clause

  • It is used to arrange the records either in Ascending or Deceding order
  • ORDER BY clause execute Row by Row
  • ORDER BY clause is the only clause which is going to execute after select clause
  • Arrange the record in accending order by default

syntax

SELECT Group_By_expression / group Function FROM table_name [WHERE <Filter condition>] [Group By column_name/expression] [Having <group Filter condition>] ORDER BY col_name/expression/col_number [ASC/DESC]

ORDER of execution

  1. FROM
  2. WHERE
  3. Group BY
  4. Having
  5. SELECT
  6. ORDER BY
