JOIN

The process of retrieving of data From multiple table simultaneously is known as Join

Types of JOIN

  1. cartesian / cross Join
  2. Inner Join
  3. Natural join
  4. outer Join
    1. Left outer join
    2. Right outer join
    3. Full outer Join
  5. self Join

when / or why

Whenever we need to select the data From more than one table we use the concept of Join

① cartesian / cross Join

  • A record From table one is merge with all the record of table two is known as cross JOIN
  • The number of column is present in result table is summation OF both table
  • The number of records present in result table is equal to the product of both table

syntax

Oracle syntax

Select * / col_name / expression From table_name1, table_name2;

ANSI syntax

Select * / col_name / expression From table_name1 cross JOIN Table_name2;

Natural JOIN

Natural join has behaviour, IF there is connection between two table It behavious like INNER join

or else

IF there is NO connection between two table it behaviour like cartesian JOIN

syntax

only ANSI syntax

select * From Table1 Natural JOIN Table2;
select * From emp Natural join Dept;

Here there is common column such as DeptNo so it behaviour like INNER JOIN

select * From emp natural join customer;

Here there is no common column that why it behaviour like cross JOIN

Self JOIN

  • Joining self same two table is known as self JOIN

When or why

Whenever data to be selected is in the same table, but present in different records we use the concept of self JOIN

① WAQTD emp name, manager name along with DeptNo IF emp working as clerk.

select ename, e2.name, E1.DeptNo, E2.DeptNo From emp E1, emp E2 where E1.MGR = E2.empNo AND E1.Job = 'clerk';

② WAQTD emp name and manager name IF manager IS working as actual manager

select e1.name, e2.name From emp e1, emp e2 where E1.MGR = E2.empNo AND e2.Job = 'manager';

(E = e) ↳ same for all question
sql IS not case sensitive.

③ WAQTD emp.name and manager name along with their Job IF emp and manager are working For same Designation

select e1.name, e2.name, e1.Job, e2.Job From emp e1, emp e2 where e1.MGR = e2.empNo AND e1.Job = e2.Job

④ WAQTD emp name AND manager name Along with their annual sal IF emp works In Dept 10, 20 and manager sal is Greater than emp sal.

select E1.name, E2.name, e1.sal*12, e2.sal*12 From emp E1, emp E2 WHERE E1.MGR = E2.empNo AND E1.DeptNo IN(10,20) AND e2.sal > e1.sal

⑤ WAQTD emp name, manager name along with manager name and sal OF all the emp

select E1.name, E1.sal, E2.name, E2.sal From emp E1, Emp E2 WHERE E1.MGR = E2.empNo
