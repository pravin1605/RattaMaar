Constraint

  • A constraint is a rule that we apply on a column or a table to control what kind of data can be stored in that column
  • Constraint helps us maintain the accuracy, consistency and integrity of data in the database

Types of constraints

  1. Unique
  2. Not Null
  3. check
  4. primary key
  5. foreign key
  6. Default

① UNIQUE

It is constraint which is used to avoid Duplicate or a Repeated value

② Not Null

It is constraint which is used to avoid Null values

③ check

check is a constraint which is used for extra validation with a condition, If a condition is satisfied then the value is accepted.

④ Default

sets a default value if No value is provided.

⑤ primary key

is a constraint which is used to identified a record uniquely from table

characteristics

  1. PK cannot accept duplicate value
  2. PK cannot accept Null values
  3. PK is a combination of unique and Not Null
  4. We can have only one PK in table

⑥ Foreign key

  • is a constraint which is used to established connection between two tables.
  • A Foreign key is a column in one table that is used to connect to the primary key of another table

characteristic

  1. FK can accept duplicate values
  2. FK can accept Null values
  3. FK it is not combination of unique and Not Null
  4. We can have multiple FK in a table
  5. Attribute become a FK then must be PK in it's own table
  6. FK is also known as Referential Integrity constraint.
