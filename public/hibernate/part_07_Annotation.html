📘 What are Annotations & Why Are They Important?

Annotations are special metadata used to provide instructions to Hibernate/JPA. They help Hibernate understand:

  • Which class is a table
  • Which field is a column
  • Which field is a primary key
  • How values should be generated
  • How mapping should happen
🔹 Before annotations — XML (old way):
<class name="Student"> <id name="id"/> </class> // Lengthy + difficult to maintain
🔹 Now with annotations (new way):
@Entity public class Student { } // Short ✅ Readable ✅ Easy to maintain ✅
Annotations replaced verbose XML mapping files in Hibernate. They provide metadata directly in Java classes — making code shorter, readable, and easier to maintain. Key annotations: @Entity, @Table, @Id, @GeneratedValue, @Column.
1 @Entity Class Level | Mandatory

Definition: Used to declare a POJO class as an Entity Class. Tells Hibernate: This Java class should be mapped to a database table.

import jakarta.persistence.Entity; @Entity public class Student { }

Internal Working: @Entity → Student Class → Student Table

Why Important?

  • Without @Entity → Hibernate will NOT recognize class
  • No table mapping will happen
🔹 Important Points:
  • Mandatory for every Entity Class
  • Applied above class declaration
  • Converts POJO into Persistent Class
  • Maps class with table (by default: class name = table name)
2 @Table Class Level | Optional

Definition: Used to specify table details — change table name, define schema, define catalog.

@Entity @Table(name="student_info") public class Student { } // Student class → student_info table

Why Important? By default Hibernate uses class name as table name. When DB naming convention differs from Java:

Without @Table
Student class → Student table
With @Table
Student class → student_info table

Points: Optional | Class level | Used when table name differs from class name

3 @Id Field Level | Mandatory

Definition: Used to declare Primary Key inside Entity Class.

@Entity public class Student { @Id private int id; private String name; }

Why Important? Every table must have a Primary Key which uniquely identifies records and prevents duplicate identification.

Points: Mandatory | One @Id per entity | Field level | Without @Id → AnnotationException

4 @GeneratedValue Field Level | Used with @Id

Definition: Used to automatically generate Primary Key values. Removes need for manual ID assignment.

@Id @GeneratedValue // auto strategy private int id; // OR with specific strategy: @Id @GeneratedValue(strategy = GenerationType.IDENTITY) private int id;

DB auto-generates: 1 → 2 → 3 → 4...

🔹 Generation Strategies:
AUTO
Hibernate decides generation strategy automatically
IDENTITY
Database generates ID. Commonly used with PostgreSQL ✅
SEQUENCE
Uses a database sequence for ID generation
TABLE
Uses a separate table to track next ID value

Points: Reduces manual work | Must be used with @Id | Supports multiple strategies

5 @Column Field Level | Optional

Definition: Used to specify column details and customize database columns.

Why? By default Hibernate uses variable names as column names. Use @Column when you need: different column name, length restrictions, unique values, not-null constraints.

🔹 name — Column Name
@Column(name="student_name") private String name; // name variable → student_name column

Used when DB naming convention differs from Java.

🔹 length — Max Size
@Column(length=50) private String name; // Generates: VARCHAR(50)

Prevents unnecessary storage allocation.

🔹 nullable — NOT NULL
@Column(nullable=false) private String name; // Generates: NOT NULL constraint // NULL value → ❌ Not Allowed

Ensures mandatory fields are always filled.

🔹 unique — Unique Constraint
@Column(unique=true) private String email; // Duplicate email → ❌ Not Allowed

Prevents duplicate records for this field.

📘 Complete Entity Class Example — All Core Annotations Together
import jakarta.persistence.*; @Entity @Table(name="student_info") public class Student { @Id @GeneratedValue(strategy = GenerationType.IDENTITY) private int id; @Column( name="student_name", length=50, nullable=false ) private String name; @Column(unique=true) private String email; public Student() { } // Getters and Setters }

Core annotations: @Entity (class=table), @Table (rename table), @Id (PK), @GeneratedValue (auto PK), @Column (name/length/nullable/unique). These 5 annotations are enough for basic CRUD entity mapping in Hibernate.

6 @Transient Field Level

Definition: Tells Hibernate: "Do NOT store this field in the database."

@Entity public class Student { @Id private int id; private String name; @Transient private int age; // NOT stored in DB }

Why? Temporary data — calculated fields (age from DOB), confirm password, total marks.

FieldStored in DB
id✅

7 @Lob Field Level

Definition: LOB = Large Object. Used to store large text, images, PDFs, videos.

@Lob private String description; // CLOB @Lob private byte[] image; // BLOB

Why? Normal VARCHAR has size limits. Large content needs LOB (CLOB for text, BLOB for binary).

8 @Temporal Field Level

Definition: Used to map Java Date and Time values to specific DB types.

@Temporal(TemporalType.DATE) private Date joiningDate; // Stores: 2025-06-17 @Temporal(TemporalType.TIME) private Date loginTime; // Stores: 10:30:45 @Temporal(TemporalType.TIMESTAMP) private Date createdAt; // Stores: 2025-06-17 10:30:45
9 @Enumerated Field Level

Definition: Used to store Java Enum values in database.

public enum Gender { MALE, FEMALE } @Enumerated(EnumType.STRING) private Gender gender; // Stores "MALE" or "FEMALE" as String // EnumType.ORDINAL stores 0 or 1 (index)

Why? Without it Hibernate cannot properly map Enum values to DB.

10 @OneToOne Field Level

Definition: Represents One-to-One relationship between two entities.

@OneToOne private Passport passport;

Real Life: One Person → One Passport | One User → One Profile

11 @OneToMany Field Level

Definition: One record related to multiple records.

@OneToMany private List<Employee> employees;

Real Life: One Department → Many Employees | One Customer → Many Orders

12 @ManyToOne Field Level

Definition: Many records belong to one record.

@ManyToOne private Department department;

Real Life: Many Employees → One Department | Many Students → One College

13 @ManyToMany Field Level

Definition: Many records related to many records.

@ManyToMany private List<Course> courses;

Real Life: Students ↔ Courses (Many:Many) | Doctors ↔ Patients

14 @JoinColumn Field Level

Definition: Used to specify the Foreign Key column name.

@ManyToOne @JoinColumn(name="dept_id") private Department department; // dept_id created as Foreign Key column
15 @JoinTable Field Level

Definition: Used in Many-to-Many relationships. Creates an intermediate (join) table.

@ManyToMany @JoinTable(name="student_course") private List<Course> courses; // Creates: student_course table // with student_id + course_id columns

16 @CascadeType Relationship Attribute

Definition: Automatically performs operations on related entities when performed on parent.

@OneToMany(cascade=CascadeType.ALL) private List<Employee> employees;
PERSIST
Save child automatically with parent
REMOVE
Delete child automatically with parent
ALL
Perform all cascade operations
17 @FetchType Relationship Attribute

Definition: Controls how related data is fetched from the database.

// EAGER — load immediately @OneToMany(fetch=FetchType.EAGER) // LAZY — load when accessed @OneToMany(fetch=FetchType.LAZY)
💬 Interview Point: Most commonly used = FetchType.LAZY because it improves performance — loads related data only when actually needed.
18 @Embedded Field Level

Definition: Used to embed one class inside another entity. Embedded fields become part of the parent entity table.

@Entity public class Student { @Id private int id; @Embedded private Address address; // city + state become Student table columns }
19 @Embeddable Class Level

Definition: Marks a class whose objects can be embedded inside an entity. Used together with @Embedded.

@Embeddable public class Address { private String city; private String state; } // Used inside @Entity via @Embedded // city + state stored in parent table
20 @Inheritance Class Level

Definition: Used for inheritance mapping. Maps Java inheritance hierarchy to database tables.

@Entity @Inheritance( strategy=InheritanceType.SINGLE_TABLE) public class Person { } // Strategies: // SINGLE_TABLE — one table for all // TABLE_PER_CLASS — separate tables // JOINED — shared + child tables
21 @Version Field Level

Definition: Used for Optimistic Locking. Prevents concurrent update problems.

@Version private int version;

Real Life: Two users edit same record simultaneously → Hibernate checks version number before updating → prevents data corruption.

🎯 Interview Answer
✅ Q: What are the important Hibernate annotations?

The most commonly used Hibernate/JPA annotations are:

  1. @Entity — Declares a class as an Entity that maps to a database table.
  2. @Table — Specifies custom table name and schema details.
  3. @Id — Defines the Primary Key field.
  4. @GeneratedValue — Automatically generates Primary Key values. Strategy IDENTITY is commonly used with PostgreSQL.
  5. @Column — Customizes column properties: name, length, nullable, unique constraints.
  6. @Transient — Marks a field to be ignored (not stored in DB).
  7. @OneToOne, @OneToMany, @ManyToOne, @ManyToMany — Define entity relationships.
  8. @FetchType.LAZY — Preferred fetching strategy for better performance.
