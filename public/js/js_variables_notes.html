JavaScript · Chapter 3

Variables in JavaScript

01What is a variable?
Definition
A Variable is a named memory location used to store data or values. In simple words, variables are containers used to store information such as a name, age, salary, or marks.
Basic example
let name = "Pravin"; console.log(name);
Output
Pravin
Breaking down the example
name → the Variable (the container name)
"Pravin" → the stored value inside the container
let → the keyword used to declare the variable
3 ways to declare variables in JavaScript
var let const
02var — the old way
var
Function-scoped variable
Old / traditional way of declaring variables
Definition
var is the old traditional way of declaring variables in JavaScript. It was the only option before ES6 was introduced in 2015.
Interview definition
var is a function-scoped variable declaration keyword that allows redeclaration and reassignment.
Characteristics of var
iCan be redeclared — same variable can be declared again
iCan be reassigned — value can be changed anytime
iHas function scope — accessible throughout the whole function
iSupports hoisting — declaration is moved to the top automatically
Basic example
var age = 20; console.log(age);
Output
20
Redeclaration — allowed with var
var name = "Pravin"; var name = "Rahul"; // redeclared — no error console.log(name);
Output
Rahul
Problem — var ignores block scope
var does NOT support block scope. A variable declared inside an if block using var leaks out into the surrounding code — this causes bugs.
var x = 10; if (true) { var x = 50; // same variable — overwrites the outer x } console.log(x);
Output
50
The outer x was overwritten because var has no block scope — this is a common bug source.
Problems with var
Accidental changesVariables can be accidentally overwritten anywhere in the code.
Redeclaration bugsRedeclaring a variable silently overwrites the old value — no error shown.
No block scopevar ignores if, for, and while block boundaries.
Hard to manageVery difficult to track and debug in large applications.
03let — the modern way
let
Block-scoped variable
Introduced in ES6 (2015) — recommended for most variables
Definition
let is a modern variable declaration keyword introduced in ES6 (2015). It solves the major problems created by var by adding block scope and preventing accidental redeclaration.
Interview definition
let is a block-scoped variable declaration keyword that allows reassignment but prevents redeclaration within the same scope.
Characteristics of let
xCannot be redeclared in the same scope — prevents accidental bugs
iCan be reassigned — value can be updated anytime
iHas block scope — stays inside the { } block where it was declared
Basic example
let salary = 50000; salary = 60000; // reassignment — allowed console.log(salary);
Output
60000
Redeclaration — NOT allowed with let
let name = "Pravin"; let name = "Rahul"; // ❌ Error — cannot redeclare
Error
SyntaxError: Identifier 'name' has already been declared
Block scope example — let vs var
var — leaks out of block
var x = 10; if (true) { var x = 50; } console.log(x);
Output
50 ← wrong!
let — stays inside block
let x = 10; if (true) { let x = 50; } console.log(x);
Output
10 ← correct!
Why let was introduced
Prevent redeclarationStops accidental variable overwriting in the same scope.
Block scopeVariable stays inside its own { } block — safer and predictable.
Fewer bugsReduces errors in large applications significantly.
Better readabilityMakes code easier to understand and maintain.
04const — fixed values
const
Block-scoped constant
Introduced in ES6 (2015) — for values that never change
Definition
const is used to declare constant values — values that should never be changed after they are set. It must be given a value at the time of declaration and cannot be changed later.
Interview definition
const is a block-scoped variable declaration keyword used for values that should not be reassigned after their initial declaration.
Characteristics of const
xCannot be redeclared — ever
xCannot be reassigned — value is permanently fixed
iHas block scope — same as let
iMust be initialized at declaration — cannot be declared empty
Basic example
const pi = 3.14; console.log(pi);
Output
3.14
Reassignment — NOT allowed with const
const country = "India"; country = "USA"; // ❌ Error — cannot reassign
Error
TypeError: Assignment to constant variable.
Must be initialized at declaration
Wrong — no value given
const x; // ❌ SyntaxError
Correct — value given
const x = 100; // Works perfectly
Why const was introduced
Prevent changesStops accidental modification of important values.
More secureGuarantees the value will never change — improves reliability.
Predictable codeMakes code easier to reason about — no surprises.
Used for constantsPI, tax rates, API URLs, config values — all should use const.
Real-life use cases for const
const PI = 3.14159; const TAX_RATE = 18; const BASE_URL = "https://api.example.com"; const APP_NAME = "MyApp";
05var vs let vs const — full comparison
Feature var let const
Scope Function scope Block scope Block scope
Redeclaration Yes — allowed No — error No — error
Reassignment Yes — allowed Yes — allowed No — error
Must initialize? No No Yes — required
Introduced in Old JavaScript ES6 (2015) ES6 (2015)
Best used for Avoid using Most variables Fixed values
Quick code comparison — all three
var city = "Pune"; // old way — function scoped let age = 22; // modern — can change const PI = 3.14; // fixed — cannot change city = "Mumbai"; // allowed age = 25; // allowed // PI = 3; // ❌ Error — const cannot be reassigned
Interview — which one to use?
Use const by default for everything.
Use let only when the value needs to change.
Avoid var completely in modern JavaScript — it causes too many bugs.
Memory Trick — var = old & buggy  ·  let = modern & flexible  ·  const = fixed & safe  ·  Default rule: use const first, switch to let if needed, never use var.
