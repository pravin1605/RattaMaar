Data Types in JavaScript

01What is a data type?
Definition
A Data Type defines what kind of value a variable can store in memory. It tells JavaScript whether the stored value is a Number, Text (String), True/False (Boolean), Object, Array, or something else.
Two main categories
Primitive data types
Store a single value directly in memory. They are simple and immutable.
NumberStringBooleanNullUndefined
Non-primitive data types
Store collections of values or complex entities. They are mutable.
ObjectArrayFunction
02Primitive data types
Definition of Primitive Data Types
Primitive data types are basic built-in data types that store single immutable values directly in memory.
01
Number
Stores integers, decimals, positive and negative values
Definition
The Number datatype is used to store integer values, decimal values, and positive or negative numbers. All numeric values in JavaScript — whether whole or decimal — use the same Number type.
Example
let age = 22; let price = 99.99; let temperature = -5; console.log(age); console.log(price); console.log(temperature);
Output
22 99.99 -5
Real-life examples
Age = 22  ·  Salary = 50000  ·  Marks = 89.5
02
String
Stores characters, words, and sentences inside quotes
Definition
String datatype is used to store characters, words, and sentences inside quotes. Quotes can be single quotes ( ' ' ), double quotes ( " " ), or backticks ( ` ` ).
Interview definition
String is a primitive datatype used to represent textual data enclosed within quotes.
Example
let name = "Pravin"; let city = 'Nashik'; let message = `Hello, ${name}`; console.log(name); console.log(city); console.log(message);
Output
Pravin Nashik Hello, Pravin
Real-life examples
Name = "Rahul"  ·  Email = "abc@gmail.com"
Types of quotes allowed
Single quotes ' 'Double quotes " "Backticks ` `
03
Boolean
Stores only two values — true or false
Definition
Boolean datatype stores only two values — true or false. It is used in conditions, decision making, and validation.
Used in
ConditionsDecision makingValidation
Example
let isPassed = true; let isLoggedIn = false; console.log(isPassed); console.log(isLoggedIn);
Output
true false
Real-life examples
Exam Passed = true  ·  User Logged In = false
04
Null
Intentionally empty value — set manually
Definition
Null represents an intentionally empty value. It means the value exists but is intentionally set to nothing. This is done by the developer on purpose.
Interview definition
Null is a primitive datatype that represents an intentional absence of value.
Example
let data = null; console.log(data);
Output
null
Real-life example
Middle Name = null  ·  Means: the user does not have a middle name — intentionally left empty.
05
Undefined
Variable declared but value not yet assigned
Definition
Undefined means the variable is declared but no value has been assigned to it. JavaScript automatically assigns undefined in this case — the developer does not set it manually.
Interview definition
Undefined is a primitive datatype assigned automatically to variables that are declared but not initialized.
Example
let x; console.log(x);
Output
undefined
Real-life example
Student marks not entered yet — the field exists but has no value assigned.

03Non-primitive data types
Definition of Non-Primitive Data Types
Non-primitive data types are reference data types used to store collections of values or complex entities.
01
Object
Stores data as key-value pairs — represents real-world entities
Definition
Object stores data in key-value pairs. It is used to represent real-world entities like a student, employee, or product — where each property has a name (key) and a value.
Interview definition
Object is a non-primitive datatype that stores data as key-value pairs.
Example
let student = { name: "Pravin", age: 22, city: "Nashik" }; console.log(student.name); console.log(student.age); console.log(student.city);
Output
Pravin 22 Nashik
Real-life example
Student object — Name: Pravin  ·  Age: 22  ·  City: Nashik
02
Array
Stores multiple ordered values — index starts from 0
Definition
Array stores multiple values in an ordered form inside square brackets [ ]. Each value has a position called an index, and indexing always starts from 0.
Interview definition
Array is a non-primitive datatype used to store multiple ordered values in a single variable.
Example
let colors = ["Red", "Blue", "Green"]; console.log(colors[0]); // index 0 console.log(colors[1]); // index 1 console.log(colors[2]); // index 2
Output
Red Blue Green
Real-life example
Subjects = ["Math", "Science", "English"]  ·  index 0 = Math, index 1 = Science, index 2 = English
03
Function
A reusable block of code that runs when called
Definition
Function is a reusable block of code designed to perform a specific task. It runs only when it is called (invoked).
Interview definition
Function is a reusable block of code that executes when it is invoked or called.
Example
function greet() { console.log("Welcome"); } greet(); // calling the function
Output
Welcome
Real-life example
ATM Machine — Withdraw Money function  ·  Check Balance function  ·  Deposit Money function
04Immutable vs Mutable behavior
Immutable — Primitive data types
Immutable means the original value cannot be changed after it is created. Primitive datatypes like String, Number, Boolean are all immutable — once a value is created in memory, it stays the same.
If you try to change a character inside a string, JavaScript silently ignores it. The string stays unchanged.
Example — trying to change a string character
let str = "Hello"; str[0] = "Y"; // trying to change first character console.log(str);
Output
Hello
The string remains "Hello" — the change at index 0 was silently ignored. Strings are immutable.
Mutable — Non-primitive data types
Mutable means the value can be modified after it is created. Objects and Arrays are mutable — their properties and elements can be changed, added, or deleted at any time.
Objects and arrays can be changed after creation. Non-primitive types are always mutable.
Example — changing an object property
let person = { name: "Pravin" }; person.name = "Rahul"; // changing the property console.log(person.name);
Output
Rahul
The name was successfully changed from "Pravin" to "Rahul" — objects are mutable.
05Primitive vs Non-primitive — full comparison
FeaturePrimitiveNon-primitive
StoresSingle value onlyMultiple values or complex data
NatureImmutable — cannot changeMutable — can be changed
MemoryStored by valueStored by reference
ComplexitySimpleComplex
ExamplesNumber, String, Boolean, Null, UndefinedObject, Array, Function
Stored by value — primitive
let a = 10; let b = a; b = 20; console.log(a); // 10 console.log(b); // 20
a is not affected — they are separate copies.
Stored by reference — non-primitive
let obj1 = {x:10}; let obj2 = obj1; obj2.x = 99; console.log(obj1.x); // 99
obj1 is also changed — they share the same reference.
Memory Trick — Primitive = Single value, Immutable, By Value  ·  Non-Primitive = Multiple values, Mutable, By Reference
