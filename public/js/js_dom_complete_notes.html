DOM — Document Object Model

When a browser loads an HTML page, it converts the entire HTML document into a tree of objects called the DOM. JavaScript uses this tree to access, read, modify, create, and delete elements on the page — all without reloading.

Full form

Document Object Model

Easy definition

"DOM is a bridge between HTML and JavaScript." HTML gives the structure. DOM lets JS talk to it.

Interview definition

"DOM is a programming interface that represents an HTML document as a tree of objects, allowing JS to dynamically access, modify, create, and delete elements."

Why needed

Without DOM, JavaScript cannot interact with HTML. DOM is what makes web pages interactive and dynamic.

DOM tree structure — how browser sees HTML

HTML → DOM Tree

The browser reads HTML and builds a tree. Every tag becomes a node. The entire document is the root. JavaScript walks this tree to find and change elements.

HTML code

<html>
  <body>
    <h1>Hello</h1>
    <p>Welcome</p>
  </body>
</html>

Browser converts it to a tree

Document
└── html
    └── body
         ├── h1
         │    └── "Hello"
         └── p
              └── "Welcome"

Every HTML element is a node in this tree. Parent → Child → Text — all connected. JS can reach any node using DOM methods.

Features of DOM — what JS can do with it

Feature 1

Dynamic Content Manipulation

Change text or HTML content on the page without reloading.

Example

document.getElementById("demo").innerHTML = "Hello Pravin";

Output — on screen

Hello Pravin ← content changes instantly on page
Feature 2

Dynamic Style Manipulation

Change CSS properties of any element directly using JavaScript.

Example

document.getElementById("demo").style.color = "red";

Output — on screen

Text turns RED on the page
Feature 3

Event Handling

Respond to user actions like clicks, keypresses, mouse movements.

Example

button.onclick = function() {
  alert("Button Clicked");
};

Output — on click

Browser alert popup: "Button Clicked"
Feature 4

Create & Delete Elements

Add new HTML elements or remove existing ones dynamically at runtime.

Example

let h1 = document.createElement("h1");  // create
document.body.appendChild(h1);           // add
document.getElementById("title").remove(); // delete

Output

New h1 appears on page / existing element disappears
Feature 5

Platform Independent

DOM works on all browsers — Chrome, Firefox, Safari, Edge. Write once, works everywhere.

  • Supported natively in every modern browser.
  • No extra library or installation needed.
  • Same DOM API works across all operating systems.

DOM selector methods — how to find elements

Selector methods are used to grab HTML elements from the DOM so JavaScript can work with them. Think of them as different ways to search for an element — by ID, by class, by tag, or by CSS selector.

01

getElementById("id")

Selects a single element by its unique id attribute. Returns the element directly (not a list). Since IDs are unique, this always returns one element or null.

"getElementById() returns the HTML element whose id matches the specified value."
  • Returns a single element — not a collection.
  • Returns null if no element with that ID exists.
  • Fastest DOM selector — IDs are indexed by the browser.
  • Memory tip: "ID = unique name tag — only one person wears it."

HTML

<h1 id="title">Hello</h1>

JavaScript

let element = document.getElementById("title");
console.log(element);
console.log(element.innerText);

Output

<h1 id="title">Hello</h1> Hello
02

getElementsByClassName("class")

Returns all elements that share the given class name. Returns an HTMLCollection — like an array but not exactly an array.

"getElementsByClassName() returns a live HTMLCollection of all elements with the specified class name."
  • Returns an HTMLCollection — not a regular array.
  • Use index to access individual items: element[0].
  • Live collection — updates automatically if DOM changes.
  • Memory tip: "class = uniform — many students wear the same uniform."

HTML

<p class="demo">HTML</p>
<p class="demo">CSS</p>
<p class="demo">JavaScript</p>

JavaScript

let elements = document.getElementsByClassName("demo");
console.log(elements);
console.log(elements[0].innerText);
console.log(elements.length);

Output

HTMLCollection(3) [p.demo, p.demo, p.demo] HTML 3
03

getElementsByTagName("tag")

Returns all elements with the given HTML tag name. Useful when you want all headings, all paragraphs, or all list items at once.

"getElementsByTagName() returns a live HTMLCollection of all elements with the specified tag name."
  • Returns an HTMLCollection.
  • Use "*" to select every element on the page.
  • Live collection — updates if DOM changes.
  • Memory tip: "tag = type label — get everything of that type."

HTML

<h1>Hello</h1>
<h1>World</h1>

JavaScript

let elements = document.getElementsByTagName("h1");
console.log(elements);
console.log(elements[0].innerText);
console.log(elements.length);

Output

HTMLCollection(2) [h1, h1] Hello 2
04

querySelector("CSS selector")

Returns the first element that matches any CSS selector. Uses the same syntax as CSS — dot for class, hash for ID, tag name directly.

"querySelector() returns the first element that matches the specified CSS selector."
  • Returns only the FIRST matching element.
  • Use "#id" for ID, ".class" for class, "tag" for tag.
  • Most flexible selector — supports all CSS selectors.
  • Returns null if no match found.
  • Memory tip: "querySelector = Ctrl+F in a document — finds the first match."

HTML

<p class="demo">HTML</p>
<p class="demo">CSS</p>
<p id="special">JavaScript</p>

JavaScript

let byClass = document.querySelector(".demo");
let byId    = document.querySelector("#special");
let byTag   = document.querySelector("p");

console.log(byClass.innerText);
console.log(byId.innerText);
console.log(byTag.innerText);

Output

HTML ← first .demo element JavaScript ← #special element HTML ← first p tag
05

querySelectorAll("CSS selector")

Returns all elements that match the given CSS selector. Returns a NodeList — similar to an array, supports forEach().

"querySelectorAll() returns a static NodeList of all elements matching the specified CSS selector."
  • Returns a NodeList — not a live collection (static snapshot).
  • Supports .forEach() directly — unlike HTMLCollection.
  • Static — does not update automatically if DOM changes.
  • Memory tip: "querySelectorAll = Ctrl+F find ALL matches."

HTML

<p class="demo">HTML</p>
<p class="demo">CSS</p>
<p class="demo">JavaScript</p>

JavaScript

let elements = document.querySelectorAll(".demo");
console.log(elements);
console.log(elements.length);

elements.forEach((el) => {
  console.log(el.innerText);
});

Output

NodeList(3) [p.demo, p.demo, p.demo] 3 HTML CSS JavaScript

DOM content methods — reading and changing text

Content methods let you read or change what is inside an HTML element. Three options — each behaves differently with HTML tags and hidden content.

01

innerHTML reads & writes HTML

Gets or sets the complete HTML content inside an element, including HTML tags. Use it when you want to inject actual HTML markup.

  • Can read and write HTML tags.
  • Setting innerHTML replaces all existing content.
  • Security risk — never inject user input directly (XSS attacks).
  • Memory tip: "innerHTML = whatever HTML is INSIDE the tag."

HTML

<h1 id="title">Hello</h1>

JavaScript — read

let t = document.getElementById("title");
console.log(t.innerHTML);

Output

Hello

JavaScript — write with HTML tag

t.innerHTML = "<i>Welcome</i>";

Output — on screen

Welcome ← appears as italic text on page
02

innerText visible text only

Gets or sets only the visible text content of an element. Ignores HTML tags and hidden elements. What you see on screen is what you get.

  • Strips all HTML tags — returns plain text only.
  • Ignores hidden elements (display:none).
  • Safer than innerHTML when handling user input.
  • Memory tip: "innerText = what the user actually sees on the page."

HTML

<h1 id="title">Hello</h1>

JavaScript — read

let t = document.getElementById("title");
console.log(t.innerText);

Output

Hello

JavaScript — write

t.innerText = "Welcome";

Output — on screen

Welcome ← plain text, no formatting
03

textContent all text including hidden

Returns all text content — both visible and hidden. Unlike innerText, it includes text inside elements with display:none.

  • Returns text from hidden elements too.
  • Does not parse HTML tags — returns them as plain text.
  • Faster than innerText — does not trigger layout recalculation.
  • Memory tip: "textContent = ALL text including what is hiding behind the curtain."

HTML

<div id="demo">
  Hello
  <span style="display:none">Hidden</span>
</div>

JavaScript

let d = document.getElementById("demo");
console.log(d.innerText);
console.log(d.textContent);

Output

Hello ← innerText (hidden span ignored) Hello Hidden ← textContent (hidden span included)

DOM attribute methods — reading and changing attributes

01

getAttribute("attr")

Reads the value of a specified HTML attribute from an element. Works on any attribute — href, src, class, id, custom data attributes.

  • Returns the attribute value as a string.
  • Returns null if the attribute does not exist.
  • Memory tip: "getAttribute = read the label on the package."

HTML

<a id="link" href="https://google.com">Google</a>

JavaScript

let value = document.getElementById("link")
            .getAttribute("href");
console.log(value);

Output

https://google.com
02

setAttribute("attr", "value")

Sets or updates the value of an HTML attribute. If the attribute doesn't exist, it creates it. If it exists, it overwrites it.

  • Takes two arguments — attribute name and new value.
  • Creates the attribute if it does not already exist.
  • Common uses: change href, update src, add class.
  • Memory tip: "setAttribute = change the label on the package."

HTML

<a id="link" href="https://google.com">Google</a>

JavaScript

document.getElementById("link")
  .setAttribute("href", "https://youtube.com");

// Verify the change
let newVal = document.getElementById("link")
             .getAttribute("href");
console.log(newVal);

Output

https://youtube.com ← link now points to YouTube

DOM style methods — changing CSS with JavaScript

element.style.property = "value"

Access and modify inline CSS of any element using element.style.propertyName. CSS property names with hyphens become camelCase in JS — background-color → backgroundColor.

  • Only sets inline styles — overrides external or internal CSS.
  • CSS hyphen properties become camelCase: font-size → fontSize, border-radius → borderRadius.
  • To read current style (including stylesheet), use getComputedStyle() instead.
  • Memory tip: "element.style = the style tag written directly on the element."

HTML

<h1 id="title">Hello</h1>

JavaScript

let title = document.getElementById("title");

title.style.color           = "red";
title.style.backgroundColor = "yellow";
title.style.fontSize        = "32px";
title.style.padding         = "10px";
title.style.borderRadius    = "8px";

Output — on screen

Hello

Text is red, background yellow, font bigger, padded, with rounded corners

CSS property → JS camelCase

background-color → backgroundColor font-size → fontSize border-radius → borderRadius text-align → textAlign

DOM create element methods — adding new elements

01

document.createElement("tag")

Creates a new HTML element in memory. The element is NOT yet visible on the page — it needs to be added using appendChild() or similar.

  • Creates element in memory only — not on page yet.
  • You can set its content and styles before adding to the page.
  • Memory tip: "createElement = manufacture the part in the factory — not installed yet."

JavaScript

let h1 = document.createElement("h1");
h1.innerText = "Welcome Pravin";
h1.style.color = "blue";
console.log(h1);

Output — in console

<h1 style="color: blue;">Welcome Pravin</h1> ← element exists in memory but NOT on page yet
02

element.appendChild(newElement)

Adds a newly created element as the last child of the specified parent element. This is how you make the element actually appear on the page.

  • Adds as the LAST child of the parent.
  • Use document.body.appendChild() to add directly to the page body.
  • Memory tip: "appendChild = install the manufactured part onto the car."

JavaScript

let h1 = document.createElement("h1");
h1.innerText = "Welcome Pravin";
document.body.appendChild(h1);
console.log("Element added to page!");

Output — console

Element added to page!

Output — on screen

Welcome Pravin ← new h1 appears on the page
Complete create example

Create → Style → Add to page

The full 3-step pattern for dynamically adding a new element: create it, set its content and style, then add it to the page.

JavaScript

// Step 1: create
let card = document.createElement("div");

// Step 2: set content and style
card.innerText          = "I was created by JavaScript!";
card.style.background   = "#EEEDFE";
card.style.padding      = "12px";
card.style.borderRadius = "8px";
card.style.color        = "#3C3489";

// Step 3: add to page
document.body.appendChild(card);

Output — on screen

I was created by JavaScript!

DOM remove method — deleting elements

remove()

element.remove()

Removes the element from the DOM completely. The element disappears from the page instantly. No parent reference needed — you call it directly on the element.

  • Called directly on the element to remove — no arguments needed.
  • Removes the element AND all its children from the page.
  • The element still exists in memory (JS variable) but is no longer on the page.
  • Memory tip: "remove() = delete key — element is gone from the page."

HTML

<h1 id="title">Hello</h1>

JavaScript

let element = document.getElementById("title");
console.log(element.innerText);  // read before removal
element.remove();
console.log("Element removed!");

Output — console

Hello Element removed!

Output — on screen

← The h1 with "Hello" disappears from the page instantly

🎯 30-second interview answer — memorize this

"DOM stands for Document Object Model. It is a programming interface that represents an HTML document as a tree of objects. DOM allows JavaScript to dynamically access, modify, create, and delete HTML elements. Common DOM methods include getElementById(), querySelector(), innerHTML, createElement(), appendChild(), and remove(). DOM acts as a bridge between HTML and JavaScript."

⭐ Golden rules — say these in an interview

  • querySelector() and querySelectorAll() are the modern preferred selectors — they accept any CSS selector syntax.
  • getElementsByClassName() returns a live HTMLCollection. querySelectorAll() returns a static NodeList — this is a key difference.
  • Never use innerHTML to insert user-provided content — it can lead to XSS (Cross-Site Scripting) attacks. Use innerText or textContent for safe text insertion.
  • CSS hyphen properties become camelCase in JS — background-color → backgroundColor.
  • createElement() creates the element in memory only. You MUST call appendChild() or insertBefore() to make it appear on the page.
  • innerText triggers layout recalculation (slower). textContent does not (faster) — use textContent when you only need to read/write plain text.
