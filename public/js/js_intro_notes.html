01📘 What is JavaScript?
DEFINITION JavaScript is a high-level programming language used to make web pages interactive, dynamic, and intelligent. It works mainly in two environments — the browser (client-side) and the server using Node.js (server-side).
▸ What we can build with JavaScript
UI interaction

Create buttons, forms, popups, and animations on web pages.

Validation

Validate user input before it reaches the server.

Data fetching

Fetch data from servers and display it dynamically.

Full applications

Build complete web apps, games, and mobile apps.

▸ Where JavaScript works
✗ Browser (client-side)

Runs directly in Chrome, Firefox, Safari, and Edge. No installation needed.

✓ Server (server-side)

Runs on a computer using Node.js. Powers the backend of web apps.

▸ Real-life understanding — HTML + CSS + JavaScript
TechnologyRole in websiteReal-life example
HTMLStructureSkeleton of the body
CSSDesignClothes and makeup
JavaScriptFunctionalityBrain and muscles
💡 Classic example: HTML creates a button · CSS styles the button · JavaScript makes the button do something when clicked.
INTRODUCTION TO JAVASCRIPT | Page 2 — Key Characteristics
02✅ Key characteristics of JavaScript
01Interpreted Language
JavaScript runs line by line

JavaScript code is executed line by line by the browser engine. No compilation step is needed — unlike Java or C++, it runs directly in the browser.

▸ Example
JS
console.log("Hello"); console.log("JavaScript");
EXECUTION ORDER
Step 1 → console.log("Hello") runs first Step 2 → console.log("JavaScript") runs second
02Dynamically Typed Language
No need to specify data type manually

JavaScript automatically determines the data type of a variable at runtime. The same variable can store different types of values.

▸ Example
JS
let x = 10; // Number x = "Pravin"; // String x = true; // Boolean
Same variable can store different data types — JavaScript handles it automatically.
03Prototype-Based Language
Objects can inherit from other objects

In JavaScript, one object can use the features (properties and methods) of another object. This is called prototype-based inheritance.

▸ Example
JS
const student = { name: "Pravin" }; console.log(student.name);
OUTPUT
Pravin
04Scripting Language
Automates behavior inside webpages

JavaScript is designed to automate behavior — popup messages, form validation, button click actions, and more — without needing a separate program.

▸ Examples of scripting
Popup messagesForm validationButton click actions
05Asynchronous Language
Can perform tasks later without stopping

JavaScript can schedule tasks to run in the future without blocking the rest of the program. This is used in timers, API calls, and event handling.

▸ Example — timer running asynchronously
JS
setTimeout(() => { console.log("Runs after 2 seconds"); }, 2000);
OUTPUT (AFTER 2 SECONDS)
Runs after 2 seconds
The rest of the program keeps running while this timer waits. JavaScript does not stop and wait.

03📘 History of JavaScript
CREATOR JavaScript was created by Brendan Eich in just 10 days in the year 1995.
▸ Timeline
1995 Created by Brendan Eich in just 10 days at Netscape.
First name Originally called Mocha — the very first name of the language.
Renamed Later renamed to LiveScript before getting its final name.
Final name Given the final name JavaScript — the name it carries today.
▸ ECMAScript — the official standard

ECMAScript is the official standard on which JavaScript is based. JavaScript follows ECMAScript rules and receives updates through it. Common versions include ES5, ES6 (ES2015), ES2020, and beyond.

▸ ECMAScript versions
ES5ES6 / ES2015ES2017ES2020ES2022+
INTRODUCTION TO JAVASCRIPT | Page 4 — Ways to use JavaScript in HTML
04✅ Ways to use JavaScript in HTML
🔹 Type 1 — Internal JavaScript

JavaScript code written directly inside the HTML file using the <script> tag. Best for small pieces of code.

▸ Example
HTML
<!DOCTYPE html> <html> <head> <title>Internal JS</title> </head> <body> <h1>Hello</h1> <script> alert("Welcome"); </script> </body> </html>
▸ Internal JS flow
HTML file loads
↓
Browser finds <script> tag
↓
Browser executes JavaScript
🔹 Type 2 — External JavaScript

JavaScript written in a completely separate .js file and linked to HTML using the src attribute. Best for large projects — keeps HTML and JS cleanly separated.

▸ HTML file
HTML
<!DOCTYPE html> <html> <head> <title>External JS</title> </head> <body> <h1>Hello</h1> <script src="script.js"></script> </body> </html>
▸ script.js file
script.js
alert("External JavaScript File");
▸ External JS flow
HTML file loads
↓
Browser reads src="script.js"
↓
Browser loads the JS file
↓
JavaScript executes
▸ Internal vs External — comparison
FeatureInternal JSExternal JS
LocationInside the HTML fileSeparate .js file
ReusabilityLow — only for that pageHigh — reuse across pages
MaintenanceDifficult for large codeEasy to manage and update
Best forSmall code snippetsLarge real-world projects
★ Most ImportantBest practice — always use External JS for real projects. It keeps your HTML clean, your JS reusable, and your code easy to maintain.
