JavaScript Strings — Complete Study Notes

Strings in JavaScript

A string is a sequence of characters used to represent text. Strings are primitive values but behave like objects because JS auto-wraps them when you call a method. Strings are immutable — no method changes the original; they always return a new one.

Ways to create

let s = "hello";   // double
let s = 'hello';   // single
let s = `hello`;   // template

Key trait

Immutable — methods never touch the original. Think of it like a photocopy machine — the original stays safe.

Indexing

Zero-based — first character is at index 0, last is at length - 1. Negative indexes (via at()) count from the end.

Why use strings

Store names, messages, URLs, HTML content, user input — basically anything text-based in your app.

Group 1 — Info & measurement

01

length property

Returns the total number of characters in the string including spaces. It is a property, not a method — no parentheses needed.

  • Counts every character — letters, spaces, symbols all count.
  • Last character index = length - 1.
  • Memory tip: "length = how many seats are in the row."

Example

let name = "Pravin is a good boy";
console.log(name.length);

Output

20
02

charAt(index)

Returns the character at the specified index. If index is out of range, returns an empty string "".

  • Does NOT support negative indexes — returns "" for negative values.
  • Use at() instead when you need negative indexing.
  • Memory tip: "charAt = which seat is at position N?"

Example

let name = "Pravin";
console.log(name.charAt(0));
console.log(name.charAt(name.length - 1));

Output

P n
03

at(index) ES2022

Returns the character at the specified index. Unlike charAt(), it supports negative indexes — so at(-1) gives the last character.

  • Negative index counts from the end: at(-1) = last char.
  • Introduced in ES2022 — modern and preferred over charAt for reverse access.
  • Memory tip: "at(-1) = last seat in the row — no need to count manually."

Example

let name = "Pravin is a good boy";
console.log(name.at(-1));
console.log(name.at(-3));

Output

y b
04

charCodeAt(index)

Returns the Unicode (ASCII) number of the character at the given index. Every character in a computer has a secret number — this reveals it.

  • 'A' = 65, 'a' = 97, '0' = 48.
  • Useful for comparing characters mathematically in algorithms.
  • Memory tip: "charCodeAt = what is the ID number of this character?"

Example

let name = "Pravin";
console.log(name.charCodeAt(0));

Output

80
05

String.fromCharCode(code) static

The reverse of charCodeAt(). Takes a Unicode number and converts it back into a character. Called on the String class itself, not on a string variable.

  • Called as String.fromCharCode() — not on a string variable.
  • Can convert multiple codes at once: String.fromCharCode(72, 101, 108).
  • Memory tip: "fromCharCode = give me the character whose ID is N."

Example

console.log(String.fromCharCode(80));
console.log(String.fromCharCode(97));

Output

P a

Group 2 — Search & check

06

indexOf(value)

Finds the index of the first occurrence of a value inside the string. Returns -1 if not found.

  • Case-sensitive — "A" ≠ "a".
  • Returns only the FIRST match — use lastIndexOf() for the last.
  • Memory tip: "indexOf = where does this word first appear?"

Example

let name = "Pravin is a good boy";
console.log(name.indexOf("a"));
console.log(name.indexOf("z"));

Output

2 -1
07

lastIndexOf(value)

Finds the index of the last occurrence of a value in the string. Scans from the end backwards. Returns -1 if not found.

  • Case-sensitive.
  • Pair with indexOf() — together they find first and last positions.
  • Memory tip: "lastIndexOf = where does this word appear for the LAST time?"

Example

let name = "Pravin is a good boy";
console.log(name.lastIndexOf("o"));

Output

18
08

includes(value) ES6

Checks whether the string contains the given value. Returns true or false. Perfect for conditions.

  • Case-sensitive.
  • Cleaner than indexOf() !== -1 for simple presence checks.
  • Memory tip: "includes = does this sentence include this word? Yes or No."

Example

let name = "Pravin is a good boy";
console.log(name.includes("good"));
console.log(name.includes("bad"));

Output

true false
09

startsWith(value) ES6

Checks whether the string begins with the given value. Returns true or false. Case-sensitive.

  • Useful for checking URL prefixes, file extensions, protocol checks.
  • Optional second param: starting position to check from.
  • Memory tip: "startsWith = does this sentence open with this word?"

Example

let name = "Pravin is a good boy";
console.log(name.startsWith("P"));
console.log(name.startsWith("p"));

Output

true false
10

endsWith(value) ES6

Checks whether the string ends with the given value. Returns true or false. Useful for file type checks.

  • Case-sensitive.
  • Great for: file.endsWith(".pdf"), email.endsWith("@gmail.com").
  • Memory tip: "endsWith = does this sentence close with this word?"

Example

let name = "Pravin is a good boy";
console.log(name.endsWith("y"));
console.log(name.endsWith("Y"));

Output

true false

Group 3 — Case conversion

11

toUpperCase()

Converts every character to uppercase. Returns a new string — original stays unchanged.

  • Does not mutate the original string.
  • Use for: storing data consistently (e.g. country codes, IDs).
  • Memory tip: "toUpperCase = SHOUT the sentence."

Example

let name = "Pravin is a good boy";
console.log(name.toUpperCase());

Output

PRAVIN IS A GOOD BOY
12

toLowerCase()

Converts every character to lowercase. Returns a new string — original stays unchanged.

  • Does not mutate the original string.
  • Common use: normalize user input — input.toLowerCase() === "yes".
  • Memory tip: "toLowerCase = whisper the sentence."

Example

let name = "Pravin is a good boy";
console.log(name.toLowerCase());

Output

pravin is a good boy

Group 4 — Extract a portion

13

slice(start, end) supports negative

Extracts a portion of the string from start up to (but not including) end. Returns a new string. Supports negative indexes.

  • End index is exclusive — character at end is NOT included.
  • Negative indexes work: slice(-3) = last 3 characters.
  • Does not mutate the original string.
  • Memory tip: "slice = cut a slice of bread — original loaf stays."

Example

let name = "Pravin is a good boy";
console.log(name.slice(0, 6));
console.log(name.slice(-3));

Output

Pravin boy
14

substring(start, end) no negative

Extracts a portion of the string from start to end (exclusive). Similar to slice() but does NOT support negative indexes.

  • Negative values are treated as 0.
  • If start > end, it swaps them automatically.
  • Does not mutate the original string.
  • Memory tip: "substring = older sibling of slice — less flexible, no negatives."

Example

let name = "Pravin is a good boy";
console.log(name.substring(0, 6));

Output

Pravin

slice vs substring — key difference

slice()

  • Supports negative indexes
  • slice(-3) = last 3 chars
  • If start > end → returns ""
  • Modern & preferred

substring()

  • No negative indexes (treated as 0)
  • substring(-3) = same as (0)
  • If start > end → swaps them
  • Older — use slice() instead

charAt() vs at() — key difference

charAt(index)

  • No negative index support
  • Returns "" for invalid index
  • Available since ES1
  • Use for older environments

at(index)

  • Supports negative indexes
  • at(-1) = last character
  • Introduced in ES2022
  • Modern & preferred

Group 5 — Modify & transform

15

replace(old, new)

Replaces the first occurrence of a value with a new value. Returns a new string.

  • Only replaces the FIRST match.
  • Use replaceAll() to replace every occurrence.
  • Accepts a regular expression for advanced patterns.
  • Memory tip: "replace = fix-it tape — covers the first mistake."

Example

let name = "Pravin is a good boy";
console.log(name.replace("Pravin", "Onkar"));

Output

Onkar is a good boy
16

replaceAll(old, new) ES2021

Replaces every occurrence of a value with a new value. Returns a new string.

  • Replaces ALL matches — not just the first.
  • Introduced in ES2021 — cleaner than using regex with /g flag.
  • Memory tip: "replaceAll = find-and-replace-all in a Word document."

Example

let name = "Pravin is a good boy";
console.log(name.replaceAll("a", "@"));

Output

Pr@vin is @ good boy
17

split(separator)

Splits the string into an array of substrings based on the separator. This is the bridge between strings and arrays.

  • Returns an array — not a string.
  • split("") splits into individual characters.
  • split(" ") splits by spaces into words.
  • Memory tip: "split = cut the rope at every knot — each piece becomes an array item."

Example

let name = "Pravin is a good boy";
console.log(name.split(" "));

Output

["Pravin", "is", "a", "good", "boy"]
18

repeat(count)

Returns a new string repeated count number of times. Like copy-pasting the string N times.

  • Count must be a non-negative number.
  • repeat(0) returns an empty string.
  • Memory tip: "repeat = the echo — same thing said N times."

Example

let word = "Ha";
console.log(word.repeat(3));

Output

HaHaHa

Group 6 — Whitespace removal

19

trim()

Removes whitespace from both the start and end of the string. Very useful for cleaning user input from forms.

  • Does NOT remove spaces between words — only from edges.
  • Use before comparing or storing user input.
  • Memory tip: "trim = haircut — trim the sides, not the middle."

Example

let s = "   Hello World   ";
console.log(s.trim());

Output

Hello World
20

trimStart() & trimEnd() ES2019

trimStart() removes whitespace only from the beginning. trimEnd() removes it only from the end.

  • Introduced in ES2019.
  • Use when you only want to clean one side.
  • Memory tip: "trimStart = erase the blank intro; trimEnd = cut the blank outro."

Example

let s = "   Hello   ";
console.log(s.trimStart());
console.log(s.trimEnd());

Output

Hello Hello

The golden rules of strings

  • Strings are immutable — no method ever changes the original. Every method returns a brand new string.
  • All search methods are case-sensitive — "A" and "a" are different.
  • split() is the bridge from string → array. join() (array method) brings it back from array → string.
  • Prefer at() over charAt() and prefer slice() over substring() — they are the modern, more powerful versions.
  • Always trim() user input before comparing or storing — users accidentally add spaces all the time.
