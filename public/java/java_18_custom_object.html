Searching custom object inside a collection

  • when we want to search an element in the collection First we should know For which element we are searching
  • The element For which we are searching is considered as key element

Diagram: key → (1) object → contains(object o) [collection], indexOf(object o) [List]; (2) attribute of an object.

Searching based on the object

  • IF the key is object we can make use of the Following two methods
    • contains(object ele) From collection interface
    • indexOf(object ele) From List interface
  • These both methods internally uses equals() method to compare key with the objects present inside the collection

Note

IF we are not overriding the equals method inside the custom object then contains() method will check the address instead of data

Searching if the key is attribute of an object

  • IF the key is attribute of an object we should traverse through all the element and compare the key with all the objects attribute
  • IF the key is matching with any of the attribute of an object then the object will be existing inside the collection
Public class Demo-searchingBasedOnId { Public static void main(string[] args) { Arraylist al = new Arraylist(); int key = 131; student toBeSearched = null; For(object o : al) { student s = (student) o; IF(key == s.id) { toBeSearched = s break; } } S.O.P.l(toBeSearched); } } O/P student {id = 131, name = vaishav, cgpa = 8.9, age = 60, branch = comp}

Removing the elements from collection

  • When we want to remove any object from the collection we should know which element we want to remove
  • The element which should be removed is consided as key element
  • The key element to be removed can be the Following things ① object ② attribute of an object

Removing an element if the key is Object

  • IF the key is object we can directly call remove(object) method from collection interface
  • this remove(object) will internally call equals method present in custom object to compare key with all the objects inside collection.
  • so IF we want to remove the object from collection we need to override equals method inside the word missing: "student class"? we need to override equals method in a such a way that it compares custom object the data
