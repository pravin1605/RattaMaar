Java - 16 List Interface

List

  • List is an interface in the Java collection Framework used to store ordered collections of elements.
  • It allows access to elements using index-based positioning
  • It is a child interface of the collection interface
  • Declared in the Java.util package
  • Introduced in Java 1.2 version
  • Implementation classes of list ① ArrayList ② LinkedList ③ Vector ④ Stack

characteristics

  • list is an indexed collection - every element is associated with an index starting from 0.
  • It automatically assigns indexes when elements are added
  • list allows duplicate elements
  • list allows null values (multiple, depending on the implementation)
  • list maintains insertion order
  • We can perform operation based on index like get(index), set(index, element), remove(index)

Methods of list interface

To ADD elements

① void add(int index, object element)
↳ Insert an element at a specific index position
↳ Existing elements are shifted to the right.

② boolean addAll(int index, collection c)
↳ Insert all elements of another collection starting from the given index.

To remove elements

③ object remove(int index)
↳ Remove the element at the specified index
↳ Returns the removed element

④ object set(int index, object element)
↳ Replace the element at a given index with new element
↳ Returns the old element

To Access elements

⑤ object get(int index)
↳ Returns the element present at the specified index

⑥ int indexOf(object element)
↳ Return the index of the first occurence of the given element
↳ IF the element is not found, it return -1

⑦ ListIterator listIterator()
↳ Returns a ListIterator to traverse the list Forward and backward

⑧ ListIterator listIterator(int index)
↳ Returns a ListIterator starting from a specific index

Other Methods

⑨ public int lastIndexOf(object element)
↳ Returns the index of the last occurence of the element

⑩ List subList(int startIndex, int endIndex)
↳ Returns a portion (sub list) of the list From startIndex to endIndex-1
IF list = [A, B, C, D, E] → subList(1, 4) → [B, C, D]

Arraylist program

Public class Demo { Public static void main(string[] args) { Arraylist al = new Arraylist() 0 al.add(10) 1 al.add("abc") 2 al.add(true) 3 al.add('c') 4 al.add(20) 5 al.add(30) 6 al.add(40) 7 al.add(50) 8 al.add(60) 9 al.add(70) //Here capacity is full 10 al.add(80) //Adding extra element S.O.P.l(al); } } O/P [10, abc, true, c, 20, 30, 40, 50, 60, 70, 80]

Diagram: al = 0x1 holds the internal object[] address. The first array 0x2 has default capacity = 10 (slots 0 to 9, each pointing to a wrapper object: 10, "abc", true, 'c', 20, 30, 40, 50, 60, 70). When the 11th element (80) is added, a new array 0x3 with new capacity 15 is created, the old elements are copied to the same indexes, 80 goes at index 10, and 0x3 replaces 0x2 inside the ArrayList object.

Explanation of the above Arraylist program

When we create an Arraylist object using Arraylist al = new Arraylist();
No internal array is created immediately

① Internal array creation

  • The internal array (object[]) is created only when the First element is added
  • By default, the initial capacity of this internal array is 10
  • The reference (address) of this object[] array is stored inside the Arraylist object.

② Why different data types can be stored

  • The internal array is of type object[]
  • since object is the parent class of all non-primitive classes, any object can be stored using upcasting
  • primitive values like int, boolean and char are automatically converted into their corresponding wrapper objects (Integer, Boolean, character) using autoboxing
  • That is why the same Arraylist can store: Integer, String, Boolean, character

③ Capacity vs size

  • capacity → length of the internal array
  • size → number of elements actually stored

④ How Arraylist grows dynamically

  • when the internal array become Full (after 10 element)
  • and we try to add the 11th element
    • A new array with larger capacity is created
    • the new capacity is calculated as old capacity + (old capacity / 2) → 10 + 5 = 15
    • All existing element are copied into the new array at the same index
    • The new element is added at the next available index
    • the reference to the old array is replaced with the reference to the new array
    • the old array becomes eligible For garbage collection

⑤ Important conclusion

  • Even though the internal structure is an array, Arraylist can store any number of elements because it dynamically resize itself
  • This resizing happens automatically and is hidden from the programmer

★ Accessing List Elements Using For Loop

  • In Java collections, elements stored inside a list can be accessed using their index position
  • Since a list maintains insertion order, each element has an index starting from 0
