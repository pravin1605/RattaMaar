Java - 03 Control Flow Statement

Control Flow Statement

  • Control flow statements is a Statement that controls the flow of execution in a program

    • ① conditional statement | Decision making statement

    ② Looping statement

    ③ Jumping statement

    ADDED: Memory map (easy way to remember)

    ① Conditional = "Should I do it?" (if, if-else, else-if, switch) → decides which code runs

    ② Looping = "How many times?" (while, do-while, for, for-each) → decides how often code runs

    ③ Jumping = "Skip or stop!" (break, continue, return) → changes the normal path

    🧠 How to think before writing any program: Input → Decision / Repeat → Output. Ask 3 questions: (1) What data do I get? (2) Is there a choice (condition) or a repeat (loop)? (3) What must be printed or returned?

    ① Conditional statement

    • conditional statement are used to decide whether the set of instruction or program has to be be executed or not based on the condition
      • ① IF statement
      • ② If else statement
      • ③ else if ladder
      • ④ switch statement .

    ADDED: Which one to choose?

    One optional action → if | Two choices (A or B) → if-else | Many ranges (marks, age groups) → else-if ladder | One variable vs fixed values (day, menu choice) → switch

    ⚡ Trick: Condition must always give true or false. Use == to compare (not =), and && (AND), || (OR), ! (NOT) to join conditions.

    ① IF statement

    { S1; IF(condition) { S2 } S3; S4; }

    ADDED: IF – Example 1 (voting)

    int age = 20; if (age >= 18) { System.out.println("You can vote"); // runs only if true } System.out.println("Thank you"); // ALWAYS runs

    Example 2 (discount)

    int bill = 1500; if (bill > 1000) { bill = bill - 100; // Rs.100 off only for big bills } System.out.println("Pay: " + bill); // Pay: 1400

    🧠 Logic: Ask "Is there a step I must do only sometimes?" → that step goes inside if. Steps that must always happen go outside.

    ⚡ Trick: If the condition is false the block is simply skipped (nothing else happens). Read it like English: "IF age is 18 or more THEN print".

    ⚠ Common mistakes: if(x = 5) (wrong, assignment) → use if(x == 5). Also if(x > 5); (extra semicolon) ends the if early and the block always runs.

    ② If else statement

    { S1; IF(condition) { S2; } else { S3; } S4; }

    ADDED: IF-ELSE – Example 1 (even / odd)

    int n = 7; if (n % 2 == 0) { System.out.println("Even"); } else { System.out.println("Odd"); // prints Odd }

    Example 2 (login check)

    String pass = "java123"; if (pass.equals("java123")) { System.out.println("Welcome"); } else { System.out.println("Wrong password"); }

    🧠 Logic: Exactly one block runs – never both, never none. Use it when the question is "A or B?".

    ⚡ Shortcut (ternary): String r = (n % 2 == 0) ? "Even" : "Odd";  → condition ? if-true : if-false

    ⚡ Trick: Compare Strings with .equals(), not ==. Remainder % 2 == 0 means even; % n == 0 means divisible by n.

    ③ else if ladder

    { S1; If (condition) { S2; } else if(condition) { S3; } . . else { S4 } S5; }
    • only one block gets executed
    • else block should be the last block
    • else block is optional.

    ADDED: ELSE-IF LADDER – Example 1 (grade)

    int marks = 82; if (marks >= 90) { System.out.println("Grade A+"); } else if (marks >= 75) { System.out.println("Grade A"); // prints this } else if (marks >= 50) { System.out.println("Grade B"); } else { System.out.println("Fail"); }

    Example 2 (positive / negative / zero)

    int n = 0; if (n > 0) System.out.println("Positive"); else if (n < 0) System.out.println("Negative"); else System.out.println("Zero"); // prints Zero

    Example 3 (largest of three, using &&)

    int a = 5, b = 9, c = 3; if (a >= b && a >= c) System.out.println("a is largest"); else if (b >= c) System.out.println("b is largest"); // prints this else System.out.println("c is largest");

    🧠 Logic: Java checks top to bottom and the first true wins; the rest are skipped. So write highest range first (90, then 75, then 50). Else is the "none of the above" safety net.

    ⚡ Trick: Draw a number line, mark the cut-off points, then write the conditions from one end to the other. Each next condition automatically means "below the previous one".

    ⚠ Mistake: writing marks >= 50 first – then 90 marks also prints "B", because the first true condition wins.

    ④ switch statement

    switch(value/variable/expression) { case value/expression : { statements } [break;] case value/expression : [ statements } [break;] . . [default : { statements } [break] ] }
    verify: bracket "[ statements }" in the second case as written

    ADDED: SWITCH – Example 1 (day name)

    int day = 3; switch (day) { case 1: System.out.println("Monday"); break; case 2: System.out.println("Tuesday"); break; case 3: System.out.println("Wednesday"); break; // prints this default: System.out.println("Invalid day"); }

    Example 2 (grouping cases – fall through on purpose)

    char ch = 'e'; switch (ch) { case 'a': case 'e': case 'i': case 'o': case 'u': System.out.println("Vowel"); // prints Vowel break; default: System.out.println("Consonant"); }

    Example 3 (calculator menu with String)

    String op = "+"; int a = 10, b = 5; switch (op) { case "+": System.out.println(a + b); break; // 15 case "-": System.out.println(a - b); break; case "*": System.out.println(a * b); break; case "/": System.out.println(a / b); break; default: System.out.println("Wrong operator"); }

    🧠 Logic: Use switch when one variable is compared with fixed values (menu, day, month, grade letter). For ranges like marks >= 50 use else-if.

    ⚡ Trick: Remember "C-B-D" = Case, Break, Default. Every case needs a break, default goes at the end.

    ⚡ Shortcut: Case labels must be constants. Switch works with int, char, byte, short, String, enum – not long, float, double, boolean. Modern Java (14+) also allows case 1, 7 -> System.out.println("Weekend"); (no break needed).

    ⚠ Mistake: forgetting break → Java "falls through" and also runs the next cases until it finds a break.

    ② Loop statement.

    • It is used to execute an instruction or a set of instruction for multiple times
    • It helps to control flow of execution
    • Types of Loops
      • ① while loop
      • ② do while loop
      • ③ for loop
      • ④ for each / enhanced For

    ADDED: Every loop has 3 parts (I-C-U)

    Initialization (start value) → Condition (keep going while true) → Update (move towards the end)

    ⚡ Trick: If a loop never stops, one of I-C-U is missing or wrong. Usually U (update) is forgotten.

    🧠 Logic: Find the repeating work first (e.g. "add a number"), then decide start, end and step. Choose: count known → for | count unknown → while | must run once at least → do-while | go through array/collection → for-each.

    ⚡ Shortcuts: i++ means i = i + 1  |  i += 2 means i = i + 2  |  sum += i means sum = sum + i

    ① while loop

    S1; while(condition) { S2; } S3;

    ① The condition is used to control the number of repetition

    ② the statements inside the loop gets executed until the condition becomes False

    ADDED: WHILE – Example 1 (print 1 to 5)

    int i = 1; // I : start while (i <= 5) { // C : condition System.out.println(i); i++; // U : update } // Output: 1 2 3 4 5

    Example 2 (sum of digits – count is unknown, so while)

    int n = 123, sum = 0; while (n > 0) { sum = sum + n % 10; // n % 10 gives last digit n = n / 10; // n / 10 removes last digit } System.out.println(sum); // 6

    Example 3 (reverse a number)

    int n = 456, rev = 0; while (n != 0) { rev = rev * 10 + n % 10; n = n / 10; } System.out.println(rev); // 654

    ⚡ Trick: % 10 = take last digit, / 10 = cut last digit. This pair solves most digit problems (sum, reverse, palindrome, count digits, Armstrong).

    🧠 Logic: while is entry controlled – condition is checked first. If it is false at the start, the body runs 0 times.

    ⚠ Mistake: forgetting i++ gives an infinite loop. Dry run on paper: write i, condition, output for each round.

    ② do while loop

    do { S1; S2; } while (condition); S3;

    ① The do block execute 1 time without checking condition

    ② In do while statement do block is executed first and then it checks the condition

    ③ It is recommended to use do whil in situation where a set of instruction have to be executed once mandatorily and later based on the demand ( line cut off at page edge

    ADDED: DO-WHILE – Example 1 (runs once even if condition is false)

    int i = 10; do { System.out.println(i); // prints 10 once i++; } while (i <= 5); // false, so loop stops

    Example 2 (menu repeats until user chooses exit)

    int choice; do { System.out.println("1.Play 2.Exit"); choice = sc.nextInt(); // sc is a Scanner (see Dynamic Read) } while (choice != 2);

    Example 3 (ask until valid age)

    int age; do { System.out.print("Enter age (1-100): "); age = sc.nextInt(); } while (age < 1 || age > 100); // repeat while input is invalid

    🧠 Logic: Use when you must do first, then ask – menus, password retry, input validation.

    ⚡ Trick: do-while ends with a semicolon ; after the condition. while / for do not. Memory line: "do-while = Do it, Wait, then check" (exit controlled).

    For loop

    S1 For(initialization ; condition ; updation) { statement 2 ; } S3 ;

    Order marks ① to ⑤ are written on the code diagram: ① initialization, ② condition, ③ statement, ④ updation verify numbers

    ADDED: FOR – Example 1 (print 1 to 5)

    for (int i = 1; i <= 5; i++) { System.out.println(i); } // Output: 1 2 3 4 5

    Example 2 (multiplication table of 5)

    for (int i = 1; i <= 10; i++) { System.out.println("5 x " + i + " = " + (5 * i)); }

    Example 3 (sum of 1 to n, and factorial)

    int n = 5, sum = 0, fact = 1; for (int i = 1; i <= n; i++) { sum += i; // 15 fact *= i; // 120 }

    Example 4 (reverse and step)

    for (int i = 10; i >= 1; i--) System.out.print(i + " "); // 10 9 8 ... 1 for (int i = 2; i <= 10; i += 2) System.out.print(i + " "); // 2 4 6 8 10

    ⚡ Trick (pattern table):
    • Run n times → for(int i=0; i<n; i++)  |  1 to n → for(int i=1; i<=n; i++)
    • Backward → i-- and i >=  |  Skip → i += step
    • Sum starts at 0, product / factorial starts at 1

    🧠 Logic: Ask 3 things: Where do I start? Where do I stop? How much do I move each time? That gives initialization, condition, updation. Execution order is I → C → body → U → C → body → U ... (initialization runs only once).

    ⚡ Shortcut: variable declared inside for(int i...) exists only inside that loop.

    Nested loop

    • Writing a loop statement inside another loop statement is known as Nested loop
    For( initialization ; condition ; updation) ← outer loop { while ← Inner loop { } }

    ADDED: NESTED LOOP – Example 1 (star triangle)

    for (int i = 1; i <= 4; i++) { // outer = rows for (int j = 1; j <= i; j++) { // inner = stars in that row System.out.print("* "); } System.out.println(); // new line after each row } // * // * * // * * * // * * * *

    Example 2 (tables 1 to 3)

    for (int i = 1; i <= 3; i++) { for (int j = 1; j <= 5; j++) { System.out.print(i * j + "\t"); } System.out.println(); }

    🧠 Logic: Outer loop = rows (slow), inner loop = columns (fast). Like a clock: the minute hand (inner) completes a full round for every single move of the hour hand (outer). Total runs = outer times × inner times.

    ⚡ Trick for patterns: (1) count rows → outer loop, (2) what changes in each row (stars, spaces, numbers) → inner loop limit, (3) println() after the inner loop.

    For loopdo-while loop
    ① statement is executed once the condition is satisfied① condition is checked after the statement is executed.
    ② Minimum number of iteration of For loop is zero② Minimum number of iteration For do while loop is one
    ③ For loop is entry controlled③ do-while loop is exit controlled

    ADDED: Quick comparison of all loops

    LoopChecks conditionMin runsUse when
    forBefore (entry)0Count is known (1 to n)
    whileBefore (entry)0Count is unknown (digits, until found)
    do-whileAfter (exit)1Menu, retry, validation
    for-eachAutomatic0Read every element of array/list

    ⚡ Memory trick: for / while = "Front door check" (entry controlled), do-while = "Back door check" (exit controlled).

    FOR-EACH / enhanced for – Example

    int[] marks = {70, 85, 90}; for (int m : marks) { // read as: "for each m in marks" System.out.println(m); } String[] names = {"Ravi", "Anu"}; for (String s : names) System.out.println(s);

    ⚡ Trick: for-each has no index and no update. It is read-only style traversal. Need the index or want to change values? Use normal for.

    JUMPING statements inside loops – break and continue

    for (int i = 1; i <= 5; i++) { if (i == 3) continue; // skip only 3 → 1 2 4 5 System.out.print(i + " "); } for (int i = 1; i <= 5; i++) { if (i == 3) break; // stop loop completely → 1 2 System.out.print(i + " "); }

    ⚡ Trick: break = "Bye, leave the loop", continue = "Skip this round, go to next", return = "Leave the whole method".

    Dynamic Read

    • Reading the data from the end user while the application is under execution
    • The user enters data using the keyboard
    • A Java application cannot directly communicate with the keyboard
    • every operating system provides standard input and output files [stream] that act as intermediate betn the program and the input and output file

    System.in

    • System is the name of a built-in (predefind) class in java.lang package
    • In is a static variable of type Input stream present inside the System class
    • It represents the standard input stream, which is typically connected to the keyboard

    Scanner class

    • Scanner is a built in class in the java.util package
    • It provides non-static methods to read input dynamically from keyboard
    • when reading from the keyboard it takes input from System.in
    • The scanner object sends a request to the input stream (to System.in) fetches the data, converts it into the required data type (like int, double, String) and give it to the Java application

    Working Process

    • when the program is running, the Java application waits for the user to enter data
    • The Java application communicate with the standard input and output streams through System.in
    • The standard input stream waits for the user to type data using the keyboard
    • whatever data user enters is stored in the standard input file in binary form
    • The scanner class converts this binary form data into Java understandable types (like int, Float, String)

    ADDED: Easy picture to remember

    🧠 Keyboard → System.in (pipe) → Scanner (translator: raw data to int / String / double) → your variable.

    ⚡ Memory trick "I-O-R": Import the class → create Object → Request the data.

    Steps to read integer data from the end user

    step① import scanner class from java.util package

    import java.util.Scanner;

    step② create object of scanner class and initialize it with System.in

    Scanner sc = new Scanner(System.in);

    step③ request for the data from the user by calling methods.

    int x = sc.nextInt();

    Note

    • when the input format doesn't match the expected data type while reading user input using scanner we get InputMismatchException

    ADDED: Dynamic Read – Example 1 (add two numbers)

    import java.util.Scanner; public class Add { public static void main(String[] args) { Scanner sc = new Scanner(System.in); System.out.print("Enter two numbers: "); int a = sc.nextInt(); int b = sc.nextInt(); System.out.println("Sum = " + (a + b)); sc.close(); } }

    Example 2 (read different types)

    String name = sc.next(); // Ravi int age = sc.nextInt(); // 21 double marks = sc.nextDouble(); // 88.5 boolean pass = sc.nextBoolean(); // true

    Example 3 (Scanner + conditions: even / odd program)

    Scanner sc = new Scanner(System.in); System.out.print("Enter a number: "); int n = sc.nextInt(); if (n % 2 == 0) System.out.println("Even"); else System.out.println("Odd");

    Example 4 (Scanner + loop: sum of n numbers)

    System.out.print("How many numbers? "); int n = sc.nextInt(), sum = 0; for (int i = 1; i <= n; i++) { sum += sc.nextInt(); } System.out.println("Total = " + sum);

    ⚡ Trick: next() = one word, nextLine() = full sentence. Pick the method by data type: next + DataType (nextInt, nextDouble ...). There is no nextChar(); use sc.next().charAt(0).

    ⚠ Common trap: after nextInt(), a following nextLine() returns empty text, because the Enter key is left in the input. Fix: add one extra sc.nextLine(); to consume it.

    int age = sc.nextInt(); sc.nextLine(); // clear leftover Enter String line = sc.nextLine(); // now reads the full sentence
