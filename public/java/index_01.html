JRE

  • JRE is to provide enviroment or area where we can do execution of program
  • you can't develop, but you can run exiting program

JVM

  • It is used to convert the bytecode into machine code with the help of Interpreter and JIT compiler and executes the program
  • JVM uses both Interpreter and JIT
    • Interpreter executes bytecode line by line
    • JIT complies a frequently bytecode into machine code for faster execution

that's why JVM use both for optimal performance

JIT compiler

  • It is used to compile the frequently executed bytecode into machine code during the runtime
  • JIT overcomes the problem of Interpreter which is performance issue
  • Here JIT will store frequently used code in cache memory
  • every time compile code which is present in cache memory will get execute directly
  • the main Disadvantage is it uses extra memory for cache and also slight delay during compilation verify "slight"

Cache memory is a high speed memory used to stored frequently accessed data to reduce cpu access time.

Interpreter

  • It is part of JVM which is used to execute the Java bytecode line by line
  • Interpreter takes one bytecode at a time and converts into machine code and executes Immediatly

Simple one line flow

First run→JIT Identifies hot code→compile it next run are Faster←cpu cache speed it up←stores it

★ Commands in command prompt.

① Absolute path

  • The path which starts from a root folder and ends at a working folder is known as absolute path

C:\users\Leo

C: → Root Folder directory  |  \users\Leo → Working Folder directory

② Root Folder

  • It is a Folder or drive which indicates the starting point of absolute path
  • In a operating system it is possible to have multiple root folders based on no. of drives

③ Working Folder directory

  • It is a Folder where the absolute path ends
  • A Folder where currently the cursor or a control is present is know as working Folder.
