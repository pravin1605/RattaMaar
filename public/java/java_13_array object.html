Comparable Interface

  • comparable interface is used to sort the group of elements in Java
  • It is present in Java.lang package
  • It is functional interface
  • an interface having only one abstract method is known as functional interface
  • By default, sort method arrange elements in ascending order only, we call that as Natural order
  • In Java single value data can be automatically sorted in Natural order
  • In Java we have multi value data, like objects
  • since an object can contain multiple fields, Java needs to know which field to be compared for sorting to avoid confusion
  • in user-defined classes, we should specify the field to compare by using compareTo() which is present in comparable interface

Steps to use compareTo()

step-1   user defined class should implements comparable interface

step-2   override compareTo() abstract method and provide sorting logic on particular field in any order

# For ascending order

  • IF current object property is greter than passing object property, return positive value (+1)
  • IF current object property is less than passing object property, return negative value (-1)
  • If both objects are equal, return 0

# For descending order

  • IF current object property is greater than passing object property, return negative value (-1)
  • IF current object property is less than passing object property, return positive value (+1)
  • IF both objects are equal, return 0

  • Using comparable interface we can define only one sorting logic inside the class
  • We can not change sorting logic dynamically
  • which means when we want more than one sorting order we can not make use of comparable interface
  • Then we will be using comparator interface

Comparator Interface

  • comparator interface is used to sort the group of elements in Java.
  • It is present in Java.util package
  • It is used to sort the group of elements in any order without changing the blueprint
  • we can sort elements based on different fields
  • compare(object o1, object o2) method is responsible to sort the elements in comparator interface

Steps to use compare(object o1, object o2)

step-1   create a separate class for Field based on which we need to sort

step-2   that class should implements comparator interface and override the compar(obj o1, obj o2) and provide sorting logic on particular field in any order .

For ascending order

  • IF 1st object property is greater than 2nd object property, return positive value (+1)
  • IF 1st object property is less than 2nd passing object property return negative value (-1)
  • If both objects are equal return zero

For descending order

  • IF 1st object property is greater than 2nd object property, return negative value (-1)
  • IF 1st object property is less than 2nd object Property, return positive value (+1)
  • IF both objects are equal, return zero

Note

  • In comparator interface we have 2 abstract method one is compare(object o1, object o2) and other one is Boolean equals(object o)
  • But when we are inheriting comparator interface we need not provide implementation to the equals method.
  • since it has the same declaration as the equals method present in object class, And object class is the parent of all the classes and one class will first extends and then implements as we have seen in multiple inheritance
  • so we need not provide implementation to the equals method of comparator interface
  • By default object class equals method which is inherited First will act as implementation to the comparator interface equals method
  • Arrays.sort() method is overloaded in such a way that it accepts two Formal arguments, one argument is object[] and second argument is comparator.
  • so when we want to call this sort method we need to pass 2 actual values, one is address of the array and other one is comparator type object.
  • this sort method will internally use the compare(object, object) present in comparator type object and sorts the array elements.
