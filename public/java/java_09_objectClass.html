Object class

  • object class is defined in java.lang package
  • It is the root class or parent class for all the class created in Java either predefined class or user classes
  • object class can be immediate parent class or super class most parent class
  • As a programmer if are creating any parent class for the child class then object class will be super most parent class for that child class

① public string tostring()

  • The return type of this method is String
  • It is used to generate Address of an object in the String format
  • Whenever we are trying to print the reference variable or reference of any object internally tostring() method will be called.

★ String format address

PackageName.className@ Hexa Decimal

There can be multiple classes with same name in different package so to avoid the confusion they invented Fully qualified name.

★ Why to override tostring() ?

We can override tostring() method in such a way that if we print reference variable of an object, we can get the states of that object instead of the address
We use for write the Data of an address

Public class student { int id; string name; int age; Public student(int id, string name, int age) { this.id = id this.name = name this.age = age } Public string tostring() //overriding { return "id = " +id+" name = "+name+" age = "+age } } Public class Driver { Public static void main(string[] args) { student obj = new student(102, "Pravin", 21); S.O.P.l(obj) } }

By overriding tostring(), we print the actual object data (id, name, age) instead of default memory address.

② public boolean equals(object obj)

  • The return type of this method is Boolean
  • equals method compares the reference of the current object with the reference of the passed object
  • if both the reference are same it returns true else returns False

★ Syntax to call equals method

current_obj.equals(passed-obj);

current obj
an object using which we are calling the method
Passed object
an object which we are passing as a actual argument

★ Note

Since the formal argument is of object type we can pass any type of object to equals(object) method

★ Implementation in object class

Public boolean equals(object obj) { return (this == obj) }
  • equals (==) operator will compare the reference of an object.
  • equals() present in object class also will compare the reference of line cut off at page end

★ Can we override equals method?

Yes, it is possible to override the equals method

★ Why We need to override equals method ?

We can override equals() in any class to compare the states of an object instead of reference

Public class student { int id; string name; int age; Public student(int id, string name, int age) { this.id = id this.name = name this.age = age } Public boolean equals(object obj) { student s = (student) obj if (this.id != s.id) return False; IF(!(this.name.equals(s.name))) return False; IF(this.age != s.age) return False; return true; } } Public class Driver { Public static void main(string[] args) { student d1 = new student(101, "pravin", 21); student d2 = new student(101, "Pravin", 21); S.O.P.l(d1 == d2); //False → It compare address S.O.P.l(d1.equals(d2)); //True → It compare data of an address } }

③ public int hashcode()

  • the return type of hashcode() is int
  • hashcode() will be having access to the original object address in the memory
  • it will return unique integer value based on the object reference [original address]
Public class Demo { Public static void main(string[] args) { Demo d1 = new Demo(); S.O.P.l(d1.hashcode()); //a327324 verify digits } }

★ can we override hashcode() ?

Yes

★ why to override hashcode ?

We can override hashcode() to generate unique integer value based on the states of an object.

Public class student { int id; string name; int age; Public student(int id, string name, int age) { this.id = id ; this.name = name this.age = age } Public int hashcode() //overriding hashcode to generate integer based on data { return id; } } Public class Driver { Public static void main(string[] args) { student obj = new student(101, "pravin", 21); S.O.P.l(obj.hashcode()); //101 } }
  • The program demonstrates overriding the hashCode() method in Java
  • The student class returns the id as the custom hash value instead of the Default memory-based hash
  • It shows how an object can be identified using data rather than memory address
  • hashcode() is mainly used for Fast searching and storage in hash-based collections
  • In real application, hashCode() is usually overridden along with equals()

Note

  • Java doesn't provide original address of an object, instead it will print String format address whenever we print the reference variable by calling tostring() implicitly, which internally uses hashcode().
