Access Modifiers

  • Access modifiers are keywords in Java that control the visibility or accessibillity of class member (fields, method, constructor) and classes themselves
  • they determine, from where in your code, you can access these element
  • In Java language, there are four access modifier
    • ① private
    • ② default (Not keyword)
    • ③ protected
    • ④ public

① Private

  • Any member declared with private keyword will have the private access level
  • the private members are restricted upto the class
  • the private members are permitted to access in the same class body where it is declared
  • the private members cannot be accessed outside the class body
  • the private keyword can be used in the declaration of variable, method, constructor and nested class
  • the private access modifier gives very good security
  • private can not be used for outer class

② Default

  • IF any member doesn't have access modifier, it will have default level access
  • the member which have default level access can be accessed in the same class as well as from other class belonging to the same package
  • It cannot accessed outside the package
  • Hence, it is also known as package level access

③ Protected

  • Any member declared by using protected keyword will have protected level access
  • the protected members are similar to default access member
  • protected members can be accessed from any class belonging to the same package
  • It can be accessed outside the package by using inheritance
  • the protected keyword can be used in the declaration of variables, method, constructor and nested class

④ Public

  • Any member declared using public keyword will have public level access
  • the public members doesn't have any restriction and it can be accessed from anywhere
  • the public keyword can be used declaration of variable, method, constructor and class
