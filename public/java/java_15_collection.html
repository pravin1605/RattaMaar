Java - 15 Collection

Collection

  • To store multiple data we made use of arrays till date, But array has some limitation
    • size of array is Fixed
    • It can store only homogenous data
    • there are no built in methods inside array

To overcome all this disadvantages of array we move to collection framework

  • Representing a group of objects as a single entity is known as collection
  • It's main purpose is to store huge amount of data
  • easy to maintain and manage the objects inside the collection

Collection framework

  • It is a set of predefined interfaces, implementation classes and utility classes
  • All the classes and interface of collection framework are present in Java.util package
  • The collection framework contains implementation of standard data structure like stack, queue, linkedlist, Hashmap
  • collection framework mainly contain 2 hierarchies ① collection hierarchy ② Map hierarchy

Collection interface

  • this interface is a root of collection interface Hierarchy
  • The collection interface defines the standard essential operations, that can be performed on any type of collection
  • It is a child interface of iterable interface
  • collection interface has 3 child interface ① List ② Queue ③ Set.

Methods of collection interface

Ⓔ To ADD Elements.

① boolean add(object element)
↳ ADDS a single element to the collection
↳ Return true if the element is successfully addcut off

② boolean addAll(collection c)
↳ ADDS all element from another collection into the current collection
↳ Return true if the elements are added successfullcut off

To Remove elements

③ boolean remove(object element)
↳ Remove a specific element from the collection
↳ Return true if the element is removed

④ boolean removeAll(collection c)
↳ Remove all elements that exist in another collection
↳ IF two lists contain common element, those elements will be removed

⑤ boolean retainAll(collection c)
↳ Keeps only the elements that are also present in another collection
↳ Removes all other elements

To Search Elements

⑦ boolean contains(object element)
↳ Checks whether the given element exist in the collection
↳ Return true or False

⑧ boolean containsAll(collection c)
↳ checks whether all elements of another collection exist in the current collection

⑥ void clear()
↳ Removes all elements from the collection
↳ the collection becomes empty verify numbering (clear is written ⑥ after containsAll)

To Access elements

⑨ public Iterator iterator()

Other methods

⑩ int size()
↳ Return the total number of elements present in the collection

⑪ boolean isEmpty()
↳ checks whether the collection is empty or not
↳ return true if no elements are present

⑫ object[] toArray()
↳ convert the collection into an array

  • When we are printing the reference variable tostring() will be called, since inside Arraylist class tostring() is overridden we will get the data stored inside the arraylist
  • Inside arraylist the actual data stored is address of Integer object, so output should actually be the address of integer object, but we will not get address of Integer object
  • since tostring() is overridden inside Integer class also
