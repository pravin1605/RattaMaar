Java - 11 Wrapper Class

Wrapper class

  • A wrapper class in Java is a predefined class that converts a primitive data type into an object
  • In simple words, wrapper classes wrap (convert) primitive values into objects so that they can be used where objects are required
  • In order to represent primitive datatype as an object we use wrapper classes
  • For every primitive data type, there is a corresponding wrapper class available in Java
  • Java is not 100% object oriented because of Primitive data types, to make Java 100% object oriented we use wrapper
  • therefore to represent primitive datatype as object we use wrapper classes

① Boxing

  • The process of converting primitive type into non-primitive using built-in methods is called as Boxing
  • Boxing can be performed by using valueOf()

syntax

Wrapper_class_name.valueOf(Primitive Data/variable)

ex ① Integer.valueOf(10) ② Character.valueOf('a') ③ Boolean.valueOf(true)

  • valueOf() is static method which is present in every wrapper class

② UnBoxing

  • The process of converting non-primitive [wrapper] into primitive type by using built-in methods is called as unBoxing
  • UnBoxing can be performed by using following method

syntax

xxxValue() (xxx → primitive data type)

ex   For int → intValue();   For byte → byteValue

Public class unBoxing { Public static void main(string[] args) { Integer i = 10; int x = i.intValue(); S.O.P.l(x); //10 character c = 'a'; char c1 = c.charValue(); S.O.P.l(c1); //a Boolean b = true; boolean b1 = b.booleanValue(); S.O.P.l(b1) //true } }

③ Auto Boxing

  • The process of converting primitive type into non-Primitive [wrapper class] without using built-in methods is called as Auto Boxing.
  • auto Boxing is possible from Java 1.5 version onwards

syntax

Wrapper_class objectName = PrimitiveValue

Because of autoBoxing, the compiler internally convert it to

wrapper_class objectName = wrapper_class.valueOf(Primite value)

Public class AutoBoxing { Public static void main(string[] args) { Integer i = 10 S.O.P.l(i) } }

Diagram: i = 0x1 → Integer object 0x1 (val 10, valueOf()).

④ Auto UnBoxing

  • The process of converting non-primitive type without using built in methods is known as auto unBoxing
  • this is also possible from Java 1.5 version

syntax

PrimitiveType Variable_Name = wrapperObject.

Internally, the compiler convert it to

Primitivetype Variable_name = wrapperobject.primitiveValue();

Public class Auto-unBoxing { Public static void main(string[] args) { Integer i = 10 int x = i S.O.P.l(x) } }
Public class equals-method-01 { Public static void main(string[] args) { Integer i1 = 400; // auto Boxing Integer i2 = 400; // auto Boxing // comparing address S.O.P.l(i1 == i2); // False // comparing actual value S.O.P.l(i1.equals(i2)); // true } }
  • When we use == to compare two wrapper class objects it compares the address of the two wrapper class objects
  • IF we want to compare based on data we need to make use of equals() method
  • equals() method of object class is overridden inside all the wrapper class
Public class equals-method-02 { Public static void main(string[] args) { Integer i1 = 120; Integer i2 = 120; S.O.P.l(i1 == i2) // true } }
  • When we are creating two wrapper classes object and the value are same with in the range of byte i.e -128 to +127 then duplicates objects will not be created, instead address of existing object will be returned, in the above example i1 and i2 are pointing to same address
  • In all the wrapper classes hashCode of object class is overridden in such a way that it returns int value which is generated based on the data instead of original address of the object
Integer i = 30 S.O.P.l(i.hashCode()); //30

Parsing

  • The process of converting string to any wrapper class type, or primitive type is known as parsing
  • It is widely used in user input, file handling, API response and data validation
  • Without parsing performing arithmetic, logical operation or proper data processing is not possible

syntax

PrimitiveType variable = wrapperclass.parsexxx(string s)

xxx → primitive data type

string s = "123" int x = Integer.parseInt(s) S.O.P.l(x) Public class Demo { Public static void main(string[] args) { string s = "True" boolean b1 = Boolean.parseBoolean(s) S.O.P.l(b1) // True Boolean b2 = Boolean.parseBoolean(s) S.O.P.l(b2) // True } }

parsexxx()

  • It is a method of wrapper class, it converts the string data into int, double or Float
  • But will work only, IF string holds data properly i.e Numbers otherwise we will get NumberformatException
string s = "123abc" int x = Integer.parseInt(s) //CTE verify: this fails at run time, not compile time O/P Exception in thread 'main' java.lang.NumberFormatException

Note

  • We Don't have any parsechar() method in character class because string is group of character and char means it can have only one character.
  • Group of character can not be converted into one single character
  • Instead we make use of string class charAt(int i) method to convert string into a char
