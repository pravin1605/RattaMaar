Java - 20 Vector and Stack

Vector class

  • It is a child class of list present in Java.util package
  • It is a Legacy class (created in 1.0 V)
  • collection Framework is introduced in 1.2 V
  • Internal implementation : Arrays

characteristics

① Initial capacity is 10

② New capacity = old capacity * 2

③ We can store duplicates

④ Insertion order is preserved

⑤ We can store multiple null

⑥ zero based indexing

⑦ Stores homogeneous and heterogeneous data

⑧ vector is thread safe, in vector methods are synchronized

constructor

① Vector()
② Vector(collection c)
③ Vector(int initial capacity)

Note

  • vector is old Version and Arraylist is the new Version
    since the vector is thread safe it will take more time to execute multiple tasks (less efficiency)

Stack class

  • It is a child class of Vector present in Java.util package
  • It is Legacy class (created in 1.0 V (collection Framework is introduced in 1.2 V))
  • Internal implementation : Arrays

characteristics

① Initial capacity is 10

② New Capacity = old capacity * 2

③ LIFO structure (Last-in-First-out)

④ Insertion order is preserved

⑤ We can store duplicates

⑥ We can store multiple null

⑦ zero based indexing

⑧ stores homogeneous and heterogeneous data

⑨ stack is thread safe.
↳ Extends vector
↳ In vector methods are synchronized

constructors

stack() ---> created empty stack with initial capacity 10

Extra Methods in stack

① E push(E item)
add the element onto the top of the stack

② E pop()
remove the element at the top of the stack

③ E peek()
returns the top element

④ int search(object o)
return the position of the element From the top (1 based position)

⑤ Boolean empty()
checks the stack is empty or not

Note

stack<Integer> s = new stack<Integer>(); s.add(100); s.push(200) S.O.P.l(s) [100, 200]
  • Here add() and push() will work same
  • Even though add() works, it's not recommended to use it with stack

why ?
- add() breaks the LIFO principle of stack
- Always use push() to maintain stack discipline
- so it is highly recommended to use only stack class method to achieve the behaviour of stack data structure
