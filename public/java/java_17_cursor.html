Enhanced For-Each Loop

  • Java introduced the enhanced For loop (for-each) to make iteration simpler and cleaner

syntax

For(dataType variable : array | collection) { //use variable }
Public class DemoForeachInt { Public static void main(string[] args) { int[] arr = {20, 30, 40, 50} For(int x : arr) { S.O.P.l(x) } } } O/P 20 30 40 50

In the above example, For the First iteration inside variable x, First element inside array will be store

Iterationvalue of x
1st20
2nd30
3rd40
4th50

Number of iteration depends on number of elements inside the array or collection

the data type of that variable should be same as the value stored inside the array or collection

Public class DemoForEach { Public static void main(string[] args) { Arraylist al = new Arraylist() al.add(10) al.add(20) al.add(30) al.add(40) al.add(50) For(object o : al) { S.O.P.l(o) } } } O/P 10 20 30 40 50

In the above example the variable type is object in Foreach loop because arraylist internally creates array of object
and whatever data we enter will be upcasted into object type

Cursors

  • this is the special characteristics given For collection concepts
  • using cursors we can retrieve the objects in Collection one by one
  • they are of 2 types ① Iterator   ② ListIterator

Iterator

  • Iterator is an interface which is used to traverse the list in forward direction
  • Basically it provides the priviledge to access the objects without using index
interface Iterator { Public boolean hasNext(); public object next(); public void remove(); }
interface Iterable { Iterator iterator() } class unknown implements Iterator { }
the arrows in the scan connect Iterable's iterator() to the Iterator interface and the unknown class

Methods of Iterator interface

① public object next()
↳ This method moves the cursor into next element in the collection and return reference of that element
↳ IF the collection doesn't have next element, it throws NoSuchElementException

② public boolean hasNext()
↳ This method returns true if collection has next element otherwise it, returns False

③ public object remove() written "object" (circled) in the method list, "void" in the interface above
↳ The method removes the elements from the collection where cursor is pointed

Public class Demo { Public static void main(string[] args) { Arraylist al = new Arraylist() al.add(10) al.add(20) al.add(30) al.add(40) al.add(50) Iterator i = al.iterator(); while(i.hasNext()) { S.O.P.l(i.next()) } } } O/P 10 20 30 40 50

In the above example when we call al.iterator(), this method internally creates and object of Iterator type and return the address.
that object will be internally having a cursor initally pointing to just before the First element inside the collection

  • When we call i.next(), next method will return the next element and moves the cursor one step Forward
  • if we keep calling next() it keeps moving cursor one step Forward
    Like this we are calling the next() multiple times once the cursor reaches the last element and still if we call next method we get NoSuch Element Exception

Note

  • Using iterator we can go in only Forward direction
  • we can use it only once, which means it is exhaustive

2. ListIterator

  • ListIterator is an interface which provides the Facility to traverse the list in Forward as well as backward direction
interface List { ListIterator listIterator(); }
interface ListIterator { Public boolean hasNext() Public object next() Public void remove() Public boolean hasPrevious() Public object previous() Public void add(object o) }
class unknown implements ListIterator { }

① hasPrevious()
↳ Returns true, if object is available in the previous index

② previous()
↳ move the cursor to next object in previous direction and return that object

Public class DemoListIterator { Public static void main(string[] args) { Arraylist al = new Arraylist(); al.add(10) al.add(20) al.add(30) al.add(40) al.add(50) //traverse in Forward direction ListIterator li = al.listIterator() while(li.hasnext()) { S.O.P.l(li.next()); } //Reverse order while(li.hasprevious) written without () { S.O.P.l(li.previous()); } //another approach ListIterator li-1 = al.listIterator(al.size()) while(li-1.has previous) written without () { S.O.P.l(li-1.previous()) } } } 10 20 30 40 50 50 40 30 20 10
  • when we want to traverse in reverse direction we need to call the ListIterator(int index) method which is accepting an index.
  • when we call this method internally it create and object of ListIterator type and a cursor will be pointing to the index which are passing when we call the method
  • so when we are calling we need to pass the last index, In order to traverse in reverse direction
