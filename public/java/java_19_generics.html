class Demo { int x }

Diagram: new Demo (three times) creates three objects 0x1, 0x2, 0x3, each with x = 0 of type int.

In this above example no matter how many objects we create inside all the objects data type of x will remain int itself

class Demo <T> { T x; }
Object createdObjectType of x
new Demo()0x1 : x = nullx is object type
new Demo<string>()0x2 : x = nullx is string type
new Demo<Integer>()0x3 : x = 0x is Integer type
new Demo<student>()0x4 : x = nullx is student type
  • IF we are using generic class we can decide the type of x dynamically For each and every Demo object
  • We can specify the type of x using type parameter '<Nonprimitive Datatype>'
  • In the class Declaration we have <T>, this T acts as a non primitive Data type, when we are creating the object we can decide what should be the type of T
    IF we are not specifying any thing T is considered as object type

T should be only non primitive type, we can not give primitive types

How to give the type of T during object creation ?

New Demo < Non primitive Datatype > ();

We can also specify the same during reference variable creation

Demo < Non primitive datatype > d ;

Generics

  • since collections are not type safe i.e programmer can add types of objects there is no restriction For that so, to overcome this drawback Java has given Generics concept where you can create an object of specific type, if we add any other type of object than specified we will get CTE
① Arraylist <Integer> al = new Arraylist <>(); al.add("Java"); //CTE al.add(100); al.add('A'); //CTE ② Arraylist <string> al = new Arraylist<>(); al.add("Java"); al.add(100); //CTE al.add('A'); //CTE ③ Arraylist <character> al = new Arraylist <>(); al.add("Java"); //CTE al.add(100); //CTE al.add('A');

We can also avoid downcasting everytime when we fetch element from the collection

Public class Program-01 { Public static void main(string[] args) { //Without generics Arraylist al = new Arraylist(); al.add(new Employee()); al.add(new Employee()); al.add("hello"); //we have to perform downcasting Employee e = (Employee) al.get(0) //With Generics Arraylist <Employee> al2 = new Arraylist (); al2.add(new Employee()) al2.add("hello"); //CTE Employee e2 = al2.get(0) //return type will be employee //Need Not downcast } }

why generics important Here

  • prevents wrong data insertion
  • Avoids manual casting
  • Avoids runtime error
  • Ensures type safety at compile time
