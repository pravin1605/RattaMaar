Java - 04 Method

Method

  • It is a block of instructions which is used to perform a specific task.

syntax

[modifiers] return_type name([Formal arguments]) { Instructions/statements [return [value/expression];] }
  • modifiers = optional  |  Formal arguments = optional
  • [modifiers] return_type name([Formal arguments]) = Method Declaration (the name and formal arguments = method signature)
  • { Instructions/statements } = Method body  |  whole thing together = Method Definition
  • return [value/expression]; → Its depends on return-type

★ Formal arguments are a local variable

  • In this syntax of method modifiers, formal arguments and return statement are optional

Important Terminology

① Method signature

  The method name and formal arguments together are called as method signature

② Method Declaration

  The modifiers, return_type and method signature together are called as method declaration

③ Method Definition

  The method declaration and block/body together are called as method Definition

Question

① where to create a method?
  We can create a method only inside a class block

② How many methods can we create inside a class?
  We can create infinite number of methods inside a class

③ can we create a method inside another method?
  No, we can't

Modifiers

  • Modifiers are special keywords that are used to define the accessibility and behavior of classes, methods, variable and constructor.
  • They tell the Java compiler
    • Who can access a class, method or variable
    • How it should behave during program execution
  • Modifiers help in implementing important concepts like encapsulation, inheritance
  • Behaviour means characteristics of class members

To call a method

  • method signature or method call statement is used to call a method

syntax

method_name([actual arguments, ...]);

actual arguments = optional

  • Here the actual arguments are optional.
public class program { public static void demo() → called } user defined method { System.out.println("Hello"); } public static void main(String[] args) → caller } Main method { System.out.println("Main start"); demo(); System.out.println("Main end"); } }

what happen when a method is called

① Execution of current method is paused

② control is transferred from caller to the called method

③ Execution of called method starts from beginning

④ once the execution is completed, control returns to the caller

⑤ execution of caller resumes

Note

  • Whenever a caller calls a method a block of memory is formed for the particular method and the instructcut off inside the method gets executed
  • once completing the execution, the memory created forcut off the particular methods gets destroyed.

No-Argument Method

  • Method declared without formal arguments is known as NO-Argument method

syntax

modifiers return_type name() { }

Advantages

① Easy to use - No need to pass values, you just call the method

② simple and clean code

③ Useful for fixed operation - best task. Does not depend on user input

④ Better readability

⑤ Less chance of wrong input - since no values are passed, input-related errors are avoided

Disadvantage

① caller of the method cannot pass data to the method

② Less flexible

③ Limited reusability

④ Often depends on global or instance data

public class No-Arg-method { public static void add() // No Formal Argument { int a = 10; int b = 20; System.out.println(a+b); } public static void main(String[] args) { add(); //call without Actual values add(20,40); //CTE } }

Parameterized Method

  • Method which is having formal arguments is called as Parameterized method

syntax

modifiers return_type name(datatype V1, datatype VN) { }
  • V1 and VN are Formal arguments
  • we can pass N Number of Formal arguments.

Advantage

① caller can pass the data

② Better reusability - No need to write multiple method for similar tasks

③ Dynamic behavior - output change based on input values

④ More Flexible - same method work with different values

Disadvantage

① caller cannot call a Parameterized method without passing data

② Wrong input can cause error - passing wrong data type

Rules to use parameterized method

① Parameters must be declared with data type

void add(int a, int b, String name)

② The number of formal and actual arguments should be same

demo(int a) add(10, 20) //CTE add(10) //CTS verify: CTS/CTE add() //CTE

③ The datatype of corresponding actual and formal argument should be same

add(int a, int b) add(10, "20") //CTE add(10, 20) //correct

④ Parameter names must be unique

void add(int a, int a) //error

⑤ Parameter are local to the method

⑥ IF method is non-static, object is required

Demo d = new Demo(); d.add(10,20)

⑦ IF method is static, no object creation required. It can be called using the class name

Demo.add(10,20)
public class program { public static void demo(int a) { } public static void main(String[] args) { demo() //CTE demo(20) demo('a') demo(10.01) //CTE verify: scan reads "1001" } }

To design a method which can return value to the caller

  • A method will return data when we mention the return type other than void
  • A method will return the value when we use the primitive and Non-primitive datatypes
  • When a method return a primitive type, it return the actual value.
    When it returns a non-primitive type, it return a reference to the object

A reference in Java is a variable that refers to an object in memory and is used to access that object.

step 1. provide the return type

step 2. Use return statement with value or expression

public static int add(int a, int b) { int res = a+b; return res; } public static void main(String[] args) { add(10,20); }
  • In the above program we understood that the method will return data to caller
  • But the drawback is that we are not consuming it, so it is of waste
  • so, in order to consume the data, we have to store it in any variable
  • or also we can use method call statement as an expression when it returns any type of data other than void
  • Redesigned main method
public static void main(String[] args) { int res = add(10,20) System.out.println(res); OR System.out.println(add(10,20)); }

Return statement

  • It is a keyword
  • It is a control transfer statement that means it stop the execution of current method and transfer the control back to the caller

syntax

return [value, variable, expression];

Rules to use return

① Return statement is mandatory if return type of the method is anything other than void

public static int demo() { } ------> CTE

② IF the return type is void, return statement is optional

public static void demo() { }
public static void demo() { return; → CTS verify: CTS/CTE } ↳ used to exit directly
public static void demo() { return 10; → CTE }

③ Return statement in Java, can return only one value.

public static int demo() { return 10,20; → CTE }
public static int demo() { return 10; return 20; → CTE //unreachable code }

Method overloading

  • The process of creating more than one method in a class with same name but different formal arguments is known as Method overloading

Rules for method overloading

① Name of the methods should be same

② Different number of Formal Arguments

③ By changing the data type

④ By changing the sequence of order

⑤ Modifiers and return type can be same or different

public class Method_overloading { public static void test(int i) { } public static byte test(byte b) { return 10; } public static void test(int a, int b) { } public void test(short a) //Non-static Method { //CTS } }

Compile Time Binding

  • The process of Binding method call statement with method definition at the compile time by the compiler by looking at the actual and formal arguments is known as compile Time Binding
  • This binding is done by the compiler by examining the method name, number of parameters, order of parameter and data types of actual and formal arguments
  • In compile-time binding, the decision of which method to call is made before the program is executed, so the method call is fixed at compile time
  • the compiler will always bind the method with same signature
  • IF there is no method with same signature means then the compiler tries for type promotion
  • ★ Type promotion is the automatic conversion of a lower range data type into a higher range data type during an operation or expression
    • Why Needed
    • To avoid data loss
    • To maintain accuracy in calculation
    • To standardize operation betn different data types
  • If it is also not possible means then the compiler throws an error.
Public class Method-overloading { public static int add(int a, int b) { return a+b; } public static int add(int a, int b, int c) { return a+b+c; } public static void main(String[] args) { System.out.println(add(10,45)); System.out.println(add(10,20,30)); } }

output

55 50 verify: add(10,20,30) = 60
