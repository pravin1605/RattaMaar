Maven manages dependencies automatically via pom.xml. We will add the Spring dependency next.

Step 2 — Add Spring Context Dependency (pom.xml)
<dependencies>
  <dependency>
    <groupId>org.springframework</groupId>
    <artifactId>spring-context</artifactId>
    <version>5.3.20</version>
  </dependency>
</dependencies>
💡 Why spring-context Dependency?

This dependency provides: ApplicationContext, BeanFactory, IoC Container, Dependency Injection, and all Spring Core Features. Without this dependency, Spring cannot create or manage objects.

Step 3 — Create POJO Class (Student.java)
📖 What is POJO?

POJO = Plain Old Java Object. A simple Java class with fields, getters, setters, and a no-arg constructor. This is the class whose object will be managed by Spring IoC Container.

package com.j2ee;

public class Student {

    private int id;
    private String name;
    private int age;
    private String address;

    public Student() {
        System.out.println("Student Object Created");
        // Spring calls this constructor to create the bean
    }

    // Getters and Setters for all fields...
    // (id, name, age, address)

    @Override
    public String toString() {
        return "Student [id=" + id +
               ", name=" + name +
               ", age=" + age +
               ", address=" + address + "]";
    }
}
🧠 Why No-Arg Constructor?

Spring uses the no-arg (default) constructor to create the bean object. If you don't provide one and have a parameterized constructor, Spring will throw an error during bean creation.

Step 4 — Create XML Configuration File (myconfig.xml)
📁 File Location

Create myconfig.xml inside src/main/java folder.

<?xml version="1.0" encoding="UTF-8"?>

<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xsi:schemaLocation="http://www.springframework.org/schema/beans
       http://www.springframework.org/schema/beans/spring-beans.xsd">

    <bean id="student"
          class="com.j2ee.Student">
    </bean>

</beans>
Understanding the Bean Tag
AttributeValueMeaning
idstudentUnique name of the bean. Used while retrieving object with getBean().
classcom.j2ee.StudentFully qualified class name. Spring uses this class to create the object via reflection.
⚙️ What Happens Internally When Spring Reads the Bean Tag
1
Spring reads <bean id="student" class="com.j2ee.Student">
2
Creates the Student object using its no-arg constructor
3
Stores it in the IoC Container with name = student
4
Manages its full lifecycle (init → use → destroy)
Step 5 — Create Driver Class (Driver.java)
package com.j2ee;

import org.springframework.context.ApplicationContext;
import org.springframework.context.support.ClassPathXmlApplicationContext;

public class Driver {

    public static void main(String[] args) {

        // Step 1: Create IoC Container — reads XML, creates all beans
        ApplicationContext context =
            new ClassPathXmlApplicationContext("myconfig.xml");

        // Step 2: Retrieve bean from container by id
        Student student = (Student) context.getBean("student");

        // Step 3: Use the object
        System.out.println(student);
    }
}
📤 Output
Student Object Created
Student [id=0, name=null, age=0, address=null]
Driver Class — Line by Line Explanation
LineWhat Happens
new ClassPathXmlApplicationContext("myconfig.xml")Spring Container starts → reads myconfig.xml → finds bean definitions → creates Student object → stores it
context.getBean("student")Retrieves the bean from IoC Container whose id = "student". Spring returns the managed object.
System.out.println(student)Calls toString() on Student. Values are null/0 because no values were injected yet.
❓ Why Are Values Null?

Currently the bean tag only creates the object. No values are injected. That is why id=0, name=null, age=0, address=null. DI (value injection) comes in the next step.

Where is Dependency Injection (DI)?
⚠️ Currently — Only Bean Creation
<bean id="student"
      class="com.j2ee.Student">
</bean>
// No values injected!
✅ With DI — Values Injected
<bean id="student"
      class="com.j2ee.Student">
  <property name="id" value="101"/>
  <property name="name" value="Pravin"/>
  <property name="age" value="22"/>
  <property name="address" value="Mumbai"/>
</bean>
📤 Output After DI
Student Object Created
Student [id=101, name=Pravin, age=22, address=Mumbai]
💡 DI = Object Creation + Value Injection

When Spring not only creates the object but also sets its field values through <property> tags — that is Dependency Injection.

Without Spring vs With Spring
❌ Without Spring
Student s = new Student();
// Developer manually creates
// Developer manages lifecycle
// Developer handles dependencies
✅ With Spring
context.getBean("student");
// Spring creates object
// Spring manages lifecycle
// Spring injects dependencies

Final Interview Answer
🎤 Expected Interview Answer

In a Spring Core XML-based project, we first create a Maven project and add the spring-context dependency. Then we create a POJO class such as Student with fields, getters, setters, and a no-arg constructor. Next, we create an XML configuration file (myconfig.xml) and define a bean using the <bean> tag with id (unique name) and class (fully qualified class name). In the Driver class, we create an IoC Container using ClassPathXmlApplicationContext, which reads the XML file, creates the Student object, manages its lifecycle, and stores it as a bean. The bean is then accessed using context.getBean("student"). If we add <property> tags inside the bean definition, Spring also performs Dependency Injection by setting field values automatically.

🧠 Steps to Remember

Maven Project → Dependency (spring-context) → POJO Class → XML Config (myconfig.xml) → Driver Class (getBean())
