Performance Optimization  •  Memoization  •  Cached Calculations

What is useMemo?

🤔 Definition

useMemo is a built-in React Hook used to memoize (cache) expensive calculations and improve application performance. It prevents unnecessary recalculations when a component re-renders.

Definition → useMemo is a React Hook that memorizes the result of a computation and recomputes it only when its dependencies change.

Remember this interview keyword 🎯

"Cache Expensive Calculations"

💡
Why Do We Need useMemo?

❌ Problem — Without useMemo

On every re-render, all code runs again — including expensive calculations — even if nothing related changed!

Component Re-renders
↓
All Code Executes Again
↓
Heavy Calculation Runs Again ❌ Waste!

🏢 Real-Life Scenario

Employee Dashboard with 10,000 records → Calculate Total Salary.
An unrelated button is clicked → Component re-renders → Salary recalculated unnecessarily! ❌

✅ Solution — With useMemo

Calculation Done Once
↓
Result Stored (Cached)
↓
Reuse Stored Result ✅ Fast!
📌
Syntax & How It Works

Syntax

const memoizedValue = useMemo(
  () => {
    return calculation;   // expensive work here
  },
  [dependencies]        // recalculate when these change
);

📐 Syntax Breakdown

Callback Function () => {'{ }'} — contains the expensive calculation
Dependency Array [num1, num2] — determines when to recalculate

Flow of useMemo

Component Renders
↓
Dependencies Changed?
↓
✅ YES
Recalculate Value
↓
Store & Return Result
❌ NO
Use Previous Cached Result
📝
Examples

Example 1 – Without useMemo ❌

import { useState } from "react";

function App() {
  const [count, setCount] = useState(0);

  const square = () => {
    console.log("Calculating..."); // runs on every render!
    return count * count;
  };

  return (
    <>
      <h1>Count: {count}</h1>
      <h2>Square: {square()}</h2>
      <button onClick={() => setCount(count + 1)}>Increment</button>
    </>
  );
}
// Problem: "Calculating..." prints on EVERY re-render ❌

Example 2 – With useMemo ✅

import { useMemo, useState } from "react";

function App() {
  const [count, setCount] = useState(0);

  const square = useMemo(() => {
    console.log("Calculating..."); // only runs when count changes!
    return count * count;
  }, [count]);

  return (
    <>
      <h1>{count}</h1>
      <h2>{square}</h2>  // use directly — it's a value, not function
      <button onClick={() => setCount(count + 1)}>Increment</button>
    </>
  );
}
// "Calculating..." ONLY prints when count changes ✅

Example 3 – Performance Optimization (Heavy Calculation)

import React, { useState, useMemo } from "react";

function App() {
  const [count, setCount] = useState(0);
  const [name,  setName]  = useState("");

  const expensiveCalc = useMemo(() => {
    console.log("Heavy Calculation Running...");
    let total = 0;
    for (let i = 0; i < 100000000; i++) total += i;
    return total;
  }, [count]); // only recalculates when count changes

  return (
    <>
      <input value={name} onChange={(e) => setName(e.target.value)} />
      <button onClick={() => setCount(count + 1)}>Increment</button>
      <h2>{expensiveCalc}</h2>
    </>
  );
}

⌨️ Typing in Input

name changes → re-render → Heavy Calc NOT executed (count didn't change)

🖱️ Clicking Increment

count changes → dependency changed → Heavy Calc runs ✅

  return employees.reduce((sum, emp) => sum + emp.salary, 0);
}, [employees]);

// 2. Product Filtering
const filteredProducts = useMemo(() => {
  return products.filter(p => p.price > 1000);
}, [products]);

// 3. Sorting Users
const sortedUsers = useMemo(() => {
  return [...users].sort();
}, [users]);

Dependency Array Cases

// Empty array → runs ONLY ONCE (on mount)
useMemo(() => calculation, []);

// With dependency → runs when count changes
useMemo(() => calculation, [count]);

Interview Questions

Common Interview Q&A

Q: What is useMemo?

A: A React Hook used to cache the result of expensive calculations and recompute them only when dependencies change.

Q: Why is useMemo used?

A: To improve performance by avoiding unnecessary recalculations during component re-renders.

Q: What does useMemo return?

A: A memoized (cached) value. Example: const result = useMemo(() => count * count, [count]);

Q: Does useMemo improve performance?

A: Yes. It prevents expensive calculations from running unnecessarily and improves application performance.

Q: When should we use useMemo?

A: When performing expensive calculations, filtering large datasets, sorting data, or optimizing performance.
