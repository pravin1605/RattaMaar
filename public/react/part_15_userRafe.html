DOM Access  •  Mutable Values  •  No Re-render

What is useRef?

🤔 Definition

useRef is a built-in React Hook that allows us to create a reference to DOM elements and store mutable values without causing re-renders.

Definition → useRef is a React Hook used to directly access DOM elements and store values that persist across renders without triggering re-rendering.

Import & Syntax

import { useRef } from "react";

// Syntax
const refName = useRef(initialValue);

// Example
const inputRef = useRef();
💡
Why Do We Need useRef?

🔄 Normally with useState

Every state change → component re-renders. Sometimes we don't want that!

useState → Re-renders every time
VS
useRef → No re-render ✅

Examples

Example 1 – Access Input Value

import { useRef } from "react";

function App() {
  const inputRef = useRef();

  const showData = () => {
    alert(inputRef.current.value); // gets input value
  };

  return (
    <>
      <input type="text" ref={inputRef} />
      <button onClick={showData}>Show</button>
    </>
  );
}
// User types "Pravin" → Click Show → Alert: Pravin

Example 2 – Focus Input Field

function App() {
  const inputRef = useRef();

  const focusInput = () => {
    inputRef.current.focus(); // moves cursor to input
  };

  return (
    <>
      <input type="text" ref={inputRef} />
      <button onClick={focusInput}>Focus</button>
    </>
  );
}
// Click button → cursor jumps into input ✅

Example 3 – Change Background Color

function App() {
  const inputRef = useRef();

  const changeColor = () => {
    inputRef.current.style.backgroundColor = "yellow"; // direct DOM style
  };

  return (
    <>
      <input type="text" ref={inputRef} />
      <button onClick={changeColor}>Change Color</button>
    </>
  );
}
// Click → input background turns yellow 🟡

Example 4 – Counter Without Re-render

function App() {
  const countRef = useRef(0);

  const increase = () => {
    countRef.current++;                    // updates value
    console.log(countRef.current);        // prints in console
    // NO re-render happens! UI stays same.
  };

  return <button onClick={increase}>Increment</button>;
}

⚠️ Why useRef Instead of a Variable?

Normal variable → resets on every re-render
useRef → value persists across re-renders without causing them

Example 5 – Timer Control

function App() {
  const timerRef = useRef();

  const startTimer = () => {
    timerRef.current = setInterval(() => {
      console.log("Running...");
    }, 1000);
  };

  const stopTimer = () => {
    clearInterval(timerRef.current); // stops the timer
  };

  return (
    <>
      <button onClick={startTimer}>Start</button>
      <button onClick={stopTimer}>Stop</button>
    </>
  );
}

Interview Questions

Common Interview Q&A

Q: What is useRef?

A: A React Hook to create references to DOM elements and store mutable values without causing component re-renders.

Q: Why is useRef used?

A: For DOM manipulation, focusing input fields, storing mutable values, and working with uncontrolled components.

Q: Does useRef cause re-render?

A: No. Updating a useRef value does NOT trigger component re-rendering.

Q: What is the current property?

A: current is a property of the ref object that stores the referenced DOM element or value. Example: inputRef.current.value

Q: Difference between useRef and useState?

A: useState causes re-render when data changes; useRef updates values without re-rendering the component.
