What is a Form?

🤔 Definition

A Form is used to collect data from users — and then validate and process it.

Real-Life Examples

Login Form Registration Form Contact Form Feedback Form Employee Form

💡 Why Do We Need Forms?

Suppose a user wants to login. We need to collect their Username and Password. Forms help us collect, validate, and process this data.

Controlled Component

🤔 What is a Controlled Component?

A form element whose value is controlled by React State. React State becomes the single source of truth.

Definition → A Controlled Component is a form element where React State becomes the single source of truth.

✅ React Controls

Input Value Updates Validation Form Submission

Flow

Input Field
↓
onChange Event fires
↓
State Updates
↓
UI Re-renders ✅

Example – Username Input

import React, { useState } from 'react';

function App() {
  const [username, setUsername] = useState("");

  return (
    <>
      <input
        type="text"
        value={username}
        onChange={(e) => setUsername(e.target.value)}
      />
      <h2>{username}</h2>  // shows typed text live
    </>
  );
}

export default App;

How It Works – Step by Step

Step 1

User types "Pravin"

Step 2

onChange() fires

Step 3

setUsername() updates state

Step 4

Component re-renders → "Pravin" appears

Login Form Example

import React, { useState } from 'react';

function App() {
  const [email,    setEmail]    = useState("");
  const [password, setPassword] = useState("");

  const handleSubmit = (e) => {
    e.preventDefault();   // stops page reload!
    console.log(email, password);
  };

  return (
    <form onSubmit={handleSubmit}>
      <input type="email"    value={email}
             placeholder="Enter Email"
             onChange={(e) => setEmail(e.target.value)} />
      <input type="password" value={password}
             placeholder="Enter Password"
             onChange={(e) => setPassword(e.target.value)} />
      <button type="submit">Login</button>
    </form>
  );
}

export default App;

⚠️ Why e.preventDefault()?

Normally: Form Submit → Page Reload (we don't want that!)
e.preventDefault() stops the default browser behavior, keeping React in control.

Advantages & Disadvantages

✅ Advantages

  • ✔ Easy Validation
  • ✔ Easy State Management
  • ✔ Real-time Updates
  • ✔ Preferred in React

❌ Disadvantages

  • ✘ More Code Required
  • ✘ Re-render on Every Change

Uncontrolled Component

🤔 What is an Uncontrolled Component?

Stores form data inside the DOM instead of React State. Data is accessed via refs.

Definition → An Uncontrolled Component is a form element where data is handled by the DOM using refs.

🔧 Hook Used

useRef()

Flow

Input Field
↓
useRef() connected
↓
Access Value Directly via inputRef.current.value ✅

Example

import React, { useRef } from 'react';

function App() {
  const inputRef = useRef();   // Step 1: create reference

  const showData = () => {
    alert(inputRef.current.value); // Step 3: read value
  };

  return (
    <>
      <input type="text" ref={inputRef} /> // Step 2: connect
      <button onClick={showData}>Show</button>
    </>
  );
}

export default App;
// User types "Pravin" → clicks Show → Alert: Pravin

🔍 How useRef Works Here

const inputRef = useRef() — creates the reference
ref={'{'}inputRef{'}'} — connects it to the input element
inputRef.current.value — gets the current value from DOM

Form Validation

🤔 What is Validation?

Validation checks whether the user entered correct data before processing. E.g., Email Required, Password Required.

Example

function App() {
  const [email, setEmail] = useState("");

  const handleSubmit = (e) => {
    e.preventDefault();
    if (email === "") {
      alert("Email Required");  // validation!
      return;
    }
    alert("Form Submitted ✅");
  };

  return (
    <form onSubmit={handleSubmit}>
      <input type="email" value={email}
             onChange={(e) => setEmail(e.target.value)} />
      <button type="submit">Submit</button>
    </form>
  );
}

Interview Questions

Common Interview Q&A

Q: What is a Controlled Component?

A: A form element whose value is controlled by React State.

Q: What is an Uncontrolled Component?

A: A form element whose value is managed by the DOM using refs.

Q: Why is useState used in Forms?

A: To store and update input field values dynamically.

Q: Why is e.preventDefault() used?

A: To prevent the default form submission behavior and avoid page reload.

Q: Which is better — Controlled or Uncontrolled?

A: Controlled Components are generally preferred — better control, validation, and state management.
