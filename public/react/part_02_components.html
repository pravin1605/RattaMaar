React Fragment

📘 Definition

A Fragment is a React feature that allows us to return multiple elements from a component without adding an extra HTML element to the DOM.

Why Use Fragments?

  • ✓ Avoid unnecessary <div> tags in the DOM
  • ✓ Keep the DOM clean and lightweight
  • ✓ Improve code readability
  • ✓ Return multiple elements from a single component

Syntax

📄 Full Syntax
<React.Fragment>
  <h1>Hello</h1>
  <h2>Welcome</h2>
</React.Fragment>
⚡ Short Syntax (Preferred)
<>
  <h1>Hello</h1>
  <h2>Welcome</h2>
</>

Example

  App.jsx 
import React from "react";

function App() {
  return (
    <>
      <h1>Hello React</h1>
      <h2>Welcome to Fragments</h2>
    </>
  );
}

export default App;
▶ Output
Hello React
Welcome to Fragments
💡 Real-Life Example: Creating a Student Details component — <><h1>Name: Pravin</h1><h2>Age: 21</h2></> — no unnecessary <div> wrapping needed!

React Components

📘 Definition

React Components are reusable building blocks of a React application that help create and manage different parts of the User Interface (UI).

Why Components?

♻️ Reusability

Write once, use anywhere in the application — Header, Footer, Button, etc.

🔧 Maintainability

Changes in one component don't affect others. Easy to update and fix bugs.

📁 Better Organization

Each UI part has its own file — keeps code clean and structured.

🐛 Easy Debugging

Isolate and test individual components independently.

⚡ Faster Development

Reuse existing components to build new features quickly.

Real-Life Example — Website Structure

Website
│
├── 🔷 Header Component
├── 🔷 Navbar Component
├── 🔷 Content Component
├── 🔷 Sidebar Component
└── 🔷 Footer Component

Types of Components

1️⃣ Functional Component

Created using JavaScript functions. Simple, modern, and preferred today.

function Student() {
  return <h1>Hello Student</h1>;
}
2️⃣ Class Component

Created using ES6 Classes. Older approach, supports lifecycle methods.

class Student extends React.Component {
  render() {
    return <h1>Hello Student</h1>;
  }
}
3

Rules of React Components

Rule 1 — Component Name Must Start with Capital Letter
✅ Correct
function Student() {
  return <h1>Student</h1>;
}
❌ Wrong
function student() {
  return <h1>Student</h1>;
}
💡 React treats lowercase tags as HTML elements (<div>, <p>) and uppercase as Components (<Student />).
Rule 2 — Component Must Return One Parent Element
✅ Option A — div wrapper
return (
  <div>
    <h1>Hello</h1>
    <h2>React</h2>
  </div>
)
✅ Option B — Fragment (Preferred)
return (
  <>
    <h1>Hello</h1>
    <h2>React</h2>
  </>
)
Rule 3 — Component Name = File Name
Student.jsx
↓
Student Component

Naming convention — keep file name and component name same for clarity.

Rule 4 — Save File with .jsx Extension
Student.jsx
Header.jsx
Footer.jsx

Ways to Use a Component

1 — Paired Tag
<Student></Student>
2 — Self-Closing Tag (Preferred)
<Student />

Class Components

📘 Definition

A Class Component is an ES6 class that extends React.Component and contains a mandatory render() method which returns JSX.

Characteristics of Class Components

🏛️ Uses ES6 Classes
class Student extends
  React.Component
🔗 Extends React.Component

Inheritance gives access to all React features and built-in methods.

⚠️ render() is Mandatory
render() {
  return <h1>Hello</h1>;
}
💾 Stateful Component
this.state = {
  name: "Pravin"
}
🔄 Lifecycle Methods

componentDidMount()
componentDidUpdate()
componentWillUnmount()

📤 Returns JSX

render() always returns JSX which gets displayed on the browser.

Class Component Examples

Example 1 — Simple Class Component

  Task.jsx 
import React from "react";

class Task extends React.Component {
  render() {
    return <h1>Hello, This is a Class Component</h1>;
  }
}

export default Task;
▶ Output
Hello, This is a Class Component

Example 2 — Using Fragment in Class Component

  Data.jsx 
import React, { Component } from "react";

class Data extends Component {
  render() {
    return (
      <>
        <h1>Hello React</h1>
        <h1>Welcome</h1>
        <h1>Fragment Example</h1>
      </>
    );
  }
}

export default Data;
▶ Output
Hello React
Welcome
Fragment Example
💡 Notice: { Component } is imported directly — so we can write extends Component instead of extends React.Component. Both are same!

Example 3 — Student Object and Destructuring

  Student.jsx 
import React from "react";

class Student extends React.Component {
  render() {
    let student = {
      name: "Pravin",
      age: 21
    };

    let { name, age } = student;  // Destructuring

    return (
      <>
        <h1>My Name is {name} and My Age is {age}</h1>
      </>
    );
  }
}

export default Student;
▶ Output
My Name is Pravin and My Age is 21
🔍 What is Destructuring?

Destructuring allows extracting values from objects directly into variables.

❌ Without Destructuring
student.name
student.age
✅ With Destructuring
let { name, age } = student;

Example 4 — Addition Component

  Addtion.jsx 
import React from "react";

class Addtion extends React.Component {
  render() {
    let a = parseInt(prompt("Enter First Number"));
    let b = parseInt(prompt("Enter Second Number"));
    return (
      <>
        <h1>The Sum of {a} and {b} is {a + b}</h1>
      </>
    );
  }
}

export default Addtion;
▶ Output (Input: 10, 20)
The Sum of 10 and 20 is 30
⚠️
Important Note: Using prompt() inside render() is NOT recommended because:
  • render() may execute multiple times → multiple popups appear
  • It blocks the browser and affects user experience

Correct approach: Handle user input using State, Forms, and Event Handling (covered in later chapters).

Rendering Components in main.jsx

After creating a component, it must be imported and rendered inside main.jsx to appear in the browser.

  main.jsx 
import { createRoot } from "react-dom/client";
import Addtion from "./Addtion";

createRoot(document.getElementById("root")).render(
  <Addtion />
);

Flow

Addtion.jsx (Component)
→
import in main.jsx
→
createRoot()
→
.render(<Addtion />)
→
Browser 🖥️

🎯 Interview Q&A
Q: What is a React Component?
A: A reusable, independent piece of UI. React apps are built by combining multiple components.
Q: What is the difference between Functional and Class Component?
A: Functional components are plain JS functions; Class components extend React.Component and need a render() method. Functional components are preferred now with Hooks.
Q: Why is render() mandatory in Class Components?
A: Because render() is the only method React calls to get JSX — without it, React doesn't know what to display.
Q: What is a React Fragment?
A: A wrapper that lets you return multiple elements without adding extra DOM nodes. Syntax: <>...</> or <React.Fragment>...</React.Fragment>.
Q: What is Destructuring in JS?
A: A shorthand to extract values from objects/arrays. let {name, age} = student; instead of student.name, student.age.
