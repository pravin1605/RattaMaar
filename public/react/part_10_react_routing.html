What is Routing?

Routing is the process of navigating between different pages or components without reloading the entire web page. It makes React SPAs feel like traditional multi-page websites.

❌ Without Routing
  • Entire page reloads on navigate
  • Slow performance
  • Poor user experience
  • All data re-fetched again
✅ With Routing
  • Only the component changes
  • Fast navigation
  • Better user experience
  • No full page reload

What is a Single Page Application (SPA)?

A SPA loads only one HTML page. When users navigate between routes, only the content area changes — the browser never refreshes.

BrowserRouter

BrowserRouter is the main/root routing component. It wraps the entire application and connects React with the browser's URL system.

❌ Without BrowserRouter
  • React cannot understand URL changes
  • Navigating breaks the app
  • No browser history tracking
✅ With BrowserRouter
  • Browser URL ↔ React UI synced
  • Back / Forward buttons work
  • No page reload on navigate

3 Responsibilities of BrowserRouter

🔗

Manages URLs

Tracks current URL — /about, /contact, /profile etc.

📜

Tracks Browser History

Supports the browser's Back and Forward buttons for seamless navigation.

🚫

Prevents Page Reload

Navigation happens inside the React app — no full browser refresh ever.

Basic Usage
import { BrowserRouter } from "react-router-dom";

function App() {
  return (
    <BrowserRouter>
      // All Routes go inside here
    </BrowserRouter>
  );
}
4

Routes Component

Routes is the container that holds all Route components. It looks at the current URL and renders only the matching route.

Structure
<Routes>
  <Route path="/"        element={<Home />} />
  <Route path="/about"    element={<About />} />
  <Route path="/contact"  element={<Contact />} />
</Routes>
Rule: Routes must always be placed inside BrowserRouter. And all Route components must be direct children of Routes.
5

Route Component & Attributes

Route defines the relationship between a URL path and a React component. When the URL matches the path, the component is rendered.

Two Key Attributes

path — URL Pattern

Defines which URL this route matches.

path="/about"
// matches: /about
element — Component to Render

The JSX component to show when URL matches.

element={<About />}
// renders <About />

Full Route Example

Route Syntax
<Route
  path="/about"       // when URL = /about
  element={<About />} // render About component
/>
User visits /about
↓

↓
path="/about" matches ✅
↓
<About /> component renders

Complete Working Example

Here's a full React app with 3 routes wired up from scratch:

App.jsx — Full Routing Setup
import { BrowserRouter, Routes, Route } from "react-router-dom";
import Home    from "./Home";
import About   from "./About";
import Contact from "./Contact";

function App() {
  return (
    <BrowserRouter>          // Step 1: Wrap everything
      <Routes>                // Step 2: Routes container

        <Route              // Step 3: Each Route
          path="/"
          element={<Home />}
        />
        <Route
          path="/about"
          element={<About />}
        />
        <Route
          path="/contact"
          element={<Contact />}
        />

      </Routes>
    </BrowserRouter>
  );
}

export default App;

How It Flows

User enters a URL
↓
BrowserRouter intercepts
↓
Routes checks each Route's path
↓
Matching Route found
↓
Component renders in the browser ✅
Clean setup tip: Always import all three — BrowserRouter, Routes, Route — in a single import statement from react-router-dom.

Interview Questions 🎯

What is Routing in React?
Routing is the process of navigating between different pages or components without reloading the entire web page. It keeps React apps as a Single Page Application.
Why is Routing used?
To create Single Page Applications (SPA) that provide fast navigation without browser refresh — improving performance and user experience.
What is BrowserRouter?
BrowserRouter is the main routing component that synchronizes the browser URL with the React application UI. It enables back/forward navigation and prevents page reloads.
What is Routes?
Routes is a container component that holds all Route components and renders the matching route based on the current browser URL.
What is Route?
Route maps a specific URL path to a React component. When the URL matches the path, the element component is rendered.
What are the attributes of Route?
path — defines the URL pattern to match (e.g. "/about")
element — the React component to render when path matches (e.g. <About />)
