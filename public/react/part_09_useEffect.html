What is useEffect?

useEffect is built-in a React Hook used to perform side effects such as API calls, timers, event listeners, DOM manipulation, and data fetching in Function Components.

What is a Side Effect?

A side effect is any operation that affects something outside the component — the network, the browser, a timer, or external storage.

🌐 API Calls
Fetch data from server
⏱️ Timers
setInterval / setTimeout
👂 Event Listeners
Add/remove safely
🖥️ DOM Manipulation
Browser title, scroll
💾 Local Storage
Save / read data
🗄️ Database Requests
Load / sync data

Why Was useEffect Introduced?

❌ Before — Class Components
class User extends Component {
  componentDidMount(){
    // API Call
  }
  componentDidUpdate(){
    // Update Logic
  }
  componentWillUnmount(){
    // Cleanup
  }
}
// 3 separate methods 😓
✅ Now — useEffect
function User() {
  useEffect(() => {
    // API Call + Cleanup
    // All in ONE place ✅
    return () => {
      // cleanup
    };
  }, []);
}
// 1 hook does it all 🎉

Dependency Array — The 3 Cases ⭐

The dependency array is the most important part of useEffect — it controls exactly when the effect runs.

Case 1

Empty Array [ ] → Runs Once Only

Effect runs only once — after the first render. Never runs again. Equivalent to componentDidMount().

Syntax
useEffect(() => {
  console.log("Runs ONCE on mount");
}, []);   // Empty array → run once
Executed ← only once on first render
First Render
↓
useEffect Runs ✅
↓
Never runs again
Practical Example — Load on mount
import { useEffect } from 'react';

function App() {
  useEffect(() => {
    fetch("https://api.example.com/users")
      .then(res => res.json())
      .then(data => console.log(data));
  }, []);   // Fetch only once when component loads

  return <h1>Hello React</h1>;
}
Use this for: API calls on page load, initializing timers, adding event listeners once.
Case 2

No Array → Runs After Every Render

Effect runs after every single render. Whenever any state or prop changes and the component re-renders, the effect fires again.

Syntax
useEffect(() => {
  console.log("Runs after EVERY render");
});   // No array = always runs
Render 1 → Executed
Render 2 → Executed
Render 3 → Executed
Render
↓
useEffect Runs
↓
Re-render → Runs Again
↓
Re-render → Runs Again ...
Practical Example
import { useState, useEffect } from 'react';

function App() {
  const [count, setCount] = useState(0);

  useEffect(() => {
    console.log("Component rendered!");
  });   // No array — runs on every re-render

  return (
    <>
      <h1>{count}</h1>
      <button onClick={() => setCount(count + 1)}>Increment</button>
    </>
  );
}
⚠️ Use sparingly! Running effects on every render can cause performance issues in large apps. Usually you want Case 1 or Case 3 instead.
Case 3

[dep] → Runs When Dependency Changes

Effect runs once on mount, then again whenever the dependency value changes. React compares old vs new value — if different, effect re-runs.

Syntax
useEffect(() => {
  console.log("Count changed!");
}, [count]);   // Only runs when count changes
count = 0 → Executed (initial)
count = 1 → Executed
count = 2 → Executed
count changes
↓
Old value ≠ New value
↓
useEffect Runs ✅
Practical Example
import { useState, useEffect } from 'react';

function App() {
  const [count, setCount] = useState(0);

  useEffect(() => {
    document.title = `Count: ${count}`;   // Update title on change
  }, [count]);

  return (
    <>
      <h1>{count}</h1>
      <button onClick={() => setCount(count + 1)}>Increment</button>
    </>
  );
}

Multiple Dependencies

Multiple deps
useEffect(() => {
  console.log("count or name changed");
}, [count, name]);   // Runs when count OR name changes
Most commonly used case! Perfect for re-fetching data when a route param or filter changes.

Cleanup Function

useEffect can return a cleanup function that runs when the component unmounts or before the effect re-runs. Prevents memory leaks.

Cleanup Syntax
useEffect(() => {
  // Setup: your side effect here

  return () => {
    // Cleanup: runs on unmount or before re-run
  };
}, []);

Timer — Setup & Cleanup

componentDidMount equivalent
useEffect(() => {
  const timer = setInterval(
    () => console.log("tick"),
    1000
  );

  // Return cleanup function
  return () => {
    clearInterval(timer);
  };
}, []);
componentWillUnmount equivalent
// The return () => {} block
// is the cleanup function.

// It automatically runs:
// 1. When component unmounts
// 2. Before effect re-runs

// Without cleanup:
// ❌ Timer keeps running
// ❌ Memory leak!

Event Listener — Setup & Cleanup

Event Listener with Cleanup
useEffect(() => {
  const handleResize = () => console.log("resized");

  window.addEventListener("resize", handleResize);   // Add

  return () => {
    window.removeEventListener("resize", handleResize);  // Remove
  };
}, []);
⚠️ Always clean up: Timers, event listeners, WebSocket connections and API subscriptions must always have a corresponding cleanup or you'll get memory leaks and bugs on unmounted components.

useEffect vs Lifecycle Methods

useEffect (Functional)Lifecycle Method (Class)
useEffect(() => {}, [])componentDidMount()
useEffect(() => {})componentDidUpdate()
useEffect(() => { return cleanup })componentWillUnmount()
useEffect(() => {}, [count])Run when count changes
Modern React prefers useEffect — one hook replaces three separate lifecycle methods and keeps related logic together in one place.

Interview Questions 🎯

What is useEffect?
useEffect is a React Hook used to perform side effects such as API calls, event listeners, timers, and DOM manipulation inside Function Components. It runs after the component renders.
What is a Dependency Array?
The dependency array is the second argument to useEffect. It controls when the effect should re-run. React watches the values in this array and re-executes the effect when any of them change.
What happens when the dependency array is empty [ ]?
The effect runs only once after the initial render and never again. Equivalent to componentDidMount(). Perfect for initial API calls.
What happens when no dependency array is provided?
The effect runs after every render — whenever any state or prop changes and causes a re-render. Equivalent to componentDidUpdate() running on all changes.
What happens when state is in the dependency array [count]?
The effect runs once on mount, then again whenever count changes. React compares old vs new value — if different, the effect fires.
What is the cleanup function in useEffect?
The function returned from useEffect. It runs before the component unmounts or before the effect re-runs. Used to clear timers, remove event listeners, cancel API calls — prevents memory leaks.
