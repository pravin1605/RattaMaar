Event Handling in React

🤔 What is Event Handling?

The process of responding to user actions — clicking a button, typing in an input, hovering over an element, etc.

Definition → Event Handling in React allows components to respond to user interactions by executing functions when specific events occur.

💡 Why Do We Need It?

❌ Without Event Handling

Button Clicked → Nothing Happens

✅ With Event Handling

Button Clicked → Function Executes → Action Performed

Common Events

onClick onChange onSubmit onMouseOver onMouseOut onKeyDown onKeyUp

Example 1 – Button Click

function App() {
  function showMessage() {
    alert("Button Clicked");
  }
  return (
    <button onClick={showMessage}>
      Click Me
    </button>
  );
}
User Clicks Button
↓
showMessage() called
↓
Alert Displayed ✅

Example 2 – Passing Arguments

function App() {
  function display(name) {
    alert(name);
  }
  return (
    <button onClick={() => display("Pravin")}>
      Click
    </button>
  );
}
// Output: Pravin

Event Object

function App() {
  function handleClick(event) {
    console.log(event); // React SyntheticEvent
  }
  return <button onClick={handleClick}>Click</button>;
}

🎯 Interview Question

Q: What is Event Handling?
A: Event Handling is the process of executing functions in response to user interactions such as clicks, typing, form submissions, and mouse events.

Conditional Rendering

🤔 What is Conditional Rendering?

Displaying different UI based on a condition — like showing a welcome message only when logged in.

Definition → Conditional Rendering allows React to render different components or elements based on conditions.

✅ Logged In

Welcome, Pravin!

❌ Not Logged In

Please Login

Method 1 – if-else

function App() {
  const isLogin = true;
  if (isLogin) {
    return <h1>Welcome User</h1>;
  }
  return <h1>Please Login</h1>;
}

Method 2 – Ternary Operator

function App() {
  const isLogin = true;
  return (
    <>
      {isLogin
        ? <h1>Welcome User</h1>
        : <h1>Please Login</h1>}
    </>
  );
}

Method 3 – Logical &&

function App() {
  const isLogin = true;
  return (
    <>
      {isLogin && <h1>Welcome User</h1>}
    </>
  );
}
Condition Checked
↓
True → Show Component A
↓
False → Show Component B

🛒 Real-Life Example

{cartItems.length > 0 ? <Cart/> : <h2>Cart Empty</h2>}

🎯 Interview Question

Q: What is Conditional Rendering?
A: Conditional Rendering is the process of displaying different UI elements based on specific conditions.

Lists and Keys

📋 What are Lists?

Lists are used to display multiple items dynamically using the map() function instead of hardcoding each item.

❌ Without Lists

<h1>Java</h1>
<h1>Python</h1>
<h1>React</h1>
Not practical!

✅ With Lists + map()

Loop through array → render dynamically. Scalable & clean!

Example – map()

function App() {
  const courses = ["Java", "Python", "React"];
  return (
    <>
      {courses.map((course) => (
        <h1>{course}</h1>
      ))}
    </>
  );
}
// Output: Java  Python  React

🔑 What is a Key?

A key is a unique identifier used by React while rendering lists. It helps React identify which items changed, added, or removed.

Example – Keys

const users = [
  { id: 1, name: "Pravin" },
  { id: 2, name: "Rahul" }
];

{users.map((user) => (
  <h2 key={user.id}>
    {user.name}
  </h2>
))}
Array Data
↓
map() loops through
↓
JSX Created with key
↓
UI Displayed ✅

🌍 Real-Life Uses

Products Employees Students Orders Customers

🎯 Interview Question

Q: Why are Keys Required in React?
A: Keys help React uniquely identify elements in a list and improve rendering performance by updating only the changed items.
