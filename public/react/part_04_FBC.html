What are Function Based Components?

📘 Definition

Function Based Components (FBC) are normal JavaScript functions that return JSX elements. React uses these functions to create and display UI components on the screen.

⚡ Simple Definition

A Function Component is a JavaScript function that returns JSX and is used to create reusable user interface elements in React.

Syntax

function ComponentName() {
  return (
    <h1>Hello React</h1>
  );
}

export default ComponentName;
💡 Rule: Component name must start with a Capital Letter. React treats lowercase names as HTML tags and Uppercase as Components.

Benefits

  • ✓ Reusable — Write once, use anywhere in the project
  • ✓ Readable — Clean, short code that's easy to understand
  • ✓ Maintainable — Update one component without breaking others
  • ✓ Easy to Debug — Isolate and test components independently

Why Function Components Are Popular

✍️ Easy to Write

Much shorter and cleaner than Class Components — no extends, no render().

👁️ Better Readability

Less code means faster understanding. Developers can focus on business logic.

⚡ Better Performance

Lightweight — no class instances created. Slightly faster rendering than Class Components.

🏆 Modern React Standard

React officially recommends Function Components with Hooks. Almost all new projects use FBC.

Code Size Comparison

🔴 Class Component — More Code
class Welcome extends React.Component {
  render() {
    return <h1>Hello</h1>;
  }
}
🟢 Function Component — Less Code
function Welcome() {
  return <h1>Hello</h1>;
}

Before Hooks vs After Hooks

1

Before React 16.8 — "Stateless Components"

Function Components were called Stateless Components because they could NOT:

  • ✗ Store State
  • ✗ Use Lifecycle Methods
  • ✗ Manage Complex Logic
// Only UI rendering was possible
function Demo() {
  return <h1>Hello React</h1>;
}
2

The Problem

For a Counter app, developers HAD to use Class Components — increasing complexity.

❌ Function Component (Before) — Could Not
// Not possible before Hooks
function Counter() {
  // state here??? ❌
}
⚠️ Had to use Class Component
class Counter extends Component {
  state = { count: 0 }
  // lots of boilerplate...
}
3

React 16.8 — Hooks Changed Everything ✅

Now Function Components can do everything Class Components can:

✅ Manage State
✅ Use Lifecycle Features
✅ Handle Side Effects
✅ Access Context

Counter App — Now Possible with Function Component

  Counter.jsx 
import React, { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);   // useState Hook

  return (
    <>
      <h1>{count}</h1>
      <button onClick={() => setCount(count + 1)}>
        Increment
      </button>
    </>
  );
}

export default Counter;
🔍 Key Points in the Code

useState(0) → creates state variable count starting at 0
setCount → function to update the state (like setState in class)
onClick={() => setCount(count + 1)} → arrow function to increment on click

Example 2 — Student Component with Variable

  Student.jsx 
function Student() {
  let name = "Pravin";    // JS variable inside function

  return (
    <h1>
      My Name Is {name}   // JSX Expression
    </h1>
  );
}

export default Student;
▶ Output
My Name Is Pravin
💡 Variables declared inside a Function Component are accessible in the JSX {} expression. This is one of the key powers of Function Components — JS and JSX in one place.

✅ Function Component (Modern)
import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);
  return (
    <button onClick={()=>setCount(count+1)}>
      {count}
    </button>
  );
}
⚠️ Class Component (Legacy)
class Counter extends Component {
  constructor() {
    super();
    this.state = { count: 0 };
  }
  render() {
    return (
      <button onClick={()=>this.setState(
        {count:this.state.count+1})}>
        {this.state.count}
      </button>
    );
  }
}
🎯 Interview Q&A
Q: What is a Function Component in React?
A: A Function Component is a JavaScript function that returns JSX and is used to create reusable UI elements in React applications.
Q: Why do we use Function Components?
A: Function Components are simpler, require less code, support Hooks, are easier to read, and are the officially recommended way of building modern React applications.
Q: Why were Function Components called Stateless Components earlier?
A: Before React Hooks (React 16.8), Function Components could only render UI — they could not manage state or use lifecycle methods. After Hooks were introduced, they became fully capable, so "Stateless" is no longer accurate.
Q: What is useState and why is it used?
A: useState is a React Hook used in Function Components to manage state. It returns a state variable and a setter function: const [count, setCount] = useState(0);
Q: What changed in React 16.8?
A: React 16.8 introduced Hooks, which allowed Function Components to manage state (useState), handle side effects (useEffect), and access context — making them as powerful as Class Components.
