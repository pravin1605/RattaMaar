1. What are Conditional Statements?
Interview Definition

Conditional Statements are used to make decisions in a PL/SQL program based on TRUE or FALSE conditions. They allow different blocks of code to execute depending on whether a condition is satisfied or not.

TypeUse WhenChoices
IFOnly one condition to checkOne choice
IF...ELSETwo possible outcomes — TRUE or FALSETwo choices
IF...ELSIF...ELSEMultiple conditions to check one by oneMultiple choices
Memory Trick

IF = 1 condition  |  IF-ELSE = 2 choices  |  IF-ELSIF-ELSE = Many choices

PL/SQL keyword is ELSIF — NOT ELSEIF (a very common mistake)

2. IF Statement
Definition

The IF statement executes a block of code only when the condition is TRUE. If the condition is FALSE or NULL, the block is completely skipped.

Syntax:

IF STATEMENT — SYNTAX
IF condition THEN statements; END IF;

Example 1 — Voting Eligibility:

VOTING ELIGIBILITY
DECLARE V_AGE NUMBER := 20; BEGIN IF V_AGE >= 18 THEN DBMS_OUTPUT.PUT_LINE('ELIGIBLE TO VOTE'); END IF; END; /
Output: ELIGIBLE TO VOTE

Example 2 — High Salary:

HIGH SALARY CHECK
DECLARE V_SAL NUMBER := 50000; BEGIN IF V_SAL >= 40000 THEN DBMS_OUTPUT.PUT_LINE('HIGH SAL'); END IF; END; /
Output: HIGH SAL

Example 3 — Topper Check:

TOPPER CHECK
DECLARE V_TOPPER NUMBER := 96; BEGIN IF V_TOPPER >= 95 THEN DBMS_OUTPUT.PUT_LINE('I AM A TOPPER'); END IF; END; /
Output: I AM A TOPPER
3. IF...ELSE Statement
Definition

The IF...ELSE statement executes one block of code if the condition is TRUE, and a different block if the condition is FALSE. Exactly one of the two blocks always executes.

Syntax:

IF-ELSE — SYNTAX
IF condition THEN true block; ELSE false block; END IF;

Example 1 — Voting Eligibility:

VOTING ELIGIBILITY — IF-ELSE
DECLARE V_VOTE NUMBER := 15; BEGIN IF V_VOTE >= 18 THEN DBMS_OUTPUT.PUT_LINE('ELIGIBLE'); ELSE DBMS_OUTPUT.PUT_LINE('RUK ABHI TIME HAI'); END IF; END; /
Output: RUK ABHI TIME HAI

Example 2 — Temperature Check:

TEMPERATURE CHECK
DECLARE V_TEMP NUMBER := 30; BEGIN IF V_TEMP >= 30 THEN DBMS_OUTPUT.PUT_LINE('TEMP IS HOT ' || V_TEMP); ELSE DBMS_OUTPUT.PUT_LINE('TEMP IS COOL ' || V_TEMP); END IF; END; /
Output: TEMP IS HOT 30

Example 3 — Account Balance Check:

ACCOUNT BALANCE CHECK
DECLARE V_BALANCE NUMBER := 0; BEGIN IF V_BALANCE > 0 THEN DBMS_OUTPUT.PUT_LINE('BALANCE AVAILABLE'); ELSE DBMS_OUTPUT.PUT_LINE('INSUFFICIENT BALANCE'); END IF; END; /
Output: INSUFFICIENT BALANCE

Example 4 — SELECT INTO with IF-ELSE (EMP Table):

SELECT INTO WITH IF-ELSE — FETCH EMPLOYEE
DECLARE V_NAME EMP.ENAME%TYPE; V_SAL EMP.SAL%TYPE; BEGIN SELECT ENAME, SAL INTO V_NAME, V_SAL FROM EMP WHERE SAL = 950; IF V_SAL = 950 THEN DBMS_OUTPUT.PUT_LINE('FETCHED NAME : ' || V_NAME); DBMS_OUTPUT.PUT_LINE('FETCHED SALARY : ' || V_SAL); ELSE DBMS_OUTPUT.PUT_LINE('DATA NOT FOUND'); END IF; END; /
Output: FETCHED NAME : JAMES   FETCHED SALARY : 950
Important Interview Point

If WHERE SAL = 10 is used and no employee has that salary, Oracle raises ORA-01403: NO_DATA_FOUND because SELECT INTO must always return exactly one row.

4. IF...ELSIF...ELSE Statement
Definition

Used when multiple conditions need to be checked one by one. The first condition that evaluates to TRUE gets executed and all remaining conditions are skipped. If none match, the ELSE block runs.

Syntax:

IF-ELSIF-ELSE — SYNTAX
IF condition1 THEN statements; ELSIF condition2 THEN statements; ELSIF condition3 THEN statements; ELSE statements; END IF;

Example 1 — Grade System:

GRADE SYSTEM — IF-ELSIF-ELSE
DECLARE V_SCORE NUMBER := 72; BEGIN IF V_SCORE >= 95 THEN DBMS_OUTPUT.PUT_LINE('GRADE A'); ELSIF V_SCORE >= 75 THEN DBMS_OUTPUT.PUT_LINE('GRADE B'); ELSIF V_SCORE >= 50 THEN DBMS_OUTPUT.PUT_LINE('GRADE C'); ELSE DBMS_OUTPUT.PUT_LINE('FAIL'); END IF; END; /
Output: GRADE C   (72 is not >= 95, not >= 75, but >= 50 → GRADE C)

Example 2 — Day of Week:

DAY OF WEEK PROGRAM
DECLARE V_DAY VARCHAR2(20) := 'MONDAY'; BEGIN IF V_DAY = 'MONDAY' THEN DBMS_OUTPUT.PUT_LINE('START OF THE WEEK'); ELSIF V_DAY = 'FRIDAY' THEN DBMS_OUTPUT.PUT_LINE('WEEKEND IS COMING'); ELSIF V_DAY = 'SUNDAY' THEN DBMS_OUTPUT.PUT_LINE('HOLIDAY'); ELSE DBMS_OUTPUT.PUT_LINE('NORMAL WORKING DAY'); END IF; END; /
Output: START OF THE WEEK
5. Common Beginner Mistakes
WRONG
V_SAL NUMBER: = 50000;
CORRECT
V_SAL NUMBER := 50000;

No space between : and = in the assignment operator

WRONG
V_TOPPER := 96;
CORRECT
V_TOPPER NUMBER := 96;

Every variable must have a datatype — NUMBER, VARCHAR2, DATE, etc.

WRONG
ELSEIF
CORRECT
ELSIF

PL/SQL uses ELSIF (no E at end) — not ELSEIF like Java or other languages

WRONG
V_DAY VARCHAR := 'MON';
CORRECT
V_DAY VARCHAR2(20) := 'MON';

VARCHAR2 requires a size. Always write VARCHAR2(size)

WRONG
IF V_TEMP >= 0 THEN
(V_TEMP not declared)
CORRECT
Use exactly the same
variable name you declared

Error: PLS-00201 — identifier must be declared. Variable name used must match the declared name exactly.

6. EMP Table Practice Questions — Conditional Statements
Q1. Fetch the salary of KING (EMPNO 7839) and check if he is the highest paid
Uses: SELECT INTO + IF-ELSE + %TYPE
KING SALARY CHECK
DECLARE V_SAL EMP.SAL%TYPE; BEGIN SELECT SAL INTO V_SAL FROM EMP WHERE EMPNO = 7839; IF V_SAL = 5000 THEN DBMS_OUTPUT.PUT_LINE('KING IS THE HIGHEST PAID : ' || V_SAL); ELSE DBMS_OUTPUT.PUT_LINE('NOT HIGHEST PAID'); END IF; END; /
Output: KING IS THE HIGHEST PAID : 5000
Q2. Fetch salary of SMITH (EMPNO 7369) and check if it is above or below 1000
Uses: SELECT INTO + IF-ELSE + %TYPE
SMITH SALARY CHECK
DECLARE V_NAME EMP.ENAME%TYPE; V_SAL EMP.SAL%TYPE; BEGIN SELECT ENAME, SAL INTO V_NAME, V_SAL FROM EMP WHERE EMPNO = 7369; IF V_SAL > 1000 THEN DBMS_OUTPUT.PUT_LINE(V_NAME || ' EARNS ABOVE 1000 : ' || V_SAL); ELSE DBMS_OUTPUT.PUT_LINE(V_NAME || ' EARNS BELOW 1000 : ' || V_SAL); END IF; END; /
Output: SMITH EARNS BELOW 1000 : 800
Q3. Fetch the job of SCOTT (EMPNO 7788) and display his salary category using ELSIF
Uses: SELECT INTO + IF-ELSIF-ELSE + %TYPE
SCOTT SALARY CATEGORY
DECLARE V_NAME EMP.ENAME%TYPE; V_SAL EMP.SAL%TYPE; BEGIN SELECT ENAME, SAL INTO V_NAME, V_SAL FROM EMP WHERE EMPNO = 7788; IF V_SAL >= 4000 THEN DBMS_OUTPUT.PUT_LINE(V_NAME || ' : VERY HIGH SALARY'); ELSIF V_SAL >= 2500 THEN DBMS_OUTPUT.PUT_LINE(V_NAME || ' : HIGH SALARY'); ELSIF V_SAL >= 1500 THEN DBMS_OUTPUT.PUT_LINE(V_NAME || ' : MEDIUM SALARY'); ELSE DBMS_OUTPUT.PUT_LINE(V_NAME || ' : LOW SALARY'); END IF; END; /
Output: SCOTT : HIGH SALARY   (SAL = 3000, not >= 4000 but >= 2500)
Q4. Fetch ALLEN's (EMPNO 7499) details and check if he is a SALESMAN or not
Uses: SELECT INTO + IF-ELSE + %ROWTYPE
ALLEN JOB CHECK
DECLARE V_EMP EMP%ROWTYPE; BEGIN SELECT * INTO V_EMP FROM EMP WHERE EMPNO = 7499; IF V_EMP.JOB = 'SALESMAN' THEN DBMS_OUTPUT.PUT_LINE(V_EMP.ENAME || ' IS A SALESMAN'); DBMS_OUTPUT.PUT_LINE('SALARY : ' || V_EMP.SAL); ELSE DBMS_OUTPUT.PUT_LINE(V_EMP.ENAME || ' IS NOT A SALESMAN'); END IF; END; /
Output: ALLEN IS A SALESMAN   SALARY : 1600
Q5. Fetch JONES (EMPNO 7566) and classify his department as HQ, Operations, or Sales Extra
Uses: SELECT INTO + IF-ELSIF-ELSE + %TYPE — DEPTNO 10=HQ, 20=Operations, 30=Sales
DEPARTMENT CLASSIFICATION
DECLARE V_NAME EMP.ENAME%TYPE; V_DEPTNO EMP.DEPTNO%TYPE; BEGIN SELECT ENAME, DEPTNO INTO V_NAME, V_DEPTNO FROM EMP WHERE EMPNO = 7566; IF V_DEPTNO = 10 THEN DBMS_OUTPUT.PUT_LINE(V_NAME || ' WORKS IN HQ (DEPTNO 10)'); ELSIF V_DEPTNO = 20 THEN DBMS_OUTPUT.PUT_LINE(V_NAME || ' WORKS IN OPERATIONS (DEPTNO 20)'); ELSIF V_DEPTNO = 30 THEN DBMS_OUTPUT.PUT_LINE(V_NAME || ' WORKS IN SALES (DEPTNO 30)'); ELSE DBMS_OUTPUT.PUT_LINE('UNKNOWN DEPARTMENT'); END IF; END; /
Output: JONES WORKS IN OPERATIONS (DEPTNO 20)
7. Quick Revision — All Three Types
StatementCondition CheckBlocksKey Point
IFOne conditionRuns only if TRUE — skipped if FALSENo ELSE — nothing happens if FALSE
IF...ELSEOne conditionTRUE block OR FALSE block — exactly one runsAlways one block executes
IF...ELSIF...ELSEMultiple conditionsFirst TRUE condition's block runs, rest skippedELSIF not ELSEIF — common mistake!
Key Keywords

IF  |  THEN  |  ELSIF  |  ELSE  |  END IF;

Every IF block must close with END IF; — forgetting this causes a compilation error

8. Frequently Asked Interview Questions
Q1. What is the difference between IF, IF-ELSE and IF-ELSIF-ELSE?
IF executes code only when the condition is TRUE. IF-ELSE executes one block for TRUE and another for FALSE. IF-ELSIF-ELSE is used when multiple conditions need to be checked — the first TRUE condition executes and the rest are skipped.
Q2. What is the correct keyword in PL/SQL — ELSEIF or ELSIF?
The correct keyword in PL/SQL is ELSIF — not ELSEIF. Using ELSEIF will cause a PLS-00103 compilation error. This is a very common mistake when coming from Java or other languages.
Q3. What error occurs when SELECT INTO returns no rows?
ORA-01403: NO DATA FOUND. SELECT INTO must always return exactly one row. If no rows are returned, the NO_DATA_FOUND exception is raised. It should be handled in the EXCEPTION section.
Q4. What happens if none of the ELSIF conditions are TRUE and there is no ELSE? Extra
If no condition matches and there is no ELSE block, the entire IF-ELSIF block is simply skipped. No error occurs — the program continues to the next statement after END IF.
Q5. Can we use SELECT INTO inside an IF block? Extra
SELECT INTO is placed in the BEGIN section before the IF block. The fetched values are stored in variables, which are then used inside the IF conditions. SELECT INTO cannot be placed directly inside an IF block condition.
Q6. What is the error when a variable is used without being declared? Extra
PLS-00201: identifier must be declared. Every variable used in BEGIN must be declared in the DECLARE section with its correct datatype. The name used in BEGIN must exactly match the name in DECLARE.
