1. What is PL/SQL?
Interview Definition

SQL is a language used to perform operations on database objects such as tables, views, and indexes.

PL/SQL is Oracle's procedural extension of SQL that combines SQL statements with programming constructs like variables, loops, conditions, cursors, and exception handling.

  • PL/SQL stands for Procedural Language / Structured Query Language
  • Developed by Oracle Corporation
  • Introduced in Oracle Version 6 around 1991
  • Extends SQL by adding programming capabilities
  • Allows developers to write complete programs inside the Oracle database
Memory Trick

PL/SQL = SQL + Procedural Language

SQL = Ask the database  |  PL/SQL = Tell the database what to do step by step

3. Why PL/SQL? (Limitations of SQL)

SQL can retrieve and manipulate data, but it cannot:

  • Store temporary values
  • Make decisions
  • Execute repetitive tasks
  • Handle runtime errors

PL/SQL solves these by providing:

Variables

Used to store temporary data

Conditions

Used to make decisions (IF / ELSIF / ELSE)

Loops

Used to repeat statements

Exception Handling

Used to handle runtime errors

Cursors

Used to process multiple rows

Modular Code

Procedures, Functions, Triggers, Packages

4. Features of PL/SQL
Block Structured Language Tight Integration with SQL Exception Handling Modular Programming Better Performance Reusable Code Supports Variables Supports Loops Supports Conditions Supports Cursors
Extra — Important

PL/SQL is compiled before execution. Oracle compiles and stores PL/SQL blocks in the database, making repeated execution faster than SQL. The compiled version is called P-code (pseudocode).

6. Structure of PL/SQL Block

PL/SQL is a Block Structured Language. Every PL/SQL program consists of blocks.

SectionKeywordMandatory?Purpose
DeclareDECLAREOptionalDeclare variables, constants, cursors, exceptions
BeginBEGINMandatoryAll executable statements go here
ExceptionEXCEPTIONOptionalHandle runtime errors
EndEND;MandatoryMarks the end of the block
Memory Trick

D-B-E-E → DECLARE → BEGIN → EXCEPTION → END

"Database Block Execution Ends" — only BEGIN and END are mandatory

6a. DECLARE Section
  • Used to declare Variables, Constants, Cursors, User-defined Exceptions
  • All declarations end with a semicolon ( ; )
  • Variables hold temporary data used in the block
  • Constants are declared using the CONSTANT keyword and cannot be changed
  • Assignment operator in PL/SQL is := (not = )
Extra — %TYPE Anchored Data Type

EMP.ENAME%TYPE allows a variable to automatically inherit the data type of a database column. Best practice to avoid type mismatch errors if the column type changes in future.

6b. BEGIN Section

Contains all executable statements. The only mandatory section along with END.

  • SELECT INTO, INSERT, UPDATE, DELETE
  • DDL Statements and TCL Statements
  • IF Conditions and Loops
  • Procedure / Function calls
6c. EXCEPTION Section

Used to handle runtime errors gracefully.

Exception NameTriggered When
NO_DATA_FOUNDSELECT INTO returns no rows
TOO_MANY_ROWSSELECT INTO returns more than one row
ZERO_DIVIDEDivision by zero
WHEN OTHERS ExtraCatch-all — handles any unhandled exception; must always be placed last

  • Cannot be called again
  • Used for testing / small programs

Real life: Writing on paper and throwing it away

  • Has a Name

Extra — Procedure vs Function

A Procedure may or may not return a value. A Function always returns exactly one value using RETURN. Functions can be used inside SQL queries (SELECT ... FROM DUAL), but Procedures cannot be called directly in SQL.

Extra — Package Structure

A Package has two parts: Package Specification (public interface / declaration) and Package Body (actual implementation / logic). Think of Spec as a header file and Body as an implementation file.

9. SELECT INTO Statement

Used to fetch data from the database into PL/SQL variables.

Syntax:

SELECT column_name INTO variable_name FROM table_name WHERE condition;
Extra — Important Rules

SELECT INTO must return exactly one row:

  • No rows returned → raises NO_DATA_FOUND exception
  • Multiple rows returned → raises TOO_MANY_ROWS exception

11. Important Rules to Remember
  • SET SERVEROUTPUT ON must be run before using DBMS_OUTPUT.PUT_LINE
  • Every PL/SQL block must end with END; followed by / (forward slash to execute)
  • := is the assignment operator — used to assign values to variables
  • = is the comparison operator — used only in conditions (WHERE / IF)
  • String concatenation uses the || operator
  • PL/SQL keywords are case-insensitive but conventionally written in UPPERCASE
  • DBMS_OUTPUT is a built-in Oracle package used to display output
  • DUAL is a special one-row dummy table in Oracle used to call functions in SELECT
Memory Trick

:= for assignment, = for comparison — different from most other languages!

12. Frequently Asked Interview Questions
Q1. What is PL/SQL?
PL/SQL is Oracle's procedural extension of SQL that combines SQL statements with programming constructs such as variables, loops, conditions, cursors, and exception handling.
Q2. Why was PL/SQL introduced?
PL/SQL was introduced to overcome the limitations of SQL by providing programming capabilities such as decision making, looping, and error handling inside the Oracle database.
Q3. What are the sections of a PL/SQL block?
1. DECLARE (Optional) — variable declaration   2. BEGIN (Mandatory) — executable statements   3. EXCEPTION (Optional) — error handling   4. END (Mandatory) — end of block
Q4. What is an Anonymous Block?
An Anonymous Block is a temporary PL/SQL block without a name. It is not stored in the database and is used only once. Mainly used for testing or one-time execution.
Q5. What is a Named Block?
A Named Block is stored permanently in the Oracle database and can be reused multiple times. Examples: Procedure, Function, Trigger, Package.
Q6. Difference between Procedure and Function? Extra
A Procedure may or may not return a value. A Function always returns exactly one value using the RETURN statement. Functions can be called inside SQL queries, but Procedures cannot be called directly in SQL.
Q7. What is %TYPE in PL/SQL? Extra
%TYPE is an anchored data type that allows a PL/SQL variable to automatically inherit the data type of a database column. Example: V_NAME EMP.ENAME%TYPE. Best practice to avoid type mismatch errors.
Q8. What is WHEN OTHERS in exception handling? Extra
WHEN OTHERS is a catch-all exception handler that catches any exception not handled by a specific WHEN clause. It must always be placed as the last WHEN clause in the EXCEPTION section.
Q9. What is the DUAL table in Oracle? Extra
DUAL is a special one-row, one-column dummy table in Oracle used to evaluate expressions or call functions in a SELECT statement. Example: SELECT GET_SQUARE(5) FROM DUAL;
Q10. What is the difference between := and = in PL/SQL? Extra
:= is the assignment operator used to assign values to variables. = is the comparison operator used in conditions. Using = for assignment causes a compilation error in PL/SQL.
Q11. What happens if SELECT INTO returns no rows or multiple rows? Extra
No rows → raises NO_DATA_FOUND exception. Multiple rows → raises TOO_MANY_ROWS exception. SELECT INTO must always return exactly one row.
