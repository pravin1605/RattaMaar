1. What is a Variable?
Interview Definition

A Variable is a named memory location used to store a value temporarily during program execution.

The value stored in a variable can be:

Number Character / String Date Boolean

Variables help us store, modify, and reuse data whenever required.

Memory Trick

Variable = Named Box in memory → put a value in it, use it anytime, change it anytime

2. Why Do We Need Variables?
  • Store values temporarily during program execution
  • Perform calculations
  • Fetch database records and hold them
  • Display output using DBMS_OUTPUT
  • Pass values between statements in the same block
3. Variable Declaration Syntax

Variables are declared in the DECLARE section of a PL/SQL block.

Syntax:

VARIABLE_NAME DATATYPE(SIZE);

Examples:

V_NAME VARCHAR2(20);
V_AGE NUMBER(3);
V_SAL NUMBER(10,2);
Extra — Initialization

Variables can be declared and initialized in the same line using :=

V_AGE NUMBER := 25;
V_NAME VARCHAR2(20) := 'SCOTT';
4. Rules for Naming Variables
#Rule
1Must begin with a letter (A–Z)
2Can contain letters, numbers, underscore ( _ ), dollar sign ( $ ), hash ( # )
3Cannot contain spaces
4Cannot use PL/SQL reserved words (SELECT, BEGIN, END, etc.)
5Variable names are not case-sensitive
Valid Examples
  • V_NAME
  • EMP_SALARY
  • AGE1
Invalid Examples
  • 1NAME — starts with number
  • EMP SAL — contains space
  • SELECT — reserved word
5. Assigning Values to Variables

PL/SQL uses the assignment operator := to assign values.

Syntax:

VARIABLE_NAME := VALUE;

Examples:

V_AGE := 60;
V_NAME := 'SCOTT';
Memory Trick

:= means "gets the value of" → V_AGE := 60 means "V_AGE gets the value 60"

= is only for comparison (in WHERE / IF conditions), never for assignment

6. Displaying Output

To display messages or variable values, use:

DBMS_OUTPUT.PUT_LINE('MESSAGE');
DBMS_OUTPUT.PUT_LINE(VARIABLE_NAME);
  • Must enable output first using: SET SERVEROUTPUT ON
  • Use || operator to join text and variable values
  • DBMS_OUTPUT is a built-in Oracle package
Extra — String Concatenation with ||

Use || to combine strings and variables in output:

DBMS_OUTPUT.PUT_LINE('NAME IS: ' || V_NAME);
7. Variable Reassignment — How It Works
ConceptExplanation
Variable ReassignmentA variable can be assigned a new value anytime. The new value replaces the old one.
Multiple AssignmentsIf a variable is assigned multiple times, only the last assigned value is stored in memory.
Example 1 — Reassignment

V_NUM starts as 27, then assigned 7.

Output: NUMBER IS 7

Latest value replaces the old value.

Example 2 — Multiple Assignments

V_NUM assigned 7, then 18, then 45.

Output: THE NUMBER IS 45

Only the last assigned value remains.

8. What is a Datatype?
Interview Definition

A Datatype defines what kind of data can be stored, how much memory will be allocated, and what operations can be performed on the data.

DatatypeUsed For
NUMBERNumeric values (integers and decimals)
VARCHAR2Variable-length character / string values
CHARFixed-length character values
DATEDate and time values
BOOLEANTRUE / FALSE / NULL values
9. Classification of PL/SQL Datatypes

4LOB DatatypesStore large objects — CLOB, BLOB, BFILEAdvanced
Memory Trick

S-R-C-L → Scalar → Reference → Composite → LOB

"Some Rookies Can't Lift" — Scalar and Reference are most important for interviews

10. Numeric Datatypes — Details
DatatypeDescriptionKey Feature

Use PLS_INTEGER for loop counters and calculations where performance matters.

11. Reference Datatypes — %TYPE and %ROWTYPE
TypeWhat it doesExample
%TYPEVariable inherits the datatype of a single database columnV_NAME EMP.ENAME%TYPE
%ROWTYPE ExtraVariable inherits the structure of an entire table row — all columns and their typesV_EMP EMP%ROWTYPE
Extra — Why use %TYPE and %ROWTYPE?

Best practice: If the column datatype changes in the database, the variable automatically adjusts. No need to manually update the PL/SQL code. Avoids type mismatch errors.

Memory Trick

%TYPE = one column's type  |  %ROWTYPE = entire row's type (all columns)

12. SELECT INTO Statement
Interview Definition

SELECT INTO is used to fetch data from a database table and store it directly into PL/SQL variables. Unlike normal SQL (which only displays data), SELECT INTO stores the data into variables for further use.

Normal SQL

SELECT ENAME FROM EMP;

Only displays data on screen. Cannot be used inside PL/SQL for further processing.

PL/SQL — SELECT INTO

SELECT ENAME INTO V_NAME FROM EMP;

Stores data into a variable for use in further logic or output.

Syntax:

SELECT col1, col2 INTO var1, var2 FROM table_name WHERE condition;
13. SELECT INTO — Important Rules
CaseWhat HappensException Raised
Exactly one row returnedWorks correctly — value stored in variableNone
No rows returnedVariable gets no value — error occursNO_DATA_FOUND
More than one row returnedCannot store multiple rows in one variable — error occursTOO_MANY_ROWS
Important Rule

SELECT INTO must always return exactly one row. Always use a proper WHERE condition to filter exactly one record.

14. Example — Fetch Employee Name and Salary

Fetch employee name and salary from EMP table where EMPNO = 7369 and display them.

StepWhat Happens
DECLAREV_NAME declared as EMP.ENAME%TYPE, V_SAL as EMP.SAL%TYPE
SELECT INTOENAME and SAL fetched from EMP table where EMPNO = 7369
DBMS_OUTPUTDisplays: NAME IS: SMITH SALARY IS: 800
Extra — Multiple Column Fetch

When fetching multiple columns, the number of columns and variables must match exactly — SELECT col1, col2 INTO var1, var2

15. Example — Third Highest Salary

Find the third highest salary from the EMP table using DENSE_RANK() inside SELECT INTO.

StepExplanation
DENSE_RANK()Assigns ranks to salaries in descending order — highest salary gets rank 1
SubqueryInner query assigns rank to each salary row using DENSE_RANK() OVER (ORDER BY SAL DESC)
Outer WHERE RN = 3Filters only the row with rank 3 — which is the third highest salary
SELECT INTO V_MAXStores the third highest salary into the variable V_MAX
OutputTHIRD HIGHEST SALARY IS: [value]
Extra — DENSE_RANK vs RANK

DENSE_RANK does not skip numbers when there are ties. Example: if two employees have the same salary and are ranked 2, the next rank is 3 (not 4). RANK would skip to 4 in this case.

16. GREATEST() Function
Definition

The GREATEST() function returns the largest value from a given list of values.

Syntax:

SELECT GREATEST(value1, value2, value3, ...) FROM DUAL;
ExampleOutput
SELECT GREATEST(100, 300, 50) FROM DUAL;300
SELECT GREATEST(5, 10, 7, 2) FROM DUAL;10
Extra — LEAST() Function

LEAST() is the opposite of GREATEST() — it returns the smallest value from a list. Example: SELECT LEAST(100, 300, 50) FROM DUAL; → Output: 50

17. Frequently Asked Interview Questions
Q1. What is a Variable in PL/SQL?
A variable is a named memory location used to store a value temporarily during program execution.
Q2. What is the assignment operator in PL/SQL?
The assignment operator is := (colon equals). Example: V_NUM := 100; It assigns the value 100 to the variable V_NUM.
Q3. What is a Datatype?
A datatype specifies what type of data a variable can store, how much memory it requires, and what operations can be performed on it.
Q4. What is SELECT INTO in PL/SQL?
SELECT INTO is used to fetch data from a database table and store it directly into PL/SQL variables for further use in the program.
Q5. What exceptions can occur in SELECT INTO?
1. NO_DATA_FOUND — when the query returns no rows.   2. TOO_MANY_ROWS — when the query returns more than one row. SELECT INTO must always return exactly one row.
Q6. What are the rules for naming variables in PL/SQL? Extra
1. Must begin with a letter. 2. Can contain letters, numbers, _, $, #. 3. Cannot contain spaces. 4. Cannot use reserved words. 5. Names are not case-sensitive.
Q7. What is the difference between %TYPE and %ROWTYPE? Extra
%TYPE anchors a variable to the datatype of a single database column. %ROWTYPE anchors a variable to the structure of an entire table row — it holds all columns and their types together.
Q8. What is the difference between PLS_INTEGER and SIMPLE_INTEGER? Extra
Both store integer values with better performance than NUMBER. SIMPLE_INTEGER is faster than PLS_INTEGER but cannot store NULL values. PLS_INTEGER can store NULL.
Q9. What is the GREATEST() function? Extra
GREATEST() returns the largest value from a given list of values. Example: SELECT GREATEST(100, 300, 50) FROM DUAL; returns 300. Its opposite is LEAST(), which returns the smallest value.
Q10. What is DENSE_RANK() and how is it different from RANK()? Extra
DENSE_RANK() assigns consecutive ranks without gaps even when there are ties. RANK() skips the next rank number when there are ties. Example: if two rows share rank 2, DENSE_RANK gives next row rank 3, but RANK gives rank 4.
