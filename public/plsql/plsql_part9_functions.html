1. What is a Function?
Interview Definition

A Function is a named PL/SQL block used to perform a specific task and return exactly one value. It is a subprogram that accepts input parameters, performs an operation, and returns a single result using the RETURN statement. Once stored in the database, it can be reused in SQL queries, PL/SQL blocks, and other programs.

  • A function always returns exactly one value using the RETURN keyword
  • It can be called inside a SQL query — SELECT function_name() FROM DUAL
  • It accepts input parameters — default mode is IN
  • Once created, it is stored permanently in the Oracle database
  • Mainly used when a computed result needs to be returned after performing an operation
Memory Trick

Function = Procedure that MUST return a value

Procedure → may or may not return  |  Function → ALWAYS returns exactly one value

2. Parts of a Function
1. Function Specification (Header)
  • Specifies the name of the function
  • Defines the input parameters and their datatypes
  • Specifies the return datatype using RETURN keyword
  • Written before IS / AS keyword
2. Function Body
  • Contains the actual code to perform the task
  • Must include at least one RETURN statement
  • Written between BEGIN and END
  • Can include SQL, loops, conditions, cursors, and exception handling
3. Function — Syntax
FUNCTION — GENERAL SYNTAX
CREATE [OR REPLACE] FUNCTION function_name ( parameter datatype -- IN mode is default ) RETURN return_datatype -- declare what type will be returned IS / AS -- Local variables, cursors (optional) BEGIN -- SQL / PL/SQL logic RETURN expression; -- Mandatory — must return a value [EXCEPTION WHEN OTHERS THEN -- Optional error handling] END [function_name]; /
KeywordMeaning
CREATE OR REPLACE FUNCTIONCreate or overwrite the function in the database
RETURN datatype (header)Declares what type of value the function will return
IS / ASStarts the function block — both work identically
RETURN expression; (body)Mandatory — returns the computed value to the caller
END [function_name];Marks the end of the function
Extra — How to Call a Function

Method 1 — SQL query:   SELECT function_name(params) FROM DUAL;

Method 2 — PL/SQL block:   result := function_name(params);

Method 3 — Inside another procedure or function body

5. Function — Teacher Examples
Example 1 — GET_SAL: Fetch Employee Salary by EMPNO
Task: Accept EMPNO as input and return the salary of that employee from EMP table.
Logic: SELECT SAL INTO V_SAL WHERE EMPNO = P_EMPNO → RETURN V_SAL. SMITH (7369) has salary 800.
GET_SAL — RETURN EMPLOYEE SALARY
CREATE OR REPLACE FUNCTION GET_SAL(P_EMPNO NUMBER) RETURN NUMBER AS V_SAL NUMBER; BEGIN SELECT SAL INTO V_SAL FROM EMP WHERE EMPNO = P_EMPNO; RETURN V_SAL; -- Return the fetched salary END; / -- Call the function SELECT GET_SAL(7369) FROM DUAL;
Output: 800  → SMITH (EMPNO 7369) has salary 800
Example 2 — FIRST_CHAR: Return First Character of a String
Task: Accept a string and return its first character using SUBSTR.
Logic: SUBSTR(P_CHAR, 1, 1) → starts at position 1, extracts 1 character → 'S' from 'SAHIL'.
FIRST_CHAR — RETURN FIRST CHARACTER
CREATE OR REPLACE FUNCTION FIRST_CHAR(P_CHAR VARCHAR2) RETURN CHAR AS BEGIN RETURN SUBSTR(P_CHAR, 1, 1); -- Extract 1 character from position 1 END; / -- Call the function SELECT FIRST_CHAR('SAHIL') FROM DUAL;
Output: S  → First character of 'SAHIL'
Example 3 — STRING_LENGTH: Return Number of Characters in a String
Task: Accept a string and return the total number of characters in it using LENGTH.
Logic: LENGTH('SAHIL') counts all characters → returns 5.
STRING_LENGTH — RETURN LENGTH OF STRING
CREATE OR REPLACE FUNCTION STRING_LENGTH(P_STRING VARCHAR2) RETURN NUMBER AS BEGIN RETURN LENGTH(P_STRING); -- Return total number of characters END; / -- Call the function SELECT STRING_LENGTH('SAHIL') FROM DUAL;
Output: 5  → 'SAHIL' has 5 characters
Example 4 — GREETING: No Parameter — Return Fixed Message
Task: Create a function with no parameters that returns a fixed welcome message.
Logic: No input — directly RETURN the hardcoded string.
GREETING — NO PARAMETER FUNCTION
CREATE OR REPLACE FUNCTION GREETING RETURN VARCHAR2 AS BEGIN RETURN 'WELCOME TO PLSQL CLASS'; END; / -- Call the function SELECT GREETING() FROM DUAL;
Output: WELCOME TO PLSQL CLASS
Example 5 — GREETING: With Name Parameter — Return Personalised Message
Task: Accept a name and return a personalised welcome message by concatenating the name to the fixed message.
Logic: RETURN fixed_string || V_NAME → joins both strings and returns.
GREETING — WITH NAME PARAMETER
CREATE OR REPLACE FUNCTION GREETING(V_NAME VARCHAR2) RETURN VARCHAR2 AS BEGIN RETURN 'WELCOME TO PLSQL CLASS, ' || V_NAME; END; / -- Call the function SELECT GREETING('PRAVIN') FROM DUAL;
Output: WELCOME TO PLSQL CLASS, PRAVIN
6. Extra Function Examples — String Operations Extra
Example 6 — REVERSE_STRING: Return Reverse of a String (Using FOR LOOP + SUBSTR)
Task: Accept a string and return it reversed character by character.
Logic: Oracle PL/SQL has no built-in REVERSE() for strings. We use FOR I IN REVERSE 1..LENGTH() loop to pick characters from last to first and build the reversed string one character at a time.
REVERSE_STRING — FOR LOOP + SUBSTR (CORRECT METHOD)
CREATE OR REPLACE FUNCTION REVERSE_STRING(P_STRING VARCHAR2) RETURN VARCHAR2 AS V_REVERSE VARCHAR2(4000) := ''; -- Empty string to build result BEGIN -- FOR REVERSE loop goes from last index down to 1 FOR I IN REVERSE 1..LENGTH(P_STRING) LOOP -- Pick one character at position I and append to result V_REVERSE := V_REVERSE || SUBSTR(P_STRING, I, 1); END LOOP; RETURN V_REVERSE; END; / -- Call the function SELECT REVERSE_STRING('PRAVIN') FROM DUAL;
Output: NIVARP  → 'PRAVIN' reversed character by character
Dry Run — How REVERSE_STRING('PRAVIN') Works Step by Step
Input: 'PRAVIN' → LENGTH = 6 I = 6 → SUBSTR('PRAVIN', 6, 1) = 'N' → V_REVERSE = 'N' I = 5 → SUBSTR('PRAVIN', 5, 1) = 'I' → V_REVERSE = 'NI' I = 4 → SUBSTR('PRAVIN', 4, 1) = 'V' → V_REVERSE = 'NIV' I = 3 → SUBSTR('PRAVIN', 3, 1) = 'A' → V_REVERSE = 'NIVA' I = 2 → SUBSTR('PRAVIN', 2, 1) = 'R' → V_REVERSE = 'NIVAR' I = 1 → SUBSTR('PRAVIN', 1, 1) = 'P' → V_REVERSE = 'NIVARP' RETURN 'NIVARP'
Example 7 — GET_SUBSTRING: Extract a Portion of a String
Task: Accept a string, starting position, and length — return the extracted portion using SUBSTR.
Logic: SUBSTR('WELCOME', 1, 4) → starts at position 1, extracts 4 characters → 'WELC'.
GET_SUBSTRING — EXTRACT PORTION OF STRING
CREATE OR REPLACE FUNCTION GET_SUBSTRING ( P_STRING VARCHAR2, P_START NUMBER, P_LENGTH NUMBER ) RETURN VARCHAR2 AS BEGIN RETURN SUBSTR(P_STRING, P_START, P_LENGTH); -- Extracts P_LENGTH characters starting from P_START position END; / -- Call the function SELECT GET_SUBSTRING('WELCOME', 1, 4) FROM DUAL;
Output: WELC  → 4 characters from position 1 of 'WELCOME'
Example 8 — TO_UPPER_CASE: Convert String to Uppercase
Task: Accept a string and return it converted to uppercase using UPPER.
Logic: UPPER('pravin') → 'PRAVIN'. Oracle UPPER function converts all lowercase letters to uppercase.
TO_UPPER_CASE — CONVERT TO UPPERCASE
CREATE OR REPLACE FUNCTION TO_UPPER_CASE(P_STRING VARCHAR2) RETURN VARCHAR2 AS BEGIN RETURN UPPER(P_STRING); -- Converts all characters to uppercase END; / -- Call the function SELECT TO_UPPER_CASE('pravin') FROM DUAL;
Output: PRAVIN  → 'pravin' converted to uppercase
Example 9 — ANNUAL_SAL: Calculate Annual Salary of Employee
Task: Accept EMPNO and return the annual salary (monthly salary × 12) of that employee from EMP table.
Logic: Fetch SAL for given EMPNO → multiply by 12 → RETURN result. SMITH: 800 × 12 = 9600.
ANNUAL_SAL — RETURN ANNUAL SALARY OF EMPLOYEE
CREATE OR REPLACE FUNCTION ANNUAL_SAL(P_EMPNO NUMBER) RETURN NUMBER AS V_SAL NUMBER; BEGIN SELECT SAL INTO V_SAL FROM EMP WHERE EMPNO = P_EMPNO; RETURN V_SAL * 12; -- Annual = monthly × 12 END; / -- Call the function SELECT ANNUAL_SAL(7369) FROM DUAL;
Output: 9600  → SMITH salary 800 × 12 = 9600
Example 10 — LAST_CHAR: Return Last Character of a String
Task: Accept a string and return its last character.
Logic: SUBSTR(P_STRING, -1, 1) → negative position counts from the end → position -1 is the last character.
LAST_CHAR — RETURN LAST CHARACTER
CREATE OR REPLACE FUNCTION LAST_CHAR(P_STRING VARCHAR2) RETURN CHAR AS BEGIN RETURN SUBSTR(P_STRING, -1, 1); -- -1 = last position from end END; / -- Call the function SELECT LAST_CHAR('ORACLE') FROM DUAL;
Output: E  → Last character of 'ORACLE' is 'E'
Example 11 — REMOVE_SPACES: Remove All Spaces from a String
Task: Accept a string and return it with all spaces removed.
Logic: REPLACE(P_STRING, ' ', '') replaces every space character with an empty string → all spaces stripped.
REMOVE_SPACES — STRIP ALL SPACES FROM STRING
CREATE OR REPLACE FUNCTION REMOVE_SPACES(P_STRING VARCHAR2) RETURN VARCHAR2 AS BEGIN RETURN REPLACE(P_STRING, ' ', ''); -- Replace space with nothing END; / -- Call the function SELECT REMOVE_SPACES('P L S Q L C L A S S') FROM DUAL;
Output: PLSQLCLASS  → All spaces removed from the string

Important — No Built-in REVERSE() in PL/SQL

Oracle PL/SQL does NOT have a built-in REVERSE() function for strings. Always use the FOR LOOP + SUBSTR approach to reverse a string manually — as shown in Example 6 above.

Common Mistakes with Functions

1. Missing RETURN statement in body → PLS-00372 error

2. Missing RETURN datatype in header → PLS-00103 compilation error

3. Using REVERSE() built-in for strings → does not exist in PL/SQL — use FOR LOOP + SUBSTR

4. Calling a function with EXEC → use SELECT or assignment, not EXEC

5. Using VARCHAR instead of VARCHAR2 → PLS-00215 error — always use VARCHAR2

9. Frequently Asked Interview Questions
Q1. What is a function in PL/SQL?
A function is a named PL/SQL block that performs a specific task and always returns exactly one value using the RETURN statement. Once stored in the database, it can be reused in SQL queries and PL/SQL blocks.
Q2. What is the difference between a procedure and a function?
A procedure may or may not return a value and cannot be used in a SQL SELECT statement. A function always returns exactly one value and can be called in a SQL SELECT statement. Functions are used to compute and return a result; procedures are used to perform a task.
Q3. What is the RETURN keyword in a function?
RETURN is used in two places. In the header: RETURN datatype — declares what type the function will return. In the body: RETURN expression; — actually returns the computed value to the caller. Both are mandatory in a function.
Q4. How do you call a function in Oracle?
Method 1: SELECT function_name(params) FROM DUAL;   Method 2: result := function_name(params); inside a PL/SQL block.   Method 3: Inside another procedure or function body.
Q5. How do you reverse a string in PL/SQL? Extra
Oracle PL/SQL has no built-in REVERSE() function for strings. Use a FOR LOOP with REVERSE keyword and SUBSTR to pick characters from the last position to the first. Declare an empty VARCHAR2 variable, append each character in reverse order, and return the result.
Q6. What does SUBSTR do? What are the parameters? Extra
SUBSTR(string, start, length) extracts a portion of a string. Start is the position to begin from (1-based index). Length is how many characters to extract. A negative start position (-1) extracts from the end of the string. Example: SUBSTR('ORACLE', 1, 3) returns 'ORA'.
Q7. What is DUAL and why is it used with functions? Extra
DUAL is a special one-row, one-column dummy table in Oracle. Since SELECT always needs a FROM clause, DUAL is used when no real table is needed — just to call a function or evaluate an expression. Example: SELECT GET_SAL(7369) FROM DUAL;
Q8. Can a function have no parameters? Extra
Yes. A function can have no parameters. It is called with empty parentheses: SELECT function_name() FROM DUAL; Example: the GREETING function returns a fixed welcome message without needing any input.
