What is a Query Parameter?
📌 Definition

A Query Parameter is data attached to a URL after the ? symbol in the form of key-value pairs.

It is used to send small pieces of data from the client (browser) to the server through the URL itself.

URL Breakdown — Query Parameter Anatomy
query?id=101&name=rohit
Servlet URL
query → mapped to Queryparameter.java
? Symbol
? → marks start of query parameters
Parameter 1
id=101 → key: id, value: 101
& Separator + Parameter 2
&name=rohit → key: name, value: rohit
Why Query Parameters are Used?

Used to send small data through URL — no form submission required.

Use CaseExample URL
Search valuegoogle.com/search?q=java+servlet
Product IDamazon.com/product?id=1001
Mobile filterflipkart.com/mobile?id=2001
Page numbersite.com/list?page=3&size=10
Student IDcollege.com/student?id=101&name=rohit

📘 What Happens When Link is Clicked

Tomcat reads: URL = /query → maps to Queryparameter.java

Servlet reads: id=101 and name=rohit from request

File 2 — Queryparameter.java ⭐ Most Important
📌 Purpose

Receives GET request from browser, reads query parameters using req.getParameter(), and generates an HTML response sent back to the browser.

Queryparameter.java
@WebServlet("/query") // Maps URL /query to this servlet public class Queryparameter extends HttpServlet { @Override protected void doGet(HttpServletRequest req, HttpServletResponse resp) throws ServletException, IOException { PrintWriter p = resp.getWriter(); // output stream to browser p.print("<html><body>"); p.print("<h1> student details from form </h1>"); p.print("<h1> name is : " + req.getParameter("name") // reads "rohit" + "</h1>"); p.print("<h1> Id is : " + req.getParameter("id") // reads "101" + "</h1>"); p.print("</body></html>"); } }

⚠️ Important — Key Points About getParameter()
  • getParameter() always returns a String — convert to int/double if needed
  • Returns null if the parameter name doesn't exist in the URL
  • Parameter names are case-sensitive — "name" ≠ "Name"
  • Works for both URL query params and HTML form data

File 7 — web.xml (Welcome File Configuration)
📌 What is a Welcome File?

A Welcome File is the default page that Tomcat opens when a user visits the application without specifying any page in the URL.

Example: User types http://localhost:8080/servletthirdday/ (no page name)

Tomcat automatically searches the welcome file list and opens the first file it finds.

web.xml
<welcome-file-list> <welcome-file>queryparameter.html</welcome-file> <!-- Checked 1st --> <welcome-file>pageb.html</welcome-file> <!-- Checked 2nd --> <welcome-file>paged.html</welcome-file> <!-- Checked 3rd --> <welcome-file>pagec.jsp</welcome-file> <!-- Checked 4th --> </welcome-file-list>
Welcome File Search Order

Tomcat searches files in order. It opens the first file it finds. If none are found, Tomcat throws a 404 error.

1
queryparameter.html → Tomcat looks for this file
FOUND → OPEN
2
pageb.html → Only checked if #1 not found
CHECK
3
paged.html → Only checked if #2 not found
CHECK
4
pagec.jsp → Last resort — only if #3 not found
CHECK
📘 Real-World Analogy — Welcome File

Think of it like a hotel receptionist's checklist:

"Is Suite A available? → Yes → Give Suite A."  |  "If not → Check Suite B → if not → Suite C"

Tomcat follows the same ordered search — first match wins.

🧠 Memory Trick — Welcome File

Welcome File = "Hotel Room Priority List" — VIP guest gets the best room available, checked in order.

If queryparameter.html exists → that's the VIP room → open immediately. Otherwise move down the list.

🎯 Interview Q&A
Q1. What is a Query Parameter?
A Query Parameter is data passed through the URL after the ? symbol in the form of key-value pairs. Example: query?id=101&name=rohit — here id=101 and name=rohit are query parameters.
Q2. Why do we use request.getParameter()?
request.getParameter() is used to retrieve data sent by the client through URL query parameters or HTML form fields. It takes the parameter name as a String and returns the corresponding value as a String.
Q3. What does request.getParameter() return if the parameter doesn't exist?
It returns null. Always check for null before using the returned value to avoid NullPointerException.
Q4. Why is HttpServlet used when link is clicked?
Clicking an HTML link (<a href>) sends an HTTP GET request. HttpServlet provides the doGet() method which is specifically designed to handle GET requests.
Q5. What is the purpose of @WebServlet("/query")?
It maps the URL /query to the Queryparameter servlet class. When Tomcat receives a request for /query, it automatically invokes this servlet — no web.xml entry needed.
Q6. What is a Welcome File in Servlet?
A Welcome File is the default page Tomcat opens when a user accesses the application without specifying a page in the URL (e.g. http://localhost:8080/app/). It is configured in web.xml inside <welcome-file-list>.
Q7. How does Tomcat search Welcome Files?
Tomcat searches files in the order listed in <welcome-file-list>. It opens the first file it finds in the webapp directory. If no file in the list exists, Tomcat throws a 404 error.
Q8. What is the difference between HTML and JSP?
HTML — static only, no Java code, no dynamic content. JSP — can embed Java code (<%= %>), can display dynamic data (from DB, session, servlet), processed on server before being sent to browser as HTML.
Q9. Can we send multiple query parameters? How are they separated?
Yes. Multiple query parameters are separated by the & symbol. Example: ?id=101&name=rohit&age=23 — three parameters sent together.
🧠 Memory Trick — Query Parameter URL

"Question Marks Separate Answers"

URL + ? (question) + key=value (answer) + & (and another answer)

getParameter("key") = Servlet asking: "What is the value of this key?"
