Client-Server Communication

Whenever a user opens a website (e.g. www.google.com) or submits a form, the browser sends a Request to the server. The server processes it and sends back a Response.

Client (Browser)
↓ Request
Server
↓ Response
Client (Browser)
What is a Request?
📌 Definition

A Request is a message sent by the client to the server asking for something.

Think of it as: "Hello Server, please give me this resource."

📘 Examples of Requests
  • Open Home Page
  • Login User
  • Show Employee Data
  • Calculate Salary
What Information is Present in Request?
1. URL

Example: http://localhost:8080/login → tells the server which resource is requested.

2. Request Method
MethodPurpose
GETFetch / retrieve data from server
POSTSend / submit data to server
PUTUpdate existing data on server
DELETEDelete data from server
3. Form Data

When user enters data in a form, browser sends it inside the request body.

📘 Example

User enters: Username = Pravin   Password = 123

Browser sends: username=Pravin&password=123 inside the request.

4. Headers

Additional information automatically sent by the browser with every request.

  • Browser Name & Version
  • Language preference
  • Operating System
  • Cookies
📘 Complete Request Example

POST /login

username=Pravin&password=123

Meaning: "Please login user Pravin with password 123"

What is a Response?
📌 Definition

A Response is a message sent by the server back to the client.

Think of it as: "Here is the result you requested."

What Information is Present in Response?
1. Status Code

Tells whether the request succeeded or failed.

Status CodeMeaning
200 OKRequest was successful
404 Not FoundRequested resource not found
500 Internal Server ErrorServer encountered an error
2. Headers

Extra information about the response sent along with the body.

  • Content-Type (e.g. text/html)
  • Content-Length
  • Cookies
3. Response Body

The actual data sent back to the browser.

📘 Example

<h1>Welcome Pravin</h1> — an HTML page

<table><tr><td>Employee Data</td></tr></table> — table data

Or simply plain text: Login Successful

📘 Complete Response Example

200 OK

Welcome Pravin

How Servlet Reads Request?

Servlet receives a Request object of type HttpServletRequest. This object contains everything sent by the client.

📌 Reading Request Data

Method: request.getParameter("username")

If browser sends username=Pravin, Servlet reads it as:

String name = "Pravin";

How Servlet Creates Response?

Servlet uses the HttpServletResponse object to send data back to client.

📌 Sending Response Data

PrintWriter pw = response.getWriter();

pw.print("Welcome Pravin");

Browser receives and displays: Welcome Pravin

How Servlet API Helps Here?

Servlet API provides two very important interfaces for Request-Response handling:

ServletRequest / HttpServletRequest

Purpose: Read client request data

  • getParameter("name") — read form field
  • getMethod() — GET or POST?
  • getHeader("name") — read headers
  • getSession() — get session
ServletResponse / HttpServletResponse

Purpose: Send response back to client

  • getWriter() — get PrintWriter to write
  • setContentType("text/html") — set type
  • setStatus(200) — set status code
  • sendRedirect("url") — redirect client

🎯 Interview Q&A
Q1. What is the role of Servlet in Request and Response processing?
Servlet acts as an intermediary between the client and the server. It receives the client request through the HttpServletRequest object, processes the request, interacts with databases or business logic if required, and sends the result back to the client using the HttpServletResponse object.
Q2. Which objects are used by a Servlet to handle Request and Response?
HttpServletRequest — used to read data sent by the client. HttpServletResponse — used to send data back to the client.
Q3. What is a Status Code? Name 3 important ones.
200 OK — request succeeded. 404 Not Found — resource not found. 500 Internal Server Error — server-side error occurred.
Q4. What is the difference between GET and POST?
GET — sends data in URL, used for fetching data, data visible in browser. POST — sends data in request body, used for submitting sensitive data (login, forms), data not visible in URL.
Q5. What is a Request Header?
A Request Header is additional metadata automatically sent by the browser along with the request — such as browser name, accepted language, content type, and cookies.
Q6. What method is used to read form data in Servlet?
request.getParameter("fieldName") — reads a single form field value sent by the client.
Q7. What method is used to send response from Servlet?
response.getWriter() — returns a PrintWriter object, used to write text/HTML response back to the client.
Q8. What does setContentType() do?
response.setContentType("text/html") — tells the browser what type of content is being sent in the response, so it can render it correctly.
🧠 Memory Trick — Request vs Response

Request → Reaches server | Response → Returns to client

Request = Question to server  |  Response = Answer from server

GET = Grab data (visible in URL)  |  POST = Push data (hidden in body)
