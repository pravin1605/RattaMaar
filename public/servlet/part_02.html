2. Servlet API
What is Servlet API?

Servlet API is a collection of interfaces and classes provided by Java to create Servlets.

Without Servlet API, we cannot create a Servlet.

📌 Servlet API Provides
  • Interfaces — contracts that Servlets must follow
  • Classes — ready-made implementations
  • Methods — tools for handling requests and generating responses
Why Servlet API is Needed?
📘 Example

Suppose a browser sends: Name = Pravin   Age = 23

How will Java read this data? Using → request.getParameter("name")

This method comes from Servlet API.

Similarly → response.getWriter() also comes from Servlet API.

∴ Servlet API provides all the tools required to build web applications.

🎯 Interview Q&A — Servlet API
Q1. What is Servlet API?
Servlet API is a set of interfaces and classes provided by Java (in javax.servlet and javax.servlet.http packages) used to build server-side web applications.
Q2. What are the two main packages in Servlet API?
javax.servlet — generic/protocol-independent classes. javax.servlet.http — HTTP-specific classes like HttpServlet, HttpSession.
Q3. What is the difference between GenericServlet and HttpServlet?
GenericServlet is protocol-independent and overrides service(). HttpServlet extends GenericServlet and is HTTP-specific, providing doGet(), doPost(), etc.
Q4. What is HttpServletRequest?
An interface that extends ServletRequest. It provides HTTP-specific methods to read client request data such as parameters, headers, session, cookies.
Q5. What is HttpServletResponse?
An interface that extends ServletResponse. It provides methods to send HTTP responses back to the client, set content type, and get a writer/stream for output.
Q6. What is RequestDispatcher?
RequestDispatcher is an interface in javax.servlet that allows forwarding a request to another resource (Servlet/JSP) or including another resource's content in the response.
Q7. What is HttpSession?
HttpSession is an interface used to maintain session between multiple requests from the same client. It stores user-specific data across requests (e.g., login info).
Q8. Why must we use HttpServlet instead of GenericServlet for web apps?
Web applications use HTTP protocol. HttpServlet provides HTTP-specific features like GET/POST handling, session management, and cookies — which GenericServlet lacks.
🧠 Memory Trick — Servlet API Packages

javax.servlet → Generic (G for Generic, no protocol lock)

javax.servlet.http → HTTP Specific (H for HTTP — hypertext)

Think: "First learn to walk (generic), then run on HTTP (specific)"
