9. PrintWriter in Servlets
What is PrintWriter?
📌 Definition

PrintWriter is a Java class used to write formatted text output to a stream — such as the browser, a file, or console.

In Servlets, it is used to send HTML, text, or JSON from the Servlet back to the client (browser).

AspectInformation

What Data Types Can PrintWriter Print?

PrintWriter automatically converts any data type to text before writing:

PrintWriter out = response.getWriter(); // Integers out.print(100); // → 100 out.println(200); // → 200\n // Double / Float out.print(3.14); // → 3.14 out.println(2.5); // → 2.5\n // Boolean out.print(true); // → true out.println(false); // → false\n
// String out.print("Hello"); // → Hello out.println("World"); // → World\n // char out.print('A'); // → A out.println('B'); // → B\n // Object out.print(obj); // → obj.toString() out.println(obj); // → obj.toString()\n // Formatted out.printf("Age=%d", 25); // → Age=25
⭐ Key Point

PrintWriter automatically converts everything to text (String) before sending. You never need to manually convert int, double, or boolean — just pass it directly to print() or println().

print() vs println() vs write()

Why setContentType() is Important?
📌 response.setContentType("text/html")

This tells the browser how to interpret the data being sent. Without it, the browser may display raw HTML tags as plain text instead of rendering them as a page.

Content Type ValueWhat It MeansWhen to Use
"text/html"Send HTML — browser renders it as webpageMost servlet responses
"text/plain"Send plain text — browser shows as-isSimple text responses
"application/json"Send JSON dataREST API responses
"text/xml"Send XML dataXML responses
⚠️ Best Practice — Order Matters

Always call setContentType() BEFORE calling getWriter(). Once PrintWriter is obtained, the content type cannot be changed.

// ✅ Correct order response.setContentType("text/html"); // FIRST PrintWriter out = response.getWriter(); // SECOND // ❌ Wrong order — content type may not be applied PrintWriter out = response.getWriter(); // FIRST — wrong! response.setContentType("text/html"); // SECOND — too late!

🎯 Interview Q&A
Q1. What is PrintWriter in Servlet?
PrintWriter is a Java class from java.io package used to write formatted text output to a stream. In servlets, it is used to send HTML or text data from the servlet back to the client browser. It is obtained via response.getWriter().
Q2. Is PrintWriter a class or interface?
PrintWriter is a Class — not an interface. It extends the Writer abstract class and belongs to the java.io package.
Q3. How do you get a PrintWriter in a Servlet?
PrintWriter out = response.getWriter(); — it is obtained from the HttpServletResponse object. The request object does NOT have a getWriter() method.
Q4. What is the difference between print() and println()?
print() — writes data without a new line. Next output continues on the same line. println() — writes data and then adds a newline character (\n). Next output starts on a new line.
Q5. What is the difference between PrintWriter and System.out.println()?
System.out.println() sends output to the server console — only the developer sees it (used for debugging). PrintWriter.println() sends output to the client browser — the user sees it.
Q6. Why is setContentType() called before getWriter()?
setContentType("text/html") must be called before getWriter() because once the writer is obtained, the response headers (including content type) may already be committed. Calling it after may have no effect or cause errors.
Q7. Can PrintWriter print integer, double, and boolean values?
Yes. PrintWriter automatically converts any data type — int, double, boolean, char, Object — to its String representation before writing. No manual conversion is needed.
Q8. What does response.getWriter() return?
It returns a PrintWriter object that is connected to the HTTP response output stream. Anything written to this PrintWriter is sent as the HTTP response body to the client browser.
Q9. What is the use of out.close() at the end?
out.close() flushes any remaining buffered output and closes the PrintWriter, releasing associated resources. It is a good practice to call it after writing all response content.
