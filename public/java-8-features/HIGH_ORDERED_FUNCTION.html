Complete notes — definition, characteristics, programs, examples, advantages
📘 Higher Order Function — Definition
🔹 What is a Higher Order Function?

A Higher Order Function is a function (method) that:

1
Accepts another function (Lambda Expression) as a parameter
2
Returns another function (Lambda Expression)
In Java, since functions cannot exist independently, Functional Interfaces and Lambda Expressions are used to achieve Higher Order Functions.
📘 Why Higher Order Functions?
🔹 Normally — passing data

Methods normally accept data values as parameters.

add(10, 20); // 10 and 20 are data values
🔹 With Higher Order Functions — passing behavior

Sometimes we want to pass behavior (logic) instead of data. Higher Order Functions make this possible.

(a,b) -> a+b (a,b) -> a*b // These are behaviors, not data
📘 Characteristics of Higher Order Functions
🔹 1 — Accept function as parameter
disp((a,b) -> a+b);
🔹 2 — Return a function
return (a,b) -> a+b;
🔹 3 — Work with Lambda Expressions

Lambda Expressions make Higher Order Functions possible in Java.

HIGHER ORDER FUNCTIONS | Page 2 — Accepting a Lambda Expression
✅ Higher Order Function — Accepting a Lambda Expression
🔹 Functional Interface used
public interface Calculator { int calculate(int a, int b); }
🔹 Program — method accepting Lambda as parameter
public class Test2 { // Method accepting function / lambda expression public static void disp(Calculator c) { System.out.println(c.calculate(10, 20)); } public static void main(String[] args) { disp((a,b) -> a+b); // 30 disp((a,b) -> a-b); // -10 disp((a,b) -> a/b); // 0 disp((a,b) -> a*b); // 200 } }
🔹 Output
30 -10 0 200
🔍 Explanation — call by call
CallLambda passedCalculationOutput
Call 1(a,b) -> a+b10 + 2030
Call 2(a,b) -> a-b10 - 20-10
Call 3(a,b) -> a/b10 / 20 (integer division)0
Call 4(a,b) -> a*b10 * 20200
The method disp() accepts Lambda Expressions — therefore it is a Higher Order Function. Since Lambda Expressions are implementations of Functional Interfaces, they can be passed directly.
HIGHER ORDER FUNCTIONS | Page 3 — Returning a Lambda Expression
✅ Higher Order Function — Returning a Lambda Expression
🔹 Definition

If a method returns a Lambda Expression, then that method is called a Higher Order Function.

🔹 Program — method returning Lambda
public class MethodReturningLambda { // Method returning a Lambda Expression public static Calculator returnCalci() { return (a,b) -> a+b; } public static void main(String[] args) { Calculator c = returnCalci(); System.out.println(c.calculate(10, 20)); } }
🔹 Output
30
🔍 Explanation
1
returnCalci() returns the Lambda (a,b) -> a+b
2
Calculator c = returnCalci(); stores the returned Lambda
3
c.calculate(10, 20) performs 10 + 20 = 30
📋 Summary — Higher Order Functions
🔹 Accepts a function
disp((a,b) -> a+b);
🔹 Returns a function
return (a,b) -> a+b;
🔹 Real Life Example — Online shopping: discount calculator

An online shopping application needs to calculate different types of discounts. Instead of creating separate classes for every discount type, Lambda Expressions can be passed dynamically.

LambdaDiscount type
(a,b) -> a+bFestival Discount
(a,b) -> a-bCoupon Discount
(a,b) -> a*bSpecial Offer
This is the practical use of Higher Order Functions — behavior passed dynamically, no separate classes required.
FUNCTIONAL PROGRAMMING | Page 4 — Definition, First-Class Citizen & Features
📘 Functional Programming — Definition
🔹 What is Functional Programming?

Functional Programming is a programming paradigm in which functions are treated as First-Class Citizens. Functions can be passed as arguments, returned from methods, and stored in variables.

🔹 Simple definition

Functional Programming is a style of programming where functions are treated like data.

📘 What is a First-Class Citizen?

An entity is called a First-Class Citizen if it can do all three of the following:

🔹 1 — Stored in a variable
Calculator add = (a,b) -> a+b;
🔹 2 — Passed as an argument
disp((a,b) -> a+b);
🔹 3 — Returned from a method
return (a,b) -> a+b;
Since Lambda Expressions can do all three operations, functions behave like First-Class Citizens in Java.
📘 Functional Programming Features
🔹 1 — Functions as arguments
disp((a,b) -> a+b);
🔹 2 — Functions as return values
return (a,b) -> a+b;
🔹 3 — Functions stored in variables
Calculator add = (a,b) -> a+b;
🔹 4 — Less code

Lambda Expressions significantly reduce code compared to traditional approaches.

🔹 5 — Better readability

Programs become easier to understand and follow.

🔹 6 — Stream API support

Functional Programming is heavily used in the Stream API.

list.stream() .filter(x -> x%2==0) .forEach(System.out::println);
