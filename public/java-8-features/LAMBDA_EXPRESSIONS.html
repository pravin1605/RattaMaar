Functional Interface (SAM Interface)

Definition

A Functional Interface contains exactly one abstract method. SAM stands for Single Abstract Method. It is called a Functional Interface because we provide implementation for only one abstract method.

public interface Demo1 {
  public void m1();
}

Allowed — multiple default methods

allowed 
default void m2() {
  System.out.println("m2");
}

Allowed — multiple static methods

allowed 
public static void m3() {
  System.out.println("m3");
}

Cannot have 2+ abstract methods

not allowed

Adding a second abstract method breaks the Functional Interface contract.

Object class methods — special rule

Even if an interface declares equals(Object) , hashCode() , or toString() , these are NOT counted as abstract methods — they already exist in the Object class. The compiler ignores them while counting. So the interface below is still a valid Functional Interface:

public interface Demo1 {
  public void m1();                    // counted — 1 abstract method
  public boolean equals(Object obj);   // ignored
  public int hashCode();               // ignored
}

Conventional Approach — Before Java 8

Steps required to use a Functional Interface

1
Create an Interface
2
Create a Child Class implementing the interface
3
Override the abstract method
4
Create an Object
5
Call the Method
// Interface
public interface Vehicle { void start(); }

// Two separate classes needed
public class Car implements Vehicle {
  public void start() { System.out.println("Car Started"); }
}
public class Bus implements Vehicle {
  public void start() { System.out.println("Bus Started"); }
}

// Driver class
Vehicle car = new Car();
car.start();  // Car Started
Vehicle bus = new Bus();
bus.start();  // Bus Started

Problem with this approach

To execute only one method we are forced to create an interface, multiple child classes, override the method, create objects, and then call it. This increases code length, development time, and maintenance cost.

Lambda Expression — Definition

What is a Lambda Expression?

A Lambda Expression is an anonymous function used to provide the implementation of a Functional Interface in a concise way. Introduced in Java 8 to reduce boilerplate code and support Functional Programming. No child class is required, no method overriding is required.

Lambda Syntax

Three components

( )
Parameters
->
Lambda operator
{ }
Method body
InterfaceName variable = (parameters) -> {
  method body
};

Without parameters

Vehicle car = () -> {
  System.out.println("car started");
};
car.start();

With parameters (type specified)

Demo2 d1 = (int a) -> {
  System.out.println(a * 2);
};
d1.m1(10); // Output: 20

With parameters (type omitted)

Java automatically infers the datatype from the method declaration. Both forms are valid.

Demo2 d2 = (a) -> {
  System.out.println(a * 2);
};
d2.m1(20); // Output: 40

Single parameter shorthand

When there is only one parameter, parentheses can also be omitted.

Even e = x -> x % 2 == 0;
Explicit Return vs Implicit Return

Explicit Return

Uses the return keyword inside { } curly braces. Used when there are multiple statements in the body.

Test t = (a, b) -> {
  return a * b * 5;
};
System.out.println(t.display(3, 2));
// Output: 30
Calculation: 3 × 2 × 5 = 30. Since return is explicitly written, this is Explicit Return.

Implicit Return

If the lambda body has only one return statement, the return keyword and { } curly braces can both be removed. Java automatically returns the result.

Test t = (a, b) -> a * b * 5;
System.out.println(t.display(3, 2));
// Output: 30
Same result — shorter code. Only works for single-expression bodies.

Important Notes

Note 1 — Functional Interfaces only

Lambda Expressions can only be used with Functional Interfaces. They cannot be used with normal interfaces that have multiple abstract methods.

Note 2 — Dynamic functionality

Using Lambda Expressions we can change the functionality dynamically. Same interface reference, different implementations at different points.

Note 3 — No child classes needed

No need to create child classes and override methods. The lambda body directly acts as the implementation of the single abstract method.

Examples

Example 1 — No parameters (Vehicle)

public interface Vehicle {
  void start();

  public static void main(String[] args) {
    Vehicle car = () -> {
      System.out.println("car started");
    };
    car.start();  // car started

    Vehicle bus = () -> {
      System.out.println("bus started");
    };
    bus.start();  // bus started
  }
}
Same Functional Interface, two different implementations — no child classes created, no method overriding.

Example 2 — With parameters

public interface Demo2 {
  void m1(int a);

  public static void main(String[] args) {
    Demo2 d1 = (int a) -> {  // type specified
      System.out.println(a * 2);
    };
    d1.m1(10);  // Output: 20

    Demo2 d2 = (a) -> {  // type omitted
      System.out.println(a * 2);
    };
    d2.m1(20);  // Output: 40
  }
}

Example 3 — Even number check

public interface Even {
  boolean isEven(int x);

  public static void main(String[] args) {
    Even e1 = (int x) -> {  // explicit return
      return x % 2 == 0;
    };
    System.out.println(e1.isEven(23));  // false

    Even e2 = x -> x % 2 == 0;  // implicit return
    System.out.println(e2.isEven(10));  // true
  }
}
23 is odd → false  |  10 is even → true

Example 4 — Calculator (void, no return)

public interface Calculator {
  void add(int x, int y);

  public static void main(String[] args) {
    Calculator c1 = (int x, int y) -> {  // type specified
      System.out.println(x + y);
    };
    c1.add(10, 20);  // 30

    Calculator c2 = (x, y) -> {  // type omitted
      System.out.println(x + y);
    };
    c2.add(30, 40);  // 70
  }
}

Example 5 — Explicit and implicit return calculator

public interface Calculator2 {
  int add(int x, int y);

  public static void main(String[] args) {
    Calculator2 c1 = (a, b) -> {  // explicit return
      System.out.println("calculating sum");
      return a + b;
    };
    System.out.println(c1.add(20, 30));  // calculating sum → 50

    Calculator2 c2 = (x, y) -> x + y;  // implicit return
    System.out.println(c2.add(20, 30));  // 50
  }
}

Example 6 — Dynamic calculator (same interface, four operations)

public interface Calculator {
  int calculate(int x, int y);

  public static void main(String[] args) {
    Calculator add = (x, y) -> x + y;
    Calculator sub = (x, y) -> x - y;
    Calculator pro = (x, y) -> x * y;
    Calculator div = (x, y) -> x / y;

    System.out.println("sum="        + add.calculate(10, 20));  // 30
    System.out.println("difference=" + sub.calculate(10, 20));  // -10
    System.out.println("product="    + pro.calculate(10, 20));  // 200
    System.out.println("division="   + div.calculate(10, 20));  // 0
  }
}
The same Functional Interface int calculate(int x, int y) is implemented in four different ways — addition, subtraction, multiplication, division. This demonstrates the dynamic nature of Lambda Expressions.
