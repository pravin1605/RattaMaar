Built-in Functional Interfaces

Complete notes — Predicate, Function, Consumer, Supplier, BiFunction

Introduction

What are Built-in Functional Interfaces?

Java 8 introduced several predefined Functional Interfaces in the package java.util.function . These are called Built-in Functional Interfaces because Java already provides them. They are heavily used with Lambda Expressions, Method References, Stream API, and Functional Programming.

Why Built-in Functional Interfaces?

Before Java 8, whenever we needed a Functional Interface, we created our own. For example:

interface Calculator {
  int calculate(int x, int y);
}

Java 8 provides many commonly used Functional Interfaces so we don't need to create them again and again. This reduces boilerplate code, development time, and maintenance effort.

1 — Predicate<T>

Definition

Predicate<T> is a Functional Interface used to test a condition on an input and return a boolean value.

Abstract method

boolean test(T t);

Purpose

1
Checking conditions
2
Filtering data
3
Used in Stream API's filter()

Memory trick

Predicate = Prediction. It answers TRUE or FALSE / YES or NO.

Example

import java.util.function.Predicate;

public class DemoPredi {
  public static void main(String[] args) {

    Predicate<Integer> p = t -> t%2==0;
    System.out.println(p.test(20));           // true

    Predicate<String> p2 = t -> t.length()>=5;
    System.out.println(p2.test("programming")); // true
    System.out.println(p2.test("pro"));         // false
  }
}
Output: true true false

Explanation

1
t%2==0 checks if number is even. p.test(20) → 20%2=0 → true
2
t.length()>=5 checks string length. p2.test("programming") → length 11 → true
3
p2.test("pro") → length 3 → false

Real life examples of Predicate

Age >= 18 Salary > 50000 Marks >= 35

All these conditions return true or false — therefore Predicate is used.

2 — Function<T,R>

Definition

Function<T,R> is a Functional Interface that takes one input and returns one output.

Abstract method

R apply(T t);

Purpose

1
Data Transformation
2
Data Conversion
3
Mapping Operations
4
Mostly used with Stream API's map()

Understanding T and R

Function<String, Integer>
// Input → String
// Output → Integer

Example

import java.util.function.Function;

public class DemoFunction {
  public static void main(String[] args) {

    Function<String, Integer> f1 = x -> x.length();
    System.out.println(f1.apply("hello"));   // 5
    System.out.println(f1.apply("abcdef")); // 6
  }
}
Output: 5 6

Explanation

Function<String, Integer> — Input: String, Output: Integer. f1.apply("hello") → length 5. f1.apply("abcdef") → length 6.

Real life examples of Function

Name → Length Temperature → Fahrenheit String → Uppercase

One value transformed into another.

3 — Consumer<T>

Definition

Consumer<T> is a Functional Interface that accepts one input but returns nothing.

Abstract method

void accept(T t);

Purpose

1
Printing
2
Logging
3
Updating
4
Modifying Data

Memory trick

Consumer = Consumes data, returns nothing.

Example

import java.util.function.Consumer;

public class DemoConsumer {
  public static void main(String[] args) {

    Consumer<String> c = x -> {
      System.out.println("hello " + x);
    };

    c.accept("hemanth");  // hello hemanth
    c.accept("soham");    // hello soham
    c.accept("salaar");   // hello salaar
  }
}
Output: hello hemanth hello soham hello salaar

Explanation

accept() receives the value and processes it. No value is returned.

Real life examples of Consumer

Print Data Send Email Write Log Display Result

These operations don't return values — Consumer is used.

4 — Supplier<T>

Definition

Supplier<T> is a Functional Interface that takes no input but returns a value.

Abstract method

T get();

Purpose

Used when data needs to be generated or supplied.

Memory trick

Supplier = Supply Data. Input: Nothing. Output: Something.

Example

import java.util.function.Supplier;

public class DemoSupplier {
  public static void main(String[] args) {

    Supplier<String> s = () -> "hello every one im A DON";

    System.out.println(s.get());
    System.out.println(s.get());
    System.out.println(s.get());
  }
}
Output: hello every one im A DON hello every one im A DON hello every one im A DON

Explanation

Supplier accepts no input. Returns a String every time get() is called.

Real life examples of Supplier

Generate OTP Random Number Current Date Current Time

No input required — Supplier generates the value.

5 — BiFunction<T,U,R>

Definition

BiFunction<T,U,R> is a Functional Interface that accepts two inputs and returns one output.

Abstract method

R apply(T t, U u);

Purpose

Used when two values need to be combined into one result.

Understanding generics

BiFunction<Integer,Integer,Integer>
// Input1 → Integer
// Input2 → Integer
// Output → Integer

Example

import java.util.function.BiFunction;

public class DemoBIfun {
  public static void main(String[] args) {

    BiFunction<Integer,Integer,Integer> bi = (x,y) -> x+y;

    System.out.println(bi.apply(10, 20));  // 30
    System.out.println(bi.apply(20, 30));  // 50
    System.out.println(bi.apply(40, 20));  // 60
  }
}
Output: 30 50 60

Explanation

(x,y) -> x+y adds two numbers. bi.apply(10,20) → 30. bi.apply(20,30) → 50. bi.apply(40,20) → 60.

Key rule to always remember

All built-in Functional Interfaces are in java.util.function . Use Predicate to test a condition, Function to transform data, Consumer to consume without returning, Supplier to supply without input, and BiFunction when you have two inputs and need one output.
